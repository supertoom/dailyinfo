Apache mod_http2竞态漏洞公开PoC

Apache HTTP Server 的 mod_http2 竞态条件漏洞 CVE-2026-119618（CVSS 9.8）已由奇安信 CERT、微步情报局和绿盟科技 CERT 复现；绿盟称拒绝服务 PoC 及漏洞细节已公开，Apache 表示尚无公开利用或在野攻击证据，官方补丁已经发布。漏洞源于 assign_headers() 对共享资源同步不当，可造成堆内存损坏、进程崩溃，并在特定条件下以 Web 服务器权限执行任意代码。 利用要求服务器加载 mod_http2、Protocols 配置包含 h2/h2c 且可网络访问，无需认证；h2c 明文连接同样受影响，仅提供 HTTP/1.1 的服务器不受影响。Apache HTTP Server 2.4.55 至 2.4.70、独立版 mod_h2 2.0.8 至 2.0.42 受影响；Apache HTTP Server 2.4.71、独立版 mod_h2 2.0.43 或更高版本已修复。无法立即更新时可关闭 HTTP/2 临时缓解。

美方捣毁FaceStealer恶意基础设施

美国司法部与FBI已中断朝鲜黑客FaceStealer行动使用的云基础设施；该团伙过去18个月骗取超过4亿美元加密货币。FBI称，攻击者通过虚假Zoom和Teams会议诱使加密、Web3从业者及开源维护者运行恶意命令，植入可窃取浏览器Cookie、记录键盘、截屏并维持远程访问的软件。 FBI已扣押900多段受害者录像，并发现部分攻击者会监控钱包数月甚至一年以上，待余额增加后转走资金。相关恶意代码的大范围分发企图在实施前被发现并阻止；报道未披露补丁状态或受影响人数。

Apple披露Secure Enclaves传感器数据隔离架构

Apple公开了Secure Enclaves芯片级安全架构的运行机制，用于在后台处理中隔离摄像头和麦克风数据；这是架构披露，未涉及已确认的漏洞或攻击。Apple称，在Secure Enclaves内处理和分析的数据，主操作系统、应用及Apple均无法访问。 该架构分为环境感知和主动两种模式：环境感知下，原始音视频留在Secure Enclaves内，处理完成后即丢弃，不进入主操作系统；主动模式下可向主操作系统释放完整传感器数据，并由安全指示器告知用户。Exclave Indicator Controller只有在确认指示器已开启且显示足够时间后，才允许完整数据流入主操作系统。 该机制应用于HomeView人员识别、Siri Recap、Live Rewind及设备传感器指示等场景。Apple称，HomeView向主操作系统发送的识别结果仅包含人员标识、位置和置信度，不含音视频数据；由于内核持续变化，其形式化验证采取逐步覆盖不同部分的方式，不声称已覆盖内核全部方面。

热度是怎么算的？了解榜单收起

热度看的是有多少账号和机构在讨论同一件事：同一家重复发只算一次，越近的讨论分量越重，每过 24 小时减半。它反映讨论有多热闹，不代表报道质量。

榜单只看过去 48 小时。走势只拿同一批一直在看的来源比较，反映的是我们看得到的范围，不代表全网人数；没有可比的历史时，不画走势线。

来源名单只列能公开阅读的报道；参与讨论的还有一些不在名单里展示的账号和机构。同一家机构在不同平台发帖合并算一家，所以参与者可能比来源还少。点进事件，可以看各方的报道和观点。
