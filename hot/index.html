Apache mod_http2竞态RCE已修复

Apache HTTP Server 的 mod_http2 竞态条件漏洞 CVE-2026-119618（CVSS 9.8）已由 Apache 修复；未认证攻击者可远程触发堆内存损坏并以 Web 服务器进程权限执行代码，但目前没有确认的在野利用。影响 Apache HTTP Server 2.4.55 至 2.4.70，以及独立版 mod_h2 2.0.8 至 2.0.42，且仅限启用 HTTP/2 的服务器；HTTP/2 默认关闭，仅提供 HTTP/1.1 的服务器不受影响。 漏洞源于 assign_headers() 函数对共享资源同步不当；Praetorian 称已在默认配置下验证可靠利用，但跨环境稳定性仍需验证，其利用代码仍在内部开发。Wiz 则称发布博客时没有公开利用代码或在野利用报告。官方修复版本为 Apache HTTP Server 2.4.71；无法立即更新时可关闭 HTTP/2 临时缓解。

wfx-loot借GitHub令牌窃取CI凭据

Aikido Security发现并命名“wfx-loot”攻击：攻击者利用4,837个失陷GitHub账户的有效凭据，自11月10日起探测61,764个公共仓库的写权限，并通过篡改或新增GitHub Actions工作流植入窃密程序。研究人员确认至少1,835个目标的机密与云凭据已被窃取；Cybernews称恶意软件被推送至逾6.5万个仓库，但未列出具体密钥类型或仓库明细。 Aikido统计的1,835仅覆盖其检索的公共仓库默认分支，实际范围可能更高；SafeDep另统计8,093个公共仓库收到恶意提交，但不表示窃密程序均成功执行。已确认执行恶意代码的仓库中，工作流可访问的所有机密和云角色都应视为泄露并立即轮换；Aikido还称，安装或打开受影响Packagist包的机器，以及在受影响提交上运行过npm install的机器，也应视为被攻陷并轮换密钥。

    7-Zip LZX堆越界写入漏洞已复现

    奇安信CERT与微步在线研究响应中心均已复现7-Zip LZX解码器堆越界写入漏洞CVE-2026-125742，影响7-Zip 0<=version<26.06，CVSS 3.1评分为7.8；官方已发布补丁，需升级至7-Zip >= 26.06，目前暂无已知在野利用或确认受害规模。 利用需诱导用户解压特制多卷CAB归档，且后续卷声明的LZX窗口大小小于前序卷；解码器须保持历史状态（keepHistory=true）且_pos未在窗口边界正确重置。奇安信CERT称该条件可触发内存破坏及任意代码执行；微步称其在官方7-Zip 26.05的Linux arm64目标上执行PoC，通过堆越界写劫持控制流实现任意代码执行。 升级前应避免使用受影响版本的7-Zip解压不可信的多卷CAB归档，必要时仅在受控隔离环境中解压。

    SignDrop Windows 零日利用公开

    安全研究员 Abdelhamid Naceri（MSNightmare）公开了 Windows CLFS 驱动本地权限提升漏洞 SignDrop 的 PoC，称其可通过路径重定向和 .cnpf 伴生文件链式启动 SYSTEM shell，使标准用户获得 SYSTEM 权限；目前尚无已确认的在野利用，Microsoft 也未确认漏洞、分配 CVE 或发布修复。 公开利用链要求 CLFS 认证注册表模式为 0（强制）或 1（学习），且 Windows Defender 必须启用。Naceri 在 Windows 11 26H2、Windows 11 26H2 Experimental 和 Windows Server 2025 Experimental 上完成测试，并估计约 80% 的 Windows 安装可能受影响，但该利用不适用于所有机器。 目前唯一可行应对是等待 Microsoft 补丁；Naceri 警告，关闭 CLFS 缓解措施会暴露于利用内存破坏漏洞的攻击。

热度是怎么算的？了解榜单收起

热度看的是有多少账号和机构在讨论同一件事：同一家重复发只算一次，越近的讨论分量越重，每过 24 小时减半。它反映讨论有多热闹，不代表报道质量。

榜单只看过去 48 小时。走势只拿同一批一直在看的来源比较，反映的是我们看得到的范围，不代表全网人数；没有可比的历史时，不画走势线。

来源名单只列能公开阅读的报道；参与讨论的还有一些不在名单里展示的账号和机构。同一家机构在不同平台发帖合并算一家，所以参与者可能比来源还少。点进事件，可以看各方的报道和观点。
