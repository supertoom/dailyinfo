Signal默认限制AI读取聊天屏幕

Signal已发布并默认启用防护：在iOS 27上限制截图，在受支持的Android设备上检测到AI助手读取Signal屏幕时自动启用Screen Security，阻止Siri、Gemini等系统级AI代理抓取聊天；Signal未公布具体应用版本号。 Signal称该措施并不完整，无法阻止代理通过文件系统获取设备上已保存的应用内容，此前Android代理还曾滥用推送通知权限读取消息。用户可在设置中关闭截图限制，但会暴露自己及联系人的消息给相关代理。macOS 27目前没有同等保护，Signal建议将Signal加入“系统设置 > Siri”的Excluded Apps列表，阻止Siri AI主动读取消息。

Ghostscript沙箱逃逸漏洞已复现并修复

奇安信CERT已复现pwn.ai公开的Ghostscript沙箱绕过远程代码执行漏洞CVE-2026-125396，CVSS 4.0评分为8.5；受影响版本为Ghostscript 10.08.0之前版本。恶意PostScript/PDF在字体加载阶段利用use-after-free关闭-dSAFER检查，可使Ghostscript以低权限账户执行命令。 该漏洞虽被归类为本地漏洞，但打印任务、邮件和网页上传均可将恶意文件送入Ghostscript；所有在-dSAFER模式下处理不受信任PostScript/PDF的部署均受影响，pwn.ai称约十款常见应用的上传、预览或打印功能可能被诱导触发。 Artifex已于9月8日在Ghostscript 10.08.0中修复，并将易受攻击的内部步骤迁移至更安全代码。应用侧修复与Ghostscript修复覆盖同一利用链的不同环节，单独更新其一不能消除风险；目前没有发现该漏洞被用于攻击的报告。

FBI调查NCIC数据库疑似遭入侵

FBI正在调查其国家犯罪信息中心（NCIC）数据库疑似遭黑客入侵；该事件已由知情人士披露，但FBI尚未公开确认。事发时间、攻击者获取访问权限的方式、信息是否被窃取及受影响范围仍不清楚，执法记录和系统可用性是否受影响也未获确认。 NCIC向地方、州和联邦执法机构提供通缉、失踪人口、犯罪记录及被盗财物等信息。报道称，目前没有迹象表明该事件与ShinyHunters、此前针对FBI系统的入侵或相关服务中断有关。

    Cairn利用MONAI Label零日漏洞取得服务器权限

    Amazon Threat Intelligence 披露，疑似中国关联威胁行为者使用自主 AI Agent 平台 Cairn，攻击东亚地区中国大陆以外大学等机构使用的 MONAI Label 医疗影像标注工具；Cairn 发现并利用路径遍历零日漏洞 CVE-2026-133968，在一台大学服务器上取得 root 权限。漏洞允许无账户用户将文件写入服务器存储目录之外，影响默认未启用登录的 MONAI Label 0.8.5 及更早版本，能否取得 root 取决于部署方式及服务账户权限。 Amazon 称攻击约持续 48 小时，攻击者约 11 分钟便完成 API 梳理和漏洞利用；维护方已发布安全公告并合并修复，但尚无包含修复的可安装版本。Amazon 以中等置信度将该活动归因于中国关联行为者；受影响组织均为非 AWS 客户。

热度是怎么算的？了解榜单收起

热度看的是有多少账号和机构在讨论同一件事：同一家重复发只算一次，越近的讨论分量越重，每过 24 小时减半。它反映讨论有多热闹，不代表报道质量。

榜单只看过去 48 小时。走势只拿同一批一直在看的来源比较，反映的是我们看得到的范围，不代表全网人数；没有可比的历史时，不画走势线。

来源名单只列能公开阅读的报道；参与讨论的还有一些不在名单里展示的账号和机构。同一家机构在不同平台发帖合并算一家，所以参与者可能比来源还少。点进事件，可以看各方的报道和观点。
