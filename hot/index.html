Agent Framework 包投毒窃取凭据

攻击者劫持 Microsoft Agent Framework 的 PyPI 包 agent-framework 发布流程，投放恶意版本 1.26.1 和 1.26.2；两版本均已被 PyPI 隔离，1.26.0 仍是最新干净版本，但实际受害规模尚未确认。恶意包会在 site-packages 根目录写入 .pth 文件，即使未导入 Agent Framework，也会随 Python 解释器启动自动执行，收集环境变量、配置文件及 Azure、AWS、GitHub、Docker、Hugging Face、OpenAI 等凭据并发送至 webhook[.]site；1.26.2 还将窃取范围扩展至 GitHub Actions。 安装过任一恶意版本的环境应立即隔离，停止运行 Python 或 pip，从干净环境重建并改用 1.26.0，同时轮换受影响环境可访问的凭据。SafeDep 称账号 vibiret 对该包及五个相关项目拥有发布权限，但其参与恶意上传尚未证实，攻击者如何取得发布权限也不明。

    Apache Roller RCE漏洞已遭在野利用发酵中

    Apache Software Foundation（ASF）确认，Apache Roller 4.0.0至6.1.4的反序列化漏洞CVE-2026-129448（CVSS 9.8）已遭在野利用；该漏洞与CVE-2026-82384为同一问题。未认证远程攻击者可经XML-RPC端点反序列化不可信数据并执行任意代码，具体受害规模尚未披露。 ASF已发布安全更新，建议升级至Apache Roller 6.1.6或更高版本，该版本禁用扩展类型，并在关闭XML-RPC功能时拒绝相关请求。无法立即升级时，可将WEB-INF/web.xml中的“enabledForExtensions”设为“false”、移除“/roller-services/xmlrpc” servlet映射并重启Roller；仅在管理界面禁用XML-RPC无效，因为旧版本会在检查该设置前完成反序列化。

热度是怎么算的？了解榜单收起

热度看的是有多少账号和机构在讨论同一件事：同一家重复发只算一次，越近的讨论分量越重，每过 24 小时减半。它反映讨论有多热闹，不代表报道质量。

榜单只看过去 48 小时。走势只拿同一批一直在看的来源比较，反映的是我们看得到的范围，不代表全网人数；没有可比的历史时，不画走势线。

来源名单只列能公开阅读的报道；参与讨论的还有一些不在名单里展示的账号和机构。同一家机构在不同平台发帖合并算一家，所以参与者可能比来源还少。点进事件，可以看各方的报道和观点。
