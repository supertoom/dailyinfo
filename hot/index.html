Apache mod_http2竞态漏洞公开PoC

Apache HTTP Server 的 mod_http2 竞态条件漏洞 CVE-2026-119618（CVSS 9.8）已由奇安信 CERT、微步情报局和绿盟科技 CERT 复现；绿盟称拒绝服务 PoC 及漏洞细节已公开，Apache 表示尚无公开利用或在野攻击证据，官方补丁已经发布。漏洞源于 assign_headers() 对共享资源同步不当，可造成堆内存损坏、进程崩溃，并在特定条件下以 Web 服务器权限执行任意代码。 利用要求服务器加载 mod_http2、Protocols 配置包含 h2/h2c 且可网络访问，无需认证；h2c 明文连接同样受影响，仅提供 HTTP/1.1 的服务器不受影响。Apache HTTP Server 2.4.55 至 2.4.70、独立版 mod_h2 2.0.8 至 2.0.42 受影响；Apache HTTP Server 2.4.71、独立版 mod_h2 2.0.43 或更高版本已修复。无法立即更新时可关闭 HTTP/2 临时缓解。

wfx-loot借GitHub令牌窃取CI凭据

Aikido Security发现并命名“wfx-loot”攻击：攻击者利用4,837个失陷GitHub账户的有效令牌，自11月10日起向61,764个公共仓库提交探测Pull Request以测试写权限，并通过篡改或新增GitHub Actions工作流植入约1,500行凭据窃取脚本。研究人员确认至少1,835个目标发生凭据窃取；SafeDep另统计8,093个公共仓库收到恶意提交，但这不代表窃密程序均成功执行。 该攻击依赖被盗令牌，并非利用已披露的GitHub软件漏洞。在确认发生执行的仓库中，工作流可访问的机密和云角色都应视为泄露并立即轮换；Aikido还称，安装或打开受影响Packagist包的机器，以及在受影响提交上运行过npm install的机器，也应视为被攻陷并轮换密钥。Aikido的检索仅覆盖公共仓库默认分支，实际影响可能更高；报道未说明统一补丁、额外配置或重启要求。

    SignDrop Windows 提权 PoC 已公开

    安全研究员 Abdelhamid Naceri（MSNightmare、Chaotic Eclipse）公开了 Windows CLFS 驱动本地权限提升漏洞 SignDrop 的 PoC，可借路径重定向和 .cnpf 伴生文件链式启动 SYSTEM shell，使标准用户获得 SYSTEM 权限；目前尚无已确认的在野利用，Microsoft 尚未确认漏洞、分配 CVE 或发布修复，CISA 已知遭利用漏洞目录也未收录。 公开利用链要求 CLFS 认证注册表模式为 0（强制）或 1（学习），且 Windows Defender 必须启用。Naceri 在 Windows 11 26H2、Windows 11 26H2 Experimental 和 Windows Server 2025 Experimental 上完成测试，并估计约 80% 的 Windows 安装可能受影响，但该利用不适用于所有机器。关闭 CLFS 缓解措施会暴露于利用内存破坏漏洞的攻击，目前可行应对是等待 Microsoft 补丁。

热度是怎么算的？了解榜单收起

热度看的是有多少账号和机构在讨论同一件事：同一家重复发只算一次，越近的讨论分量越重，每过 24 小时减半。它反映讨论有多热闹，不代表报道质量。

榜单只看过去 48 小时。走势只拿同一批一直在看的来源比较，反映的是我们看得到的范围，不代表全网人数；没有可比的历史时，不画走势线。

来源名单只列能公开阅读的报道；参与讨论的还有一些不在名单里展示的账号和机构。同一家机构在不同平台发帖合并算一家，所以参与者可能比来源还少。点进事件，可以看各方的报道和观点。
