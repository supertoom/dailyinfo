    CERT-FR 发布法国能源与水务工业控制系统安全加固建议

    CERT-FR 面向法国能源与水务领域的生产商、集成商和安装商发布工业控制系统安全加固建议，指出管理接口暴露、未设认证或使用默认口令等风险。措施包括按源 IP 过滤连接、通过 VPN IPsec 或 VPN TLS 接入、替换默认凭据并启用多因素认证、及时安装补丁，以及使用持续维护且采用 TLS 或 SSH 的远程访问软件。
