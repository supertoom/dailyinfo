中文原文

Microsoft 正警告各组织，其遭遇了数据泄露：攻击者利用其 Entra Connect Health 服务中的漏洞，未经授权访问了管理员电子邮件地址和租户配置信息。

Microsoft Entra Connect Health 是一项云端监控服务，允许管理员通过 Microsoft Entra 管理中心监控其本地身份基础设施的运行状况、性能和警报。

根据昨天发送给管理员并在 Reddit 上分享的一则安全通知，Microsoft 于 2026 年 11 月 9 日发现了 Entra Connect Health API 中的漏洞，该漏洞最初于 7 月 23 日引入。

调查确定，该漏洞已被利用，未经授权的各方得以访问租户和服务监控元数据，并可能修改 Connect Health 监控配置。

Microsoft 在通知中表示：“2026 年 11 月 20 日，我们结束了调查，并确定与贵组织关联的租户级元数据曾遭到未经授权的只读访问。我们未发现任何未经授权的配置更改。”

该公司表示，暴露的信息包括：

  • 租户技术联系人和管理员账户所属的电子邮件地址。
  • 租户 ID、显示名称、初始域名、国家/地区代码和区域信息。
  • Microsoft Entra 许可层级和目录同步状态，包括是否启用了同步以及上次同步的时间戳。
  • Connect Health 注册状态。
  • 一张过期的证书，先前用于将 Connect Health 代理注册到 Microsoft 的一项内部服务；该服务已于 2024 年末停用。

Microsoft 表示，这张过期证书已不再使用，但仍保留在 Connect Health 存储中，并且仍会由 API 返回。

不过，该公司表示，该漏洞并未暴露用户密码、密码哈希、身份验证令牌、有效加密密钥、本地服务器和 Active Directory 拓扑详细信息，或 Azure 订阅信息。

Microsoft 于 11 月 19 日部署了服务器端修复，以防止进一步利用，并审查了可用的遥测数据，以识别影响客户的未经授权 API 调用。该公司于 11 月 20 日完成调查，并开始通知受影响的组织。

Microsoft 尚未披露有多少组织受到影响，但已有十多名管理员在这篇 Reddit 帖子中报告收到了该 通知。

一些托管服务提供商（MSP）也报告称收到了针对多个客户租户的通知，其中一名管理员表示这些邮件相隔数小时送达。

通知称，无需进行软件更新或其他客户补救措施即可解决该漏洞。

不过，Microsoft 建议组织提醒其安全团队注意潜在的目标式网络钓鱼和社会工程攻击；这些攻击可能以已暴露的管理员电子邮件地址和租户信息为目标。

组织还应确保特权账户使用抗网络钓鱼的多因素身份验证，审查其 Connect Health 配置，并检查 Microsoft Entra 审计日志和登录日志中是否存在可疑活动。

Microsoft 还在 https://aka.ms/ConnectHealth/scripts 发布了一个 PowerShell 脚本，使管理员能够查看可能被暴露的租户元数据类型。

然而，该脚本显示的是当前配置值，而不是入侵期间被访问的信息。

Microsoft 尚未披露是谁利用了该漏洞、有多少租户受到影响，以及攻击最早始于何时。

BleepingComputer 联系 Microsoft 时，Microsoft 确认已修复该漏洞，并通知了受影响的客户。

“我们发现并处理了一个影响 Microsoft Entra Connect Health 的安全问题，该问题可能导致未经授权访问租户级联系人和配置元数据。我们已于 2026 年 11 月 19 日部署修复，并通过 Azure Service Health 通知受影响的客户，同时提供指导和支持。”一位 Microsoft 发言人对 BleepingComputer 表示。
