攻击者利用假 OpenAI、SpaceX 和 Anthropic 活动窃取 Microsoft、Google 账户

Fake OpenAI, SpaceX events used to steal Microsoft, Google accounts

AI 导读

Push Security 披露，攻击者以 OpenAI、SpaceX 和 Anthropic 活动为诱饵，通过 Google、Zapier URL 缩短服务、GoTo Webinar 邮件及合法 Zoom 活动页分发链接，以免费 AI 服务和奖励诱导员工使用企业账户登录。

正文 · AI 翻译
中文原文

黑客正在利用伪造的 OpenAI、SpaceX 和 Anthropic 活动邀请，将员工引诱至网络钓鱼攻击中；他们使用两个不同的钓鱼即服务（PhaaS）平台，窃取 Microsoft 和 Google 账户凭据及身份验证会话。

根据 Push Security 的一份新报告，攻击者使用看起来很逼真的活动注册页面，提供高级 AI 服务及其他奖励的免费访问权限，诱骗受害者使用企业账户登录。

这些攻击引人关注之处在于，同一 phishing 页面集成了两个独立的钓鱼即服务（PhaaS）平台 Kali365 和 VoidProxy，通过不同的身份验证攻击针对 Microsoft 和 Google 账户。

Kali365 发起 Microsoft 设备代码钓鱼攻击，而 VoidProxy 则充当中间人（AiTM）反向代理，拦截 Google 登录并窃取身份验证会话 Cookie。

Microsoft 攻击还将 VoidProxy 作为第二阶段使用，使攻击者在通过 Kali365 获取身份验证令牌后，还能捕获凭据和会话 Cookie。

Push Security 表示，其在 2026 年 10 月下旬检测到并拦截了对恶意活动注册页面的访问。

此次活动之前，已有类似活动被 ANY.RUN 记录在案；7 月，攻击者滥用合法的 Zoom 活动页面推广伪造的 Meta、OpenAI 和 Anthropic 活动，最终引发设备代码钓鱼和 AiTM 钓鱼攻击。

Cofense 还近日报道了冒充 Anthropic 活动邀请的钓鱼邮件；这些邮件通过 GoTo Webinar 的邮件基础设施发送，并将收件人重定向至多个网站，最终到达伪造的注册页面。

虚假 AI 活动导致账户钓鱼

目前尚不清楚攻击者最初如何分发钓鱼链接，但 Push Security 发现，他们使用来自可信服务的链接（包括 Google 和 Zapier 的 URL 短链接）将受害者重定向至恶意活动注册页面。

早期版本的活动中，邀请邮件还通过 GoTo Webinar 的邮件系统或合法的 Zoom 活动页面分发。

Push Security 表示，攻击者使用两个自定义钓鱼工具包（分别追踪为 ZoomMock 和 MSDRoot）创建虚假活动页面，再将受害者引导至 Kali365 和 VoidProxy 钓鱼服务。

研究人员认为，这两个工具包由同一批威胁行动者运营，因为它们使用共享的基础设施和相同的攻击目标。

此次活动冒充由 OpenAI、SpaceX 和 Anthropic 举办的活动，注册页面则被设计成类似合法活动网站。

其中一个钓鱼页面宣传一项名为“ChatGPT for Social & Digital Marketing Teams”的 OpenAI 活动，承诺向参与者提供三个月的 ChatGPT Pro。

另一个页面宣传 11 月 12 日举办的一场 SpaceX 私人活动，向注册者提供三个月的 Grok Heavy 或一份“SpaceX 股份”。

研究人员还发现了一个冒充 AWS re:Invent 2026 上 Anthropic 活动的钓鱼页面，目前该页面已被下架。

这些伪造注册页面告诉访问者，必须使用工作账户登录才能注册并领取所宣传的奖励。

在显示伪造注册页面前，这些网站会展示一个 Cloudflare CAPTCHA，要求用户“确认您不是机器人”。这可阻止自动化安全平台扫描钓鱼网站。

当访问者到达活动注册页面时，会看到两个选项：“Continue with Microsoft”和“Continue with Google”。

当受害者选择 Microsoft 选项时，钓鱼页面会联系 Kali365 平台，生成 Microsoft 设备身份验证代码。

设备代码钓鱼攻击是指攻击者滥用合法的 OAuth 2.0 设备授权流程，获取受害者 Microsoft Entra 账户的身份验证令牌。

随后，攻击者可以利用这些令牌访问用户的资源和已连接的 SSO 应用，例如 Microsoft 365、Salesforce、Google Workspace、Dropbox、Adobe、SAP、Slack、Zendesk、Atlassian 等众多应用。

过去，设备代码钓鱼攻击曾被用于数据窃取和网络间谍攻击。

访问者会被指示复制该代码，并在 Microsoft 的合法设备登录网站上输入代码，随后进行身份验证并批准请求。

这使 Kali365 钓鱼平台无需受害者直接披露密码，即可窃取 Microsoft 身份验证令牌。

设备代码身份验证成功后，页面会将受害者重定向至 VoidProxy Microsoft 登录页面，攻击者还可以在那里截获受害者的密码和会话 Cookie。

当受害者选择 Google 身份验证选项时，钓鱼页面会改为打开一个弹出窗口，其中包含 VoidProxy PhaaS 提供的 Google 登录页面。

该平台充当位于受害者浏览器与 Google 登录页面之间的中间人（AiTM）平台，代理登录表单，并窃取凭据、MFA 响应和会话 Cookie。

Kali365 和 VoidProxy 平台都允许攻击者通过截获已经完成身份验证的会话来绕过多重身份验证；在设备代码身份验证的情况下，则可完全绕过 MFA。

为防范这些攻击，员工应避免在不熟悉的网站上输入 Microsoft 设备身份验证代码，并对要求使用企业账户登录以领取奖励的活动邀请保持警惕。

组织还可以限制不需要使用设备代码身份验证的场景，并采用具备抗钓鱼能力的 MFA（例如 FIDO2 安全密钥），以帮助防止会话劫持。
