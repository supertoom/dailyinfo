Iran-Aligned Volant Manticore Uses IPFS-Based KuboShell Backdoor in Espionage Campaigns

AI 导读

Iran 关联组织 Volant Manticore 被指自 2025 年 8 月末起针对塞浦路斯电信公司、航空公司和关键基础设施开展间谍活动，并通过虚假简历投递 KuboShell 后端、收集邮箱与企业凭据。

正文 · 原文

A previously undocumented Iran-aligned cyber espionage group called Volant Manticore has targeted telecommunications companies, airlines, and critical infrastructure in Cyprus.

Central to the group's operations is a backdoor called KuboShell that uses the InterPlanetary File System (IPFS) for command-and-control (C2) and deploys Homa, a post-compromise framework that's a reimplementation of MuddyWater's MuddyC2Go. Evidence indicates that the threat actor has been operational since late August 2025.

Also delivered alongside these tools are Remote Monitoring and Management (RMM) programs like MeshCentral and NetLock RMM. In tandem, the group has been observed orchestrating credential harvesting campaigns to harvest email and corporate credentials of some of the impersonated organizations.

The use of legitimate RMM tools for persistent access has been a hallmark of the MuddyWater group, although the adversary has since also increasingly deployed its own malware in attacks. Both MuddyWater and Volant Manticore are assessed to be affiliated with Iran's Ministry of Intelligence and Security (MOIS).

"While we identified multiple links to MuddyWater, we assess that Volant Manticore likely consists of former MuddyWater operators who branched off from the group and currently operate as a separate threat cluster," Check Point said in an analysis published today. "Volant Manticore's targeting priorities appear responsive to regional geopolitical developments."

This assessment is based on the use of an older MuddyWater framework and its playbook, while diverging from established modus operandi over time to incorporate its own attack methods like credential-harvesting campaigns. The targeting of Cyprus, a country that does not align with MuddyWater's targeting patterns, and the use of separate infrastructure points to a group that pursues its own strategic objectives.

Attack chains have been found to leverage artificial intelligence (AI)-generated personas in bogus CVs to trick targets into clicking on a link to download the complete resume, resulting in the deployment of KuboShell on the victim's system. The activity is said to have been aimed at a Cyprus-based airline that operates flights between Cyprus and Israel.

This includes a shift toward Saudi Arabian healthcare entities, coinciding with escalating hostilities between Saudi Arabia and the Iranian-backed Houthis.

"This fits the MOIS's track record of targeting hospitals and healthcare providers through cyber operations during military conflicts, in some cases attempting to disrupt their operations," the cybersecurity company said.

As recently as September 2026, the group has been found to launch a phishing campaign against Saudi targets, distributing the backdoor and N-able RMM through two different healthcare-themed ZIP archives named "AI_Healthcare_Seminar.zip" and "Ai_Healthcare_Seminar_Online.zip," respectively. Some of the emails have been sent from a compromised account belonging to a private hospital in Saudi Arabia.

A Windows backdoor, KuboShell, uses IPFS for C2 and relies on Pinata to facilitate file transfer over the peer-to-peer (P2P) file-sharing network.

"On startup, KuboShell checks whether it has administrator privileges. If not, it tries to relaunch itself with higher privileges, which triggers a User Account Control (UAC) prompt," Check Point explained.

"KuboShell retrieves the MAC address of the machine's first network adapter and uses it as a unique identifier for each victim. It then registers the host by uploading a file containing hi, saved to C:\Users\Public\<MAC>.log, using a hard-coded Pinata access token."

Once registered, KuboShell checks Pinata for a command file named <MAC>.txt, and if the file exists, looks up the file’s IPFS identifier and downloads its contents through Pinata's public gateway. The downloaded content is executed via PowerShell in a hidden window. The results of the execution are saved in a file named "C:\Users\Public\<MAC>re.txt" and uploaded back to the server.

It's worth noting that the backdoor is not responsible for capturing the output. Rather, the results are returned only if the received command writes them to the text file. KuboShell then checks for a new command every 60 seconds.

Analysis indicates that KuboShell is primarily used to run basic reconnaissance commands and assess the compromised environment before downloading and executing a more capable backdoor, which includes the modular Homa Framework. This involves a three-stage process -

  • PowerShell stager, which contacts a hard-coded IP address ("185.205.187[.]109:8000") to fetch a PowerShell loader and execute it in memory
  • PowerShell loader, which decodes and launches a JavaScript backdoor
  • JavaScript Backdoor, which implements a continuous C2 loop to receive and execute PowerShell, SSH, and "cmd.exe" commands

It's suspected that the third-stage backdoor is used to execute additional modules, although the precise nature of those components is presently unknown.

"We assess that Homa's client is a JavaScript reimplementation of the older MuddyC2Go client, potentially allowing Volant Manticore to retain the more complex server-side component with minimal modifications, thereby reducing development time and resources," Check Point said.

The post-compromise framework has also been distributed via a macro-enabled Microsoft Word document called "MilitaryHeritageProposal.doc" that's believed to have targeted a Cypriot defense-related government entity. Enabling the content triggers the execution of a VBA backdoor that serves as a conduit for running follow-up payloads or commands using "cmd.exe."

"Volant Manticore shows how Iran's cyber ecosystem continues to reshape itself," Check Point concluded. "What appears to be a group of former MuddyWater operators now operates independently, pairing legacy MuddyWater tooling with new implants of their own while pursuing a regional focus that has until now drawn little attention."

"If MuddyC2Go is the latest MuddyWater framework Volant Manticore's operators had access to, the split may have happened around 2023 as MuddyWater replaced MuddyC2Go with DarkBeatC2 in late 2023.
