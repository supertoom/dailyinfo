漏洞详情

>>>>

影响组件

Vite 是一款基于原生 ES 模块的下一代前端构建工具，专为现代 Web 应用开发设计。它提供极速的冷启动、热模块替换（HMR）以及高效的生产构建能力，广泛应用于 Vue、React、Svelte 等框架项目中。Vite 通过开发服务器实现实时编译与资源服务，并支持丰富的插件生态与配置选项，显著提升开发体验与构建效率。作为前端工程化的核心工具之一，Vite 被全球大量开发者和企业采用。

>>>>

漏洞描述

近日，奇安信CERT监测到官方修复Vite 远程代码执行漏洞(QVD-2026-112681)，该漏洞源于 Vite 解析器插件中的虚拟模块 __vite-browser-external:<suffix> 和 __vite-optional-peer-dep:<suffix> 在嵌入来自 URL 的模块 ID 时未进行转义处理，导致攻击者可通过构造特殊请求注入任意代码。注入的代码可绕过 server.fs 文件访问限制读取任意文件，并利用 Vite 对 new Worker 和 import.meta.glob 使用 eval 提取值的机制，在服务器端执行任意代码（可通过 globalThis.process.getBuiltinModule 等绕过部分限制）。攻击者只需向暴露的开发服务器发送恶意 HTTP 请求即可实现任意文件读取或远程代码执行，严重威胁开发环境的机密性与完整性。目前该漏洞PoC和技术细节已公开。鉴于该漏洞影响范围较大，建议客户尽快做好自查及防护。

>>>>

利用条件

1.开发服务器通过 --host 命令行参数或 server.host 配置项显式暴露到网络（非默认 localhost）。

2.攻击者能够访问该开发服务器的网络端口并发送 HTTP 请求。

处置建议

>>>>

安全更新

官方已发布安全补丁，请及时更新至最新版本：

Vite >= 8.3.7

Vite >= 8.2.5

Vite >= 8.1.7

Vite >= 7.3.8

Vite >= 6.4.6

vite-plus >= 1.5.1

对于 Vite 8 系列，修复依赖 Rolldown 对应版本（8.3.7/8.2.5 依赖 Rolldown 1.2.17；8.1.7 依赖 1.1.7）。升级后请重新安装依赖并验证版本。

下载地址：

https://github.com/vitejs/vite/releases

临时缓解措施：

1.在无法立即升级的情况下，避免将 Vite 开发服务器暴露到网络：移除 --host 参数，或将 server.host 设置为 127.0.0.1/localhost，仅允许本地访问。

2.若确需远程访问开发服务器，应通过防火墙、反向代理或 VPN 限制访问来源 IP，仅允许可信网络访问，避免将开发端口直接暴露于公网。
