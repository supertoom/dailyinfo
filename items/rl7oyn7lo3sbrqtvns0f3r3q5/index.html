CVE-2026-111497 : Vulnérabilité dans Google Brotli

Le 21 octobre 2026, Node.js a publié un avis de sécurité concernant la vulnérabilité critique CVE-2026-111497 affectant Brotli. Cette vulnérabilité surnommée Broccoli2shell, permet à un attaquant non authentifié de provoquer une exécution de code arbitraire à distance.

Brotli est une bibliothèque libre de compression utilisée par de nombreux éditeurs tels que Microsoft, Palo Alto Networks, Python Software Foundation, VMware, Cisco, Splunk et Mitel. Node.js, Microsoft, Palo Alto Networks et Python Software Foundation ont mis à disposition des correctifs de sécurité. Les autres éditeurs procèdent actuellement à une analyse de leurs produits afin d’identifier ceux qui pourraient être concernés par cette vulnérabilité.

Liens :

  • https://nodejs.org/en/blog/vulnerability/october-2026-security-releases#nodejs-brotli-decoder-out-of-bounds-write-permits-remote-code-execution-cve-2026-111497---high

Rappel des alertes CERT-FR

[Màj] Multiples vulnérabilités dans PHP

Le 23 octobre 2026, PHP a publié un avis de sécurité concernant la vulnérabilité CVE-2026-115560. Celle-ci permet une exécution de code arbitraire à distance. L'éditeur estime que les conditions d'exploitation exigent une combinaison d'options de configuration et de code applicatif peu probable. Un correctif sera donc publié à l'occasion du prochain cycle de mises à jour.

Le CERT-FR constate des tentatives d'exploitation des vulnérabilités CVE-2026-109618 et CVE-2026-109619 ciblant des déploiements spécifiques de PHP.

De plus, le CERT-FR incite à la vigilance et rappelle que le langage PHP est utilisé dans de nombreux produits, il est donc important d'appliquer les correctifs dès que ceux-ci seront disponibles. En effet, de nombreux produits sont potentiellement impactés par cette vulnérabilité. On trouvera une liste non exhaustive de cette dernière fournie par le NCSC-NL.

Liens :

  • https://github.com/NCSC-NL/php2shell/blob/main/software/changelog_software_list.md
  • CVE-2026-115560

Incidents

Comprimission des certificats TLS intermédiaires d'eMudhra

Le 20 octobre 2026, Mozilla a publié un billet de blogue annonçant que les clés privées associées à huit certificats TLS intermédiaires eMudhra ont été compromises. eMudhra a identifié la cause de l'incident de sécurité, les clés privées des certificats ont été générées avec une taille faible.

En réponse à cet incident, certains éditeurs ont supprimé ces certificats de l'autorité eMudhra de la liste des certificats préinstallés ou les ont désactivés.

Liens

  • https://emudhra.com/en/post/certificate-security-incident
  • https://blog.mozilla.org/security/2026/10/20/protecting-firefox-users-following-the-compromise-of-emudhra-intermediate-certificates/
  • https://www.microsoft.com/en-us/msrc/blog/2026/10/microsoft-response-to-compromised-emudhra-certificate-authority-keys
