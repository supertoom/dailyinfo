Ravie Lakshmanan2026年11月26日工业控制系统 / 漏洞

美国网络安全和基础设施安全局（CISA）于周三将10个安全缺陷加入其已知被利用漏洞（KEV）目录，其中包括上周披露的5个影响 Mitel MiCollab 的漏洞。

Mitel MiCollab 漏洞列于下方——

  • CVE-2026-133275（CVSS 分数：5.3）——MiCollab 的音频、网络和视频会议（AWV）组件中存在任意文件上传漏洞，可能允许攻击者向目标系统上传任意文件。
  • CVE-2026-133303（CVSS 分数：9.0）——MiCollab 的音频、网络和视频会议（AWV）组件中存在 XML 注入漏洞，可能允许攻击者在系统上下文中执行任意命令。
  • CVE-2026-133311（CVSS 分数：5.9）——MiCollab 的音频、网络和视频会议（AWV）组件中存在未授权访问漏洞，可能允许攻击者获取敏感信息。
  • CVE-2026-133323（CVSS 分数：10.0）——MiCollab 的音频、网络和视频会议（AWV）组件中存在命令注入漏洞，可能允许攻击者在系统上下文中执行任意命令。
  • CVE-2026-133324（CVSS 分数：5.3）——MiCollab 的音频、网络和视频会议（AWV）组件中存在身份验证绕过漏洞，可能允许攻击者绕过身份验证控制，并在应用程序上下文中执行未授权操作。

这些问题影响 MiCollab 10.3 及更早版本。该公司在 2026 年 11 月 16 日发布的一份公告中表示：“Mitel 为 10.3 版本（10.3.0.18）提供了可用补丁，用于修复这些漏洞。升级到此版本并应用所提供的补丁，或升级到更晚的版本。”

建议无法应用更新的客户通过限制对 AWV 组件的外部访问来降低风险。截至撰写时，目前尚无关于这些漏洞如何在野外的被利用情况的详细信息。

加入 KEV 目录的还有以下漏洞——

  • CVE-2026-133469（CVSS 分数：9.8）——Vates Xen Orchestra 中存在指定输入类型验证不当漏洞，可能允许未经身份验证的攻击者通过包含空 JSON 对象的特制身份验证令牌绕过身份验证，并以管理员权限执行操作。
  • CVE-2026-103406（CVSS 分数：9.8）——Hewlett Packard Enterprise（HPE）Juniper Session Smart Conductor 和 Session Smart Router 中存在操作系统命令注入漏洞，可能允许远程攻击者通过特制的 salt minion ID 以 root 权限执行任意命令。

CVE-2026-133469 的加入源于 Vates VMS 发布的一份公告，该公告称这一也被跟踪为 VSA-2026-062 的漏洞已被来自以下 IP 地址和 TOR 域名的威胁行为者利用——

  • 91.211.251[.]112:8001
  • ustar3rqxgnskzgnwkgpofgtvxevm6cx3lxdbwt4mndtveqyaohid[.]onion:3333

“Juniper Networks 表示，Juniper SIRT 已收到至少一起恶意利用 CVE-2026-103406 的报告，”“敦促客户尽快升级至已修复版本，并在此期间采取措施缓解此漏洞。”

其余三项安全漏洞涉及 Danfoss AK-SM 800A 系列制冷控制器，可能导致身份验证绕过和任意命令执行——

  • CVE-2023-25914（CVSS 分数：8.8）——一项路径遍历漏洞，可能允许攻击者通过 XML 接口访问并读取底层服务器系统文件。
  • CVE-2023-25915（CVSS 分数：9.9）——一项不当输入验证漏洞，可能允许远程攻击者在受影响系统上运行任意命令。
  • CVE-2025-41450（CVSS 分数：8.5）——一项不当身份验证漏洞，可能允许攻击者生成暴露敏感信息的 Web 报告，其中包括内部 IP 地址、用户名和门店名称。

尽管 Danfoss 未提及这些漏洞已被利用，但它们很可能已在最近几周针对欧洲超市连锁店的高影响攻击中被使用。法国将其零售网站于 2026 年 10 月遭受的攻击归咎于 Shahid Kaveh（又称 Cyber Aveng3rs 和 Cyber Isnaad Front），这是隶属于伊斯兰革命卫队（IRGC）的一个伊朗网络单位。

鉴于这些漏洞正在被积极利用，联邦文职行政部门（FCEB）机构被建议在 2026 年 11 月 28 日前为除 CVE-2026-133311 和 CVE-2025-41450 之外的所有漏洞应用必要的修复。剩余两项漏洞必须在 2026 年 12 月 9 日前解决。

CISA 警告 Danfoss AK-SM 8xxA 系列存在尚未修补的新漏洞

与此同时，CISA 已警告 Danfoss AK-SM 8xxA 系列（CVE-2026-129713，CVSS 分数：9.8 / 9.3）控制器存在一项尚未修补的严重漏洞，该漏洞可能被利用来以 Web 服务器权限执行任意代码。

CISA 表示：“Danfoss AK-SM 8xxA 系列控制器中未经身份验证的 CGI 处理程序存在基于栈的缓冲区溢出，远程攻击者可通过发送 specially crafted HTTP/S POST 请求发起攻击，从而导致内存损坏、Web 服务器重启，并可能导致以 Web 服务器权限执行任意代码。利用此漏洞无需身份验证。”

Danfoss 已发布自己的警报，并表示该安全漏洞影响 5.4.0 及更早版本。该漏洞的修复预计将在即将推出的软件版本（5.5.x）中提供。该公司还表示，将移除允许客户禁用产品中“Strict mode”的选项。

在修复可用之前，建议系统管理员采取以下措施——

  • 确保只能通过安全 VPN 或通常情况下通过受保护网络远程访问这些设备
  • 将设备配置为 Strict mode，以确保产品具有更高的安全级别
  • 建议使用强密码

CISA 还建议各组织尽量减少此类设备在网络中的暴露，将控制系统网络和远程设备置于防火墙之后，并将其与业务网络隔离。

“需要远程访问时，请使用更安全的方法，例如虚拟专用网络（VPN），同时也要认识到 VPN 可能存在漏洞，应更新至可获得的最新版本。”CISA 补充道。“还要认识到，VPN 的安全性取决于所连接设备的安全性。”
