中文原文

易受攻击的 Check Point Security Gateway 实例已成为 PHP2Shell 攻击的目标，这些攻击在 VMware ESXi 主机上部署了数据擦除恶意软件。

攻击始于 10 月 30 日，最初针对以色列组织，由一个从头到尾执行整个活动的攻击者实施，涵盖初始访问、横向移动以及启动 PHP webshell。

在某些情况下，研究人员发现破坏阶段出现了政治性信息，引发了有关这是否是一次虚假旗帜行动的疑问。

PHP2Shell 是两个严重 PHP 漏洞的名称，漏洞编号分别为 CVE-2026-109618 和 CVE-2026-109619，可导致易受攻击系统上的未认证远程代码执行。

PHP 于 10 月 21 日通过紧急补丁修复了这些漏洞。然而，据 Amazon Threat Intelligence 称，利用尝试早在四天前就已开始。

CISA 于 10 月 26 日将这两个问题均加入其已知被利用漏洞（KEV）目录，随后警告称攻击者正在串联利用PHP2Shell 漏洞与 Fragnesia Linux 内核漏洞，以获取 root 权限。

网络安全公司 Check Point 表示，第一轮利用攻击针对以色列组织，而 11 月 2 日的第二轮攻击则影响了多个国家和行业的公司。

攻击者利用 PHP2Shell 通过网关的 Mobile Access 门户获取访问权限，随后利用一个编号为 CVE-2026-123039 的新披露零日漏洞获取 root 权限。

接着，他们滥用这些权限安装 PHP webshell 和 TSGA 后门；该后门嵌入了名为 TSProxy 的网络组件，用于在常规流量中隐藏并监听攻击者命令。

在针对以色列组织的攻击中，威胁行为者从网关转移至使用 gogo scanner 这一开源网络侦察工具定位的 VMware ESXi 主机。

在攻击的最后阶段，威胁行为者部署了一款名为 destroy_v6 的数据擦除工具，该工具会递归删除目标目录中的数据。

该擦除工具首先尝试进行零填充，以使恢复更加困难。它还支持一种快速模式，可跳过覆盖步骤。

Check Point 还发现，攻击者在 ESXi 主机上留下了一个名为 DREAM_ANNEXATION.txt 的文件，其中提到了“Dream Security Ltd.”。

该文件包含政治性信息，并明确拒绝就赎金支付进行谈判，表明攻击者的唯一目标是造成破坏和中断。

Check Point 谨慎地将 TSGA 和 TSProxy 与 PhiliKit 联系起来；PhiliKit 是一个此前曾出现在针对 Ivanti 设备攻击中的恶意软件框架，ESET 将其关联至中国威胁组织 UNC5221。

然而，根据现有证据，无法有把握地将这些攻击归因于该组织。

据研究人员称，第二轮攻击未包含破坏活动，但威胁行为者后续采取的行动仍不清楚。

Check Point 建议客户在所有 Management Servers 和 Security Gateways 上安装 11 月 Jumbo Hotfix，并优先处理那些暴露在互联网中的 Mobile Access 门户。

此次更新修复了 PHP2Shell 以及攻击中用于权限提升的 DynamicCLI 漏洞。

管理员还应检查此前暴露的网关上是否存在入侵迹象，包括包含 upload_progress_pwn 的会话文件、意外的 CPconfigdaemon 进程或二进制文件，以及防火墙日志中无法解释的记录缺失。

来自网关、指向内部 VMware ESXi 主机的未授权 SSH 活动也是明确的入侵迹象。
