01

漏洞详情

>>>>

影响组件

WordPress 是全球最广泛使用的开源内容管理系统（CMS），基于 PHP 和 MySQL/MariaDB 构建，提供文章发布、页面管理、媒体库、插件扩展与主题换肤等完整建站能力。它既可通过 WordPress.org 官方托管服务使用，也可免费下载自建于各类 Web 服务器环境，凭借丰富的生态和易用性成为个人博客、企业官网、新闻媒体及电商平台的主流选择，目前为全球约 43% 的网站提供底层支撑。

>>>>

漏洞描述

近日，奇安信CERT监测到WordPress Core 竞争条件远程代码执行漏洞(CVE-2026-119977)在野利用。该漏洞源于完整包核心升级过程中，升级程序将更新包解压至 wp-content/upgrade/ 下基于包名生成的可预测、Web 可访问临时目录（相关代码位于 class-wp-upgrader.php、class-core-upgrader.php、update-core.php 等）。临时目录包含安装程序 setup-config.php，且在升级窗口期间可被外部 HTTP 请求直接执行。攻击者可利用该漏洞，在升级窗口内通过竞争条件注入恶意配置，最终实现任意代码执行，导致服务器完全沦陷。目前该漏洞PoC和技术细节已公开。鉴于该漏洞已发现在野利用，建议客户尽快做好自查及防护。

>>>>

利用条件

1.正在执行完整包核心更新；

2.暂存目录可公开访问；

3.暂存路径可预测。

临时缓解措施：

1.在升级前通过 Web 服务器配置（.htaccess、Nginx 规则等）拒绝对 /wp-content/upgrade/ 的 HTTP 访问。

2.使用 WAF /防火墙拦截对 setup-config.php 及 wp-content/upgrade 路径的异常请求。
