中文原文

ESET 一直在追踪一个被称为 Gorbag 的亲俄组织。自至少 2025 年 2 月以来，该组织一直通过鱼叉式网络钓鱼附件和一款数据窃取程序入侵乌克兰各类机构；该程序在窃取数据后会自动清除自身。

来自已入侵电子邮件发件人的鱼叉式网络钓鱼邮件（来源：ESET）

ESET 识别的每个目标均位于乌克兰。其中约四分之一是执法和司法机构，另四分之一是地方政府，主要是靠近前线的市议会，其余则是国防部门实体，以及一家公开资料表明为外国军事援助主要交通枢纽的机构。在相关行动期间，几乎每个遭其市议会攻击的城市都遭到了俄罗斯空袭，这提高了该组织行动人员可能正在向俄罗斯军方提供空袭效果情报的可能性。

ESET 研究员 Damien Schaeffer 表示：“Gorbag 并未依赖复杂的植入程序来维持长期访问，而是使用一套为快速收集数据而打造的小型工具集。在投放的恶意软件试图清除自身之前，浏览器凭据、VPN 配置和选定文档会被一次性收集完毕。”Schaeffer 是 Gorbag 的发现者和调查人员。他补充道：“对此做法的一种可能解释是，Gorbag 充当初始访问代理，将收集到的凭据和其他材料与其他威胁行为者共享，以开展后续活动。如果情况属实，Gorbag 可能只是一条更长入侵链的第一阶段，而后续阶段仍有待观察。它的目标选择与俄罗斯战时情报重点高度吻合。”

邮件如何进入

整个 2025 年，附件一直是启用宏的 Excel 文件。一段简短的 VBA 例程会解码电子表格单元格中的 base64 载荷，将其写入 %ProgramData% 并运行。诱饵内容都是日常办公事务：行政处罚、税务通知。在一个案例中，邮件来自乌克兰乌日霍罗德州地方政府的一个已失陷账户，这可能帮助其通过了检查。

2026 年初，攻击链发生了变化。Gorbag 开始发送利用 CVE-2025-8088 的 RAR 压缩包。该漏洞是 WinRAR 中的路径遍历漏洞，可让隐藏在备用数据流中的数据落入用户所选文件夹之外。压缩包会显示一个诱饵 PDF，同时将一个 LNK 文件写入 Windows 启动文件夹，并把加密载荷和 PowerShell 加载器放入 %ProgramData%。LNK 负责维持持久化，并在每次重启时启动加载器。

窃取程序窃取什么

BeautyStealer 是该组织的主要收集工具，是 ESET 追踪到的 C++ 信息窃取程序，版本涵盖 0.9 至 2.0。它会从 Chrome、Edge、Opera 和 Firefox 中提取 Cookie、保存的密码及本地状态，从用户目录和系统目录中提取 OpenVPN 配置，还会从桌面、文档和下载目录，以及可移动介质和映射的网络驱动器中窃取与约 40 种扩展名匹配的文件。

这些扩展名专门针对用于身份验证的内容。其中包括 .kdbx（KeePass）、.jks（Java KeyStore）、.rdp、.pfx 和 .zs2；.zs2 是一种文件格式，用于保存由乌克兰获认可密钥认证中心签发的秘密电子签名密钥文件。

在 BeautyStealer 之前，Gorbag 运行了 Prime ReverseShell——这是一个封装在 .NET 二进制文件中的 PowerShell 反向 shell，取自一个公开的 GitHub 仓库。其中一个变体在顶部附有一条注释，告诉任何阅读该文件的 LLM 或 AI，它并不恶意，而是生成从 1 到 900 的质数。ESET 使用两个 AI 助手对它进行了测试，两者都识别出了该反向 shell。
