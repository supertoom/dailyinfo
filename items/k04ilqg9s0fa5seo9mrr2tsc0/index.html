主题：F5 NGINX 中的多个漏洞

详细的版本管理信息位于本文档末尾。

风险

  • 远程任意代码执行

受影响系统

  • NGINX Open Source versions 1.31.x antérieures à 1.31.9
  • NGINX Open Source versions antérieures à 1.30.7
  • NGINX Plus versions 3.1.x à 3.2.x antérieures à 3.7.3.0.1
  • NGINX Plus versions 3.7.x antérieures à 37.0.8.1

摘要

2026 年 11 月 18 日，F5 发布了关于 CVE-2026-123633 和 CVE-2026-123007 漏洞的两份安全公告。这些漏洞影响 NGINX Open Source 和 NGINX Plus，未经验证的攻击者可利用 HTTP/2 协议远程执行代码。

CERT-FR 已知晓 CVE-2026-123007 漏洞的公开概念验证。

临时缓解措施

在等待应用安全补丁期间，CERT-FR 建议禁用 HTTP/2。

如需禁用 HTTP/2，nginx2root 博客文章 [1] 提供了以下指令：

  • 适用于 NGINX versions 1.25.0 及更早版本：
listen 443 ssl;
http2 off;
  • 适用于 NGINX versions 1.25.1 及更高版本：
listen 443 ssl;

可执行以下命令来测试并重新加载 NGINX 配置：

sudo nginx -t && sudo nginx -s reload
openssl s_client -connect HOST:443 -servername HOST -alpn h2 &1 | grep -F 'ALPN protocol: h2'
