N-able、Windows、Chrome 等多起漏洞与安全事件汇总

⚡ Weekly Recap: N-able 0-Days, Windows 0-Days, Chrome 0-Days, Fridge 0-Days, and More Bad Days

AI 导读

本周汇总多起零日漏洞、供应链入侵及数据合规事件。N-able 漏洞已被利用，攻击者在 7 个国家 compromising 21 台 N-central 服务器并部署加密货币矿工，厂商预计当日发布补丁；Chrome CVE-2026-125350（CVSS 8.8）遭在野利用，Google 已为 Windows、macOS 和 Linux 发布更新。

正文 · 原文

A default password opened doors it never should have. A trusted update delivered malware. Even a security feature became a way to break in. Different stories, same problem: the things meant to protect us aren't always doing their job.

Meanwhile, AI is making bug hunting faster, old flaws are still paying off, and attackers keep finding easy ways in. Some attacks take real skill. Others barely need any. 

This week's stories show both sides. Here's what happened.

⚡ Threat of the Week

N-able 0-Days Exploited for Dropping Crypto Miners — A new set of vulnerabilities tracked as 4EverAble2Shell has come under active exploitation, with attackers exploiting it to deploy cryptocurrency miners on vulnerable servers. According to Huntback, the activity has successfully compromised 21 N-central servers across the U.S., South Africa, Canada, the U.K., Germany, France, and Sweden. Patches for the flaw are expected to be released N-able today.

🔔 Top News

  • Compromised bee-js and Swarm Desktop Steal Swarm Wallet Keys — Threat actors compromised @ethersphere/bee-js, the JavaScript client for the Swarm storage network, with a new postinstall hook in version 13.3.0 that downloads a second stage responsible for stealing the Swarm node's wallet key and installing a backdoor. "On Linux and macOS, the backdoor is a Go remote shell," SafeDep said. "On Windows, it is a hidden ScreenConnect client that runs as SYSTEM." The same malicious code was subsequently distributed via Swarm Desktop 0.56.2 on GitHub. The activity has since been linked to a campaign called SleepyDuck (EtherDuck), which is known to spread malicious Solidity extensions through Open VSX. "The attacker controlled two Ethersphere GitHub accounts. GitHub activity logs attribute 13 pushes on November 6 to long-time maintainer nugaon," SafeDep added. "That day the attacker injected GitHub Actions workflows to steal CI credentials, and the attempts failed. Two days later, the attacker used the release bot bee-worker to publish the malicious releases. How the attacker got into either account remains unknown."
  • Nightmare Eclipse New SignDrop 0-Day — Security researcher Abdelhamid Naceri (aka Chaotic Eclipse) released a new Windows zero-day exploit that can let attackers gain SYSTEM privileges. Called SignDrop, it has been described as a Windows Common Log FileSystem (CLFS) authentication zero-day local privilege escalation flaw. "The vulnerability turns a defense into an attack surface," Cyderes said. "Microsoft added HMAC-based authentication codes to CLFS log files specifically to block the class of logic bugs caused by improper validation of CLFS data structures, which accounted for 19 of 24 CLFS CVEs over five years. SignDrop abuses the signing mechanism itself: it forces clfs.sys to create a .cnpf signature file as SYSTEM in an attacker-controlled location, producing a privileged file-creation primitive at an attacker-selected path. Because the resulting file retains attacker-accessible security attributes, the exploit reopens it and replaces the CLFS-generated content with an embedded payload DLL." Microsoft said it's investigating the reported vulnerability. In late September, the researcher also released an exploit for BigDiskBuster, a denial-of-service (DoS) flaw impacting Microsoft Defender that's similar to UnDefend and prevents the application from performing platform/signature updates.
  • Default Admin Password Lets Researchers Unlock and Start Cars — New research found that it's possible to take over customer accounts at two major automakers, and use them to remotely unlock and start a test car, flash headlights, and sound horns after finding an administration console on the brands' login servers still protected by its default password. Both apps signed customers in through ForgeRock, an identity platform now part of Ping Identity. The carmakers remediated the flaw approximately two hours after responsible disclosure.
  • Google Patches Actively Exploited Chrome 0-Day — Google released updates to patch a high-severity vulnerability in Chrome has come under active exploitation in the wild. The flaw, tracked as CVE identifier CVE-2026-125350 (CVSS score: 8.8), has been described as a use-after-free bug in the XML component. The issue has been addressed in 157.0.8103.50/.51 for Windows and Apple macOS, and 157.0.8103.50 for Linux. Google did not disclose how the vulnerability is being exploited and in what context.
  • Meta Fined by Italy Over Accessing Android Users' Photos with Facebook App — The Italian Data Protection Authority (IDPA) hit Meta with one of its highest fines to date. According to the Italian data regulatory body, Meta has been fined €805 million for failing to disclose that it had access to user photos, videos, and metadata for those using the Facebook app on Android devices. Meta had access to Android users' ​photos and videos through a Facebook app feature that ​suggested content from users' personal galleries that they ⁠could post. The feature has been available since 2023. Meta has 60 ​days to disable the feature by default and seek users' consent ​separately. The company said it would appeal the decision. "This is a simple feature ​that helps people share photos and videos on Facebook," Meta told Reuters. ​"Users must grant permission on their device before the feature can operate, and ‌they ⁠can change that permission at any time in their settings."

📰 Around the Cyber World

  • A cybercrime investigation from independent cybersecurity journalist Brian Krebs has linked the administrator of Qilin ransomware to Aleksey Mikhailovich Yakovtsev, a 36-year-old man living in St. Petersburg, Russia.
  • The TOR project released 0.4.9.17 to include denial-of-service (DoS) defenses related to IPv6 handling. "This release comes in rapid response to the ongoing DDoS attack on the network, which has affected most relay operators," the maintainers said. "This is not an easy problem to address, as relays across the network are being overwhelmed by a massive flood of client circuits. We are actively evaluating additional defenses and so expect further releases in the near future."
  • As many as six pre-authentication remote code execution 0-day vulnerabilities have been uncovered in the Danfoss AK-SM 800A fridge controllers. The flaws, identified by Midnight Blue within the span of an hour, allow full device take-over, persistent access (possibly after reset), and persistent denial-of-service, rendering the device inoperable. Additional technical details are currently withheld. "Through remote code execution, an unauthenticated attacker can remotely run arbitrary code at the operating system level of the AK-SM800A controller," Midnight Blue said. "Due to the lack of secure boot, an attacker with RCE could push malicious firmware that simply renders the device inoperable and irrecoverable without specialized hardware intervention (e.g. by wiping flash memory and/or causing an infinite boot loop). Such a 'bricking' or wiper approach would require full device replacement." The findings unfold against the backdrop of two waves of cyber attacks targeting internet-exposed fridge controllers by Danfoss and Copeland across Europe.
  • Cruciferra has been revealed as a rebrand of the long-running KGB cryptor. It has been sold to cybercriminals since October 2025. ESET said it has prevented over 700,000 compromise attempts from Cruciferra since January 2026, most of them targeting Türkiye, Greece, and Spain. It has been used to deliver payloads like Formbook and PureLogs. "In mid-October the cryptor's domain was seized, and the service went dark," ESET said. "Days later, the same operator resurfaced with a new offering – exclusive $5K-per-build cryptors, pitched against enterprise EDRs and advertised with a claimed bundled kernel 0-day. Seized infrastructure ≠ a dead service."
  • Using AI models on a limited budget and running it against 10 popular TCP/IP stacks has led to the discovery of 99 vulnerabilities in 90 hours. Of these, 66 are new vulnerabilities, 52% of them critical or high severity. This also includes seven vulnerabilities specific to the firmware of a discontinued wireless access point, such as buffer overflow via firmware upload and hard-coded administrator credentials that cannot be changed for web and shell management. "AI cut the analysis time from 9 months to 90 hours and the research cost by 100x when compared to our previous analysis," Forescout said. "It rediscovered 40% of the vulnerabilities we had previously disclosed on those stacks. Total static analysis cost was $935, an average of $2.58 per finding."
  • Since 2021, Project Zero has followed a "90 + 30" vulnerability disclosure policy, allowing vendors up to 90 days to address a vulnerability, plus an extra 30 days "soak time" for patch rollout. That's changing now with the emergence of AI-assisted vulnerability discovery and exploitation. Going forward, Google Project Zero will disclose vulnerabilities 90 days after they are reported to the vendor, regardless of whether they are fixed. The deadline drops to 60 days on February 2, 2027, and to 30 days on January 3, 2028.
  • ClickFix-style lures are being used to deliver a macOS-focused, modular information stealer called Phexia. The malware is also capable of deploying an XMRig miner. "The most recent and notable change in Phexia occurred in May 2026, when the threat actor started testing smart contracts on the Polygon blockchain as a command-and-control (C2) dead-drop resolver (DDR)," WithSecure said. "The abuse of smart contracts by threat actors as part of their attack chain is generally known as EtherHiding. The malware previously relied on hardcoded C2 domains as well as Telegram channels and Steam profiles as its C2 DDR. The threat actor was observed actively weaponizing the Polygon smart contracts since late May to early June 2026."
  • The threat actors behind WeedHack have been linked to another cybercriminal operation called Marsalek that expands beyond using Minecraft lures to disguise malicious software as popular gaming tools, cheats, and utilities for games including Roblox, Fortnite, and Counter-Strike 2. "Active from approximately December 2025 through May 2026, Marsalek offered free access to sophisticated information-stealing malware through a publicly accessible platform, complete with a dashboard that allowed users to create malicious files, track victims, and access stolen information," McAfee Labs said. The cybersecurity company identified more than 1,560 registered accounts, over 400 malicious files, and more than 29 distribution URLs associated with the campaign. Marsalek also deploys a second information stealer called PureLog to steal sensitive data and exfiltrate it to another server. "This means that while someone using Marsalek may believe they're collecting stolen passwords and other personal information for themselves, the malware operator could also gain access to that information without their knowledge," McAfee Labs. This tactic is called double theft or a dual-hook infection.
  • New findings from SOCRadar show that ransomware operators have started handing the attack to AI agents, leading to the rise of agentic ransomware attacks. "Agentic ransomware is ransomware where AI agents do the hands-on work: choosing techniques, running tools and writing code, within limits a human sets," SOCRadar said. "In less than a year, AI agents moved from building access for ransomware brands to running live encryption and extortion campaigns."
  • An active campaign discovered in early October 2026 is targeting internet-facing Microsoft SQL Server instances and using Transact-SQL (T-SQL) commands to deliver malware such as XMRig miner and Gh0st RAT. The attacks employ predefined username and password lists to brute-force into the servers and exploit their administrative capabilities to execute commands on the underlying Windows systems. "The malware scans IP ranges for exposed SQL Servers and attempts to log in using supplied credentials," Fortinet said. "After a successful login, it remotely executes malicious T-SQL commands on the compromised server to download and run additional malware." It's not known how many servers were compromised or who was behind the campaign.

  • A Europol operation, in collaboration with law enforcement agencies from 14 countries across the globe, has successfully identified vendors and buyers from major dark marketplaces as part of Operation TorNado, a coordinated international effort targeting cybercrime, drug trafficking, and firearms offenses. "The operation, which spanned from May 2025 to October 2026, resulted in 354 arrests and hundreds of house searches worldwide," Europol said. "This effort included a follow-up action focused on the identification of suspects after the takedown of five major dark marketplaces: Archetyp, Bohemia, Nemesis, Kingdom, [and] Tor2Door." The U.S. led with 132 arrests, followed by the U.K. (59). Authorities also seized more than 5.7 metric tonnes of illicit drugs, 209 firearms, and over $234 million in both cash and virtual currencies.
  • Threat actors have been observed using a "convincing device-code phishing attack" that involves a Microsoft Teams calendar invite booking flow to target a company in the construction sector. The attack was observed in mid-October 2026. "While many device code phishing lures leverage a generic Microsoft sign-in form, this attack crafted an email with a believable social engineering lure that impersonated a legitimate senior vice president of another company in the construction sector, complete with a typosquatted email domain," Huntress said. "A link in the message to the victim began a 'Microsoft Teams Meeting Scheduler' booking flow, which included prompts to pick a duration of the call, as well as a date and a time. On the backend, these prompts kicked off the Microsoft device code sign-in process and returned a user code, and when the target clicked the 'Confirm Meeting' prompt on the lure page, they were unknowingly copying the code to their clipboard. Then a pop-up prompt opened to Microsoft's real device sign-in page, asking the target to submit the code, which completed the device-code phishing attempt."
  • Threat actors are probing two of 14 vulnerabilities newly disclosed in XWEB EVO, the Dixell refrigeration supervisor now sold under the Copeland name. According to VulnCheck, the flaws in question are CVE-2026-124014 (an unauthenticated write of the system configuration file via config.lua) and CVE-2026-124010 (an unauthenticated root command execution flaw). These two flaws, along with seven others, only affect firmware builds that predate a 2021 rewrite, while the remaining five also impact the latest firmware, 5.8.8, which has reached end-of-support and won't be patched.. As of March 2026, Copeland ended software support for the XWEB EVO family, and has advised customers to move to XWEB Pro models.
  • Microsoft has warned of a phishing campaign exploiting the widespread outage on November 12, 2026, that affected access to business email and other cloud services across multiple regions. "The messages impersonate Microsoft 365 service health notifications and reference the legitimate Exchange Online incident EX1550543," Microsoft said. "The activity is consistent with credential phishing, although credential collection and malware delivery have not been confirmed." The outage has since been attributed to a software defect introduced in a July 2026 update for network gateway servers.
  • Threat actors are exploiting unpatched GeoVision camera software to deploy an XMRig cryptocurrency miner across 13 organizations. "All malicious activity stemmed from GeoStartupAgentService.exe; across many endpoints, the activity was run under the NT AUTHORITY\SYSTEM account," Huntress said, adding the bulk of the attacks occurred between November 8 and November 10, 2026. The attack employs the Bring Your Own Vulnerable Driver (BYOVD) technique to tamper with antivirus protections like Microsoft Defender by making use of "wsftprm.sys." Also deployed as part of the intrusion chain is a PowerShell script that drops a custom Golang loader that uses BitTorrent DHT and PKARR for C2 server discovery for added resilience and to make it possible to move to new infrastructure without losing access to the infected machines. In the final stage, the loader sets up a scheduled task to execute itself every 15 minutes and ultimately deploys the miner.

Conclusion

The strange part isn't how clever some of these attacks have become. It's how many still work because of things nobody checked, fixed, or thought twice about.

And with finding flaws getting cheaper and exploiting them getting easier, that gap is only becoming harder to ignore. Plenty to unpack this week.
