APT29 关联黑客劫持 Plerdy SEO Tracker 投递 iOS 与 Android 利用链

APT29-Linked Hackers Hijack Web Analytics Script to Deliver iOS and Android Exploits

正文 · AI 翻译
中文原文

据称，与俄罗斯有关联的威胁行为者 APT29 策划了一场大规模“水坑”攻击活动，通过受入侵网站、虚假域名，以及涉及乌克兰网络分析服务 Plerdy SEO Tracker 的供应链攻击，针对 iOS 和 Android 用户。

“注入的 JavaScript 代码会收集浏览器和设备属性，”Sekoia 研究人员 Amaury-Jacques Garçon 和 Félix Aime 表示。“随后，投递基础设施会提供针对 iOS 或 Android 的特定平台 N-day 漏洞利用链。”

这些攻击的最终目标是提供能够窃取浏览器 Cookie 的载荷，在某些情况下还会窃取 Wi-Fi 密码或完整的移动设备数据。法国网络安全公司于 2026 年 10 月中旬发现了这项代号为 Poisoned Source 的活动。

这场攻击活动的显著特点是使用了三种感染途径——

  • 入侵合法网站并注入恶意 JavaScript
  • 冒充美国（“america250[.]holiday”）、乌克兰、捷克共和国和保加利亚知名网站的仿冒网站
  • 在 2026 年 8 月 27 日至 9 月 3 日期间入侵 Plerdy SEO Tracker 的供应链，向“a.plerdy[.]com/public/js/click/main.js”注入恶意代码

受入侵的网站包括一个代表美国化学工业企业的主要行业协会、一个欧洲极右翼政党，以及一个与保加利亚军方有关的网站。据怀疑，这场“水坑”攻击活动的设计目标可能是针对特定个人，而非广泛撒网。

Sekoia 表示：“目前尚不清楚攻击者是打算针对特定网站的访问者，还是试图尽可能多地入侵未打补丁的移动设备 indiscriminately，在选择性识别并利用感兴趣的信息之前不加区分地外传数据。”

“然而，在俄乌战争背景下，这些网站中有几个很可能会吸引高价值或具有战略重要性的访问者。此次供应链攻击通过一些高价值目标扩散，例如军队、特种部队和军事装备（弹道、无人机）相关网站。”

无论采用何种方法，最终都会导向同一种载荷：一个用于识别访问者设备和 Web 浏览器的 JavaScript 加载器，随后提供相应的下一阶段恶意软件。对于 iOS 用户，它会导向名为 DarkSword 的漏洞利用工具包，用于窃取 Cookie 和完整的设备数据。

在 Android 上，该恶意软件能够在不建立持久化的情况下外传 Chrome 数据和 Wi-Fi 密码。目前已识别出至少三种不同的漏洞利用——

  • Class A，针对运行 iOS 16.7 的 iOS 设备，利用 CVE-2025-43529（DarkSword 所利用的同一漏洞）和 CVE-2024-27834，交付用于窃取 Cookie 的 JavaScript 恶意软件。
  • Class B，针对运行 iOS 18.5 的 iOS 设备，利用包含 CVE-2025-43529、CVE-2026-20700、CVE-2025-14174、CVE-2025-43510 和 CVE-2025-43520 的 DarkSword exploit chain，投放 JavaScript 恶意软件，以完全窃取设备数据。这包括 SMS 消息和 iMessages；Apple Mail Envelope Index 和 Protected Index SQLite 数据库；语音信箱；WhatsApp 和 Telegram 数据库；iCloud 钥匙串、Wi-Fi 密码；联系人；通话记录；Safari 浏览历史记录和 Cookie；照片；以及 Apple Health、日历、备忘录和 iCloud Drive 中的数据。
  • Class C，针对运行 Chrome 139 至 145 版本的 Android 设备（但出于目前尚不明确的原因，明确排除 143 版本），利用 CVE-2026-3910 和 CVE-2025-27038 来实现远程代码执行、沙箱逃逸和权限提升，最终投放 AndroSnitch，以收集 Chrome 数据和 Wi-Fi 密码。

在所有三种情况下，被窃取的数据都会发送至 "ad.starx-net[.]com:8881/telemetry/v12" 端点。Android 攻击链会检查目标设备的型号标识符（即 SM-S938B），以确定其是否为 Samsung Galaxy S25 Ultra。如果设备匹配，则终止漏洞利用活动。

AndroSnitch 的名称源于它与 ANDROSNATCH 的相似之处。后者是一种窃取 Chrome Cookie 的载荷，Google 于 2024 年 8 月在披露一起疑似 APT29 水坑攻击活动时记录了它。该活动利用涉及 CVE-2024-5274 和 CVE-2024-4671 的 Chrome exploit chain，攻击访问蒙古国政府网站的 Android 用户。

Sekoia 表示："此次行动也证实，由国家支持的入侵组织仍在继续复用 DarkSword 等 CSV [Commercial Surveillance Vendors] 移动端漏洞利用框架。采用打包式 N-day 漏洞利用链降低了实施高级移动端漏洞利用的成本和技术门槛。"

Coruna 和 DarkSword 工具包 evolves

此次开发发生在 iVerify 和 Report URI 详细披露 DarkSword 的 P7 变体 数周之后。该变体通过利用广告基础设施的半点击攻击进行投放。据称，在一个案例中，漏洞利用载荷通过以世界杯为主题并从 "ad-track[.]live." 提供的恶意 Instagram 广告传播。

另一条途径属于名为 DeadTag 的犯罪攻击活动，攻击者会获取仍被数千个网站加载的旧有分析和广告标签背后的过期域名。其思路是向 iPhone 访问者提供恶意 JavaScript，并在暗中为攻击者执行竞价。

Report URI 表示："它会检查访问者是谁。搜索引擎、安全扫描器、自动化浏览器，以及任何看起来像机器人的程序都得不到任何内容。"

随后，该脚本会与攻击者的服务器交互，由服务器决定每位访问者必须重定向到的目的地。利用 DeadTag 的 iPhone 漏洞利用路径会将访问者导向 Coruna exploit kit，攻击运行 iOS 13 至 17.2.1 的较旧 iPhone，以及面向运行 iOS 18.4 至 18.7 的 iOS 设备的 DarkSword P7。

“这些不是钓鱼页面或虚假应用下载，两套工具包都会直接攻击浏览器本身，”Report URI 的 Scott Helme 表示。“仅仅打开该页面就足以让你的设备遭到入侵。无需点击任何内容，不需要点击任何链接，无需安装任何东西，也不会有任何警告。如果 iPhone 运行的是存在漏洞的 iOS 版本，这套工具包就会突破浏览器限制，并在设备上安装间谍软件。”

其他攻击方案会跳转到虚假的 Google 重定向页面、博彩和赌场诈骗注册页面、汽车交易和牙医的搜索广告，以及虚假调查和“你中奖了”奖品页面。超过 660 个已过期并被重新注册的域名属于 DeadTag 网络。

根据 Zimperium zLabs 发布的一项分析，分发 Coruna 和 DarkSword 漏洞利用工具包的行动持续演变。截至 2026 年 10 月，已有 608 个域名为 Coruna 系列代码提供分发服务。

尽管 Coruna 最初由国家行为体开发，用于高度定向的行动，但在首次披露后，该工具包发生泄露，随后被多个威胁行为体广泛用于各自的行动。

在许多情况下，人们发现诱饵网站会明确指示访问者退出应用内浏览器或其他 iOS 浏览器，改用 Safari 打开链接，以便根据设备的操作系统触发漏洞利用链。

“运行 iOS 17.2.1 或更早版本的目标设备会收到旧版 Coruna 框架（在多个恢复出的配置中表现出字节完全相同的 JavaScript 载荷），”安全研究员 Santiago Rodriguez 表示。“相反，运行较新 iOS 版本的设备会收到源自 DarkSword 的执行链。”

“经分析的分发范围涵盖约会门户、AI 伴侣平台、加密货币促销活动、媒体流媒体服务，以及在若干情况下被入侵的合法网站，这些网站通过隐藏 iframe 提供该工具包。”
