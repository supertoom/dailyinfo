Hackers Trojanize Official Q-Dir and DesktopOK Downloads to Deliver Remote Access Malware

Q-Dir 与 DesktopOK 官方下载及更新文件遭篡改，5 个版本被确认投毒并安装可远程控制的 Python RAT。恶意安装器从外部服务器下载载荷，经 7-Zip 解压运行 RAT，通过伪装 Microsoft Edge 的计划任务持久化，连接 C2 执行命令、传输文件、截图并收集系统及安全软件信息。

正文 · 原文

Ravie LakshmananNov 27, 2026

Cybersecurity researchers have disclosed details of a software supply chain attack that has tampered with Q-Dir and DesktopOK installation files distributed via the official SoftwareOK website.

"Evidence indicates that malicious files were generated not only when users downloaded the programs directly from the official download page but also during the update process of previously installed legitimate programs," South Korean cybersecurity company AhnLab said.

Q-Dir, also called the Quad Directory Explorer, is a free, lightweight file manager for Windows developed by SoftwareOK. According to its website, DesktopOK is a free Windows utility designed to save and restore desktop icon positions. 

The unauthorized modifications are designed such that the malicious activity is challenging to detect when running the programs, while simultaneously retrieving and deploying a Python-based remote control malware (RAT) from an external server.

Once installed, the RAT payload is capable of executing shell commands and Python code, transferring files, capturing screenshots, and collecting system metadata based on commands issued by the attacker.

The following product versions have been confirmed to be poisoned, given the discrepancies in the SHA-256 hashes of the installer files and the presence of additional code that triggers additional file downloads and automatic execution -

  • Q-Dir 12.85.0.0
  • Q-Dir 12.84.0.0
  • Q-Dir 12.83.0.0
  • DesktopOK 12.85.0.0
  • DesktopOK 12.82.0.0

The exact mechanism that allowed the installation files to be replaced with a trojanized version remains unknown.

"The malicious installer runs the legitimate Q-Dir or DesktopOK to lower the user's suspicion, while simultaneously downloading and installing a Python RAT package from an external server," AhnLab said.

Specifically, this involves downloading two payloads from "mail.c1a2[.]top" -

  • 7zr.exe, the legitimate 7-Zip tool to decompress files
  • dsv2_py39_agent.7z, a package containing the RAT and Python runtime environment

The attack chain is fairly straightforward in that it uses the 7-Zip tool binary to extract and run the Python RAT. The malware then sets up persistence on the host by means of a scheduled task that impersonates Microsoft Edge to fly under the radar. The task is configured to execute the RAT by launching a Python script named "py_client_dsv2.py."

Upon execution, the RAT establishes communication with its command-and-control (C2) server ("8.210.69[.]51:9876") to receive tasks and run them. It supports the following features -

  • Shell command execution
  • Python code execution
  • File upload and download
  • Screenshot capture
  • Operating system and system information

It also gathers a list of running processes and compares it against an internal list of various security products used in South Korea and abroad, including AhnLab, ESTSecurity, Hauri, CrowdStrike, SentinelOne, Trend Micro, Avast, McAfee, ESET, Symantec, Kaspersky, Bitdefender, Sophos, Fortinet, Elastic, and Malwarebytes.

Information about identified security programs is transmitted to the C2 server, so as to help the attackers better plan the next stages of the attack or serve payloads that can bypass detection.

The activity has not been attributed to any known threat actor. However, AhnLab said it identified Chinese language comments in the source code, suggesting that the malware authors or attackers may have used a Chinese-speaking environment.

"Users who are currently using Q-Dir or DesktopOK, or who have recently installed or updated these programs, should verify the hash values of the downloaded files and check their systems for any traces of RAT installation or execution," AhnLab said.

"However, simply uninstalling and reinstalling the program may not remove a Python RAT that has already been installed. Therefore, you should also check for suspicious Python execution environments, scheduled tasks, related files, and traces of external network communication, update your antivirus engine to the latest version, and then perform a full system scan."
