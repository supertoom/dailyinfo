正文 · 原文

Broadcom has released security updates to fix a critical VMware vCenter Server authentication bypass vulnerability that Chinese-linked hackers have exploited in zero-day attacks since September 2026.

The vulnerability, tracked as CVE-2026-123890, affects the VMware Directory Service in vCenter Server, a management platform organizations use to manage VMware virtualized environments.

According Broadcom, the flaw allows an unauthenticated attacker with network access to a vulnerable vCenter Server to bypass authentication and gain unauthorized access.

Successful exploitation can allow attackers to obtain administrative access to vCenter, giving them control over the virtual machines managed by the server.

Broadcom patched the vulnerability on November 19 in VMSA-2026-0009, which also fixes four other vulnerabilities affecting VMware SDDC Manager and VMware Tools for Windows.

"You are affected if you are running any version of VMware vCenter, SDDC Manager, or VMware Tools for Windows prior to the versions listed as "fixed" in the VMSA," Broadcom's security advisory reads.

"This includes vCenter and SDDC Manager deployed standalone and as part of VMware Cloud Foundation, VMware vSphere Foundation, VMware Telco Cloud Platform, and VMware Telco Cloud Infrastructure, as well as VMware Tools installed in Windows virtual machines."

The company considers the vCenter vulnerability as an emergency update, urging organizations to install the patches as soon as possible.

Broadcom says there are no official workarounds for the vulnerabilities, although network restrictions and firewall controls can help reduce exposure.

Furthermore, the vulnerability affects vCenter regardless of whether Enhanced Linked Mode is enabled.

While Broadcom has not confirmed that the flaw was exploited, researchers at Google's Mandiant have documented attacks exploiting CVE-2026-123890.

Chinese hackers exploited VMware zero-day

In a report published today, Mandiant and Google Threat Intelligence Group (GTIG) revealed that a suspected Chinese state-sponsored hacking group tracked as Armory Castle (formerly UNC5221) exploited CVE-2026-123890 in early September 2026.

"Successful exploitation results in a remote authentication bypass which creates an authenticated session established as administrator@vsphere.local," explains Mandiant.

"Using the authenticated administrator session, the attacker can execute arbitrary commands and acquire files, including the data.mdb database, by leveraging the vCenter Server Directory Service (vmdird) RPC interface vmdirdbcp."

Armory Castle is a cyberespionage group known for exploiting zero-day vulnerabilities in enterprise network appliances, including Citrix NetScaler and Ivanti Connect Secure devices, to breach corporate networks and deploy custom malware.

The group was also recently linked to attacks exploiting a BeyondTrust Remote Support zero-day, tracked as CVE-2026-102764, which has been exploited since late August.

Mandiant says the VMware exploitation was part of the same intrusion campaign, with the attackers first compromising BeyondTrust Remote Support appliances before moving laterally into internal Linux systems and targeting VMware infrastructure.

After gaining access to an internal Linux appliance, the hackers deployed the "SLIMSAVAGE" web shells to maintain persistent access, escalated privileges to root, and scanned the internal network for VMware systems.

The attackers then used a custom Golang exploitation tool named BONESAW to exploit CVE-2026-123890 and compromise a VMware vCenter Server.

Mandiant observed the tool successfully creating a vCenter Single Sign-On (SSO) administrator account and stealing the server's directory database, which can be used to extract further credentials.

BONESAW can also extract SAML signing keys, allowing attackers to forge authentication tokens and gain administrative access to VMware environments.

Following the exploitation, the hackers deployed another tool called SAWSNAKE, which enables so-called Golden SAML attacks to forge authentication tokens, bypass multifactor authentication, and impersonate legitimate users.

During the attack, the attackers also deployed additional web shells and backdoors, including CAGEMATCH, BEARBONES, and LAZYBONES, to execute commands, transfer files, steal credentials, and maintain access to compromised systems.

The attacks ultimately allowed Armory Castle to move deeper into the victims' virtualized environments, access ESXi hosts, and extract sensitive information from virtual machines, including Windows Active Directory database files.

Mandiant says the use of two zero-day vulnerabilities in the same campaign, along with multiple malware families tailored to the targeted platforms, demonstrates the threat actor's technical expertise.

The researchers urge admins to apply the VMware security updates as soon as possible and configure additional security controls to protect their virtualization infrastructure against future attacks.
