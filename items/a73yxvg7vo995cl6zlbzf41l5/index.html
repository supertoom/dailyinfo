Download CSAF

Summary

  • On November 19, 2026, the PHP Foundation announced the availability of security fixes that address a critical vulnerability that could lead to remote code execution. This vulnerability is identified by CVE-2026-126714.

    For information about this vulnerability, see the advisory GHSA-fm2m-fjf5-v3cp. This vulnerability is being referenced as phpAfterShell.

    For information about Splunk products and offerings, see Vulnerabilities in PHP affecting Splunk Products - November 2026.

    This advisory will be updated as additional information becomes available.

    This advisory is available at the following link:
    https://sec.cloudapps.cisco.com/security/center/content/CiscoSecurityAdvisory/cisco-sa-phpaftershell-nov-2026-kT9pL4Xe
