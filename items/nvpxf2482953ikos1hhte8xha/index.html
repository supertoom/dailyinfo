中文原文

攻击者利用 GeoVision 摄像头管理软件入侵了 13 个组织的 Windows 机器，并将其变成了加密货币矿机。Huntress 在一份威胁公告中警告了这一点。

GeoVision 是一家台湾监控和门禁控制公司，客户遍布 110 个国家。受害者来自不同行业，大多数入侵发生在 11 月 8 日至 10 日之间。每次攻击活动都始于一项属于 GeoVision 软件的服务，而对受害者外部 IP 地址进行 Shodan 搜索后，均发现了暴露在互联网上的 GeoVision 设备和管理界面。

禁用杀毒软件，安装矿机

入侵后，攻击者运行了一系列脚本，检查 Microsoft Defender 是否正在运行。其中一个脚本下载了一个内核驱动；该驱动此前曾在自带易受攻击驱动（BYOVD）攻击中被滥用，以篡改杀毒软件。

研究人员写道：“在攻击的这一阶段，我们还观察到攻击者配置了三个 IFEO Debugger 劫持，利用了 Windows 的一项故障排除功能。映像文件执行选项（IFEO）允许管理员配置一个‘调试器’，在启动特定可执行文件时运行。该设置存储在 Windows 注册表中一个以该可执行文件命名的键下。”

这些劫持将三个 Windows 安全进程重定向至 systray.exe，很可能是为了阻止它们启动。随后，攻击者安装了自定义加载程序；在部分机器上，该加载程序被设置为每 15 分钟以及系统启动时运行。该加载程序下载了 XMRig，这是一款受到威胁行为者欢迎的开源加密货币矿机。

存在已知缺陷的过期版本

该公告没有指明具体漏洞、CVE 或产品版本。过去对 GeoVision 产品的在野利用，例如 CVE-2024-6047 和 CVE-2024-11120，针对的是已停止支持的嵌入式设备，因此 Help Net Security 向 Huntress 询问：受影响的主机是否运行着仍受支持且最新的 GeoVision 版本，以及攻击者使用的是已知漏洞、未披露漏洞，还是薄弱或默认凭据。

Huntress 安全运营分析师 Anthony Gibbs 告诉 Help Net Security，对部分受影响主机的检查发现，它们运行的是 GV-VMS 17.4.8.0，该版本于 2024 年 4 月 24 日编译。这一版本早于 GeoVision 修复版本 V17.4.8.58。

Huntress 高级安全运营分析师 Austin Worline 表示：“GeoVision 2026 年 4 月的公告确认，WebCam Server 功能存在三个无需身份验证的远程代码执行漏洞，影响这一版本（GV-VMS 17.4.8.0）。因此，利用已知漏洞是最有可能的解释。”

Worline 补充道：“我们目前尚未确定使用的是三个 CVE 中的哪一个，也尚未确认 GeoVision 是否认为这些安装仍受支持。”

旨在比其服务器存活的加载程序

该加载程序包含一个 BitTorrent Mainline DHT 客户端和一个 PKARR 解析器，使操作人员能够通过公钥找到当前的服务器地址，并在转移到新基础设施时保持对受感染机器的访问。我们询问 Huntress，是否在其他加密货币挖矿活动中见过这种技术，以及这是否表明操作人员希望保留这些据点以用于其他目的，例如出售访问权限。

“我们会把这种加载器描述为类似僵尸网络的程序：它的 DHT 和 PKARR 功能使操作人员能够找到更新后的服务器地址并投放新的有效载荷。韧性目标与 EtherHiding 类似，但机制不同：这种加载器使用 BitTorrent DHT 和 PKARR 来发现服务器，”Gibbs 解释道。

“在此次活动中，我们观察到它下载了 XMRig。获取其他有效载荷的能力可能支持挖矿之外的用途，包括可能出售访问权限，但我们没有看到证据表明这些事件中出售过访问权限或将其用于其他目的。”

“就我个人而言，我还没见过这种技术被用于其他加密货币挖矿活动，但这并不意味着它没有被使用过，”他补充道。

SOC 在多个组织中观察到的攻击链（来源：Huntress）

给防御方的建议

“这次攻击提醒我们，暴露在互联网上的软件可能让攻击者获得进入组织的立足点。组织应取消对 GeoVision 设备和管理接口不必要的公共访问，将其置于 VPN 后，或将访问限制为受信任的 IP 地址，”Huntress 警告道。

Huntress 还建议安全团队检查是否存在由 GeoVision 服务启动的命令行 shell 或 PowerShell 会话。如果发现任何此类情况，应在删除文件或更改配置之前隔离受影响的主机并保存证据。

“组织应将摄像头管理应用程序和软件视为企业攻击面的一部分，”研究人员总结道。
