Cisco Secure Firewall Adaptive Security Appliance 和 Secure Firewall Threat Defense Software 远程访问 SSL VPN 隧道拒绝服务漏洞

高

CVE-2026-76418

CWE-690

下载 CSAF

电子邮件

摘要

  • Cisco Secure Firewall Adaptive Security Appliance (ASA) Software 和 Cisco Secure Firewall Threat Defense (FTD) Software 的远程访问 SSL VPN 服务中存在一个漏洞，可能允许未经身份验证的远程攻击者导致设备意外重新加载，从而造成拒绝服务 (DoS) 状态。

    此漏洞是由于在隧道组上配置了辅助身份验证时出现逻辑错误所致。攻击者可以在连接 SSL 远程访问 VPN 时发送特制请求来利用此漏洞。成功利用可能使攻击者导致受影响设备重新加载，从而造成 DoS 状态。

    Cisco 已发布修复此漏洞的软件更新。没有可解决此漏洞的变通方案。

    本公告可通过以下链接获取：
    https://sec.cloudapps.cisco.com/security/center/content/CiscoSecurityAdvisory/cisco-sa-asaftd-tunnel-dos-s6mgkb75

受影响的产品

  • 如果 Cisco 设备运行易受攻击版本的 Cisco Secure Firewall ASA Software 或 Cisco Secure FTD Software、SSL 远程访问 VPN 登录服务可访问，并且在下文所述的隧道组范围内配置了辅助身份验证，则此漏洞会影响这些 Cisco 设备。

    有关哪些 Cisco 软件版本易受攻击的信息，请参阅本公告的 已修复软件 部分。

    确定 SSL 远程访问 VPN 配置

    如果运行配置中包含 webvpn 关键字，并且至少在一个接口上启用了 SSL VPN，则该配置易受攻击，如下表所示：

    Cisco Secure Firewall ASA Software 和 Secure FTD Software 功能 易受攻击的配置
    SSL 远程访问 VPN1 
    webvpn
     enable <interface_name>

    1. 对于 Cisco Secure FTD Software，可在 Cisco Secure Firewall Management Center (FMC) Software 中通过 Devices > VPN > Remote Access 启用远程访问 VPN 功能，或在 Cisco Secure Firewall Device Manager (FDM) 中通过 Remote Access VPN 启用。

    确定隧道组配置

    如果配置了 tunnel-group-list enable，请检查所有隧道组（包括默认隧道组 DefaultWEBVPNGroup）是否配置了 secondary-authentication-server-group。

    注意： 此检查并不仅限于登录页面上组列表中显示的配置文件。

    如果不存在 tunnel-group-list enable，或已使用 no tunnel-group-list enable 命令将其移除，请检查默认隧道组 DefaultWEBVPNGroup 是否配置了 secondary-authentication-server-group，因为禁用组列表时，如果该默认组使用辅助身份验证，暴露情况仍然存在。

    注意：在 Cisco Secure FTD Software 上，应审查已部署的远程访问 VPN 策略，以及 Cisco Secure FMC Software 或 Cisco Secure FDM 中生成的设备运行配置。无需成功登录 VPN 即可到达受影响的处理路径。

    据已知，只有本公告受影响产品部分列出的产品会受到此漏洞影响。

    Cisco 已确认此漏洞不影响以下 Cisco 产品：

    • Cloud-delivered Firewall (CDFW)
    • Cloud-delivered Firewall Management Center (cdFMC)
    • Secure Access (CSA)
    • Secure FMC Software

临时解决方案

  • 没有能够解决此漏洞的临时解决方案。但可以采取缓解措施，即在任何用户配置的隧道组列表或默认隧道组 DefaultWEBVPNGroup 上禁用辅助身份验证。

    情况 1：如果 DefaultWEBVPNGroup 未使用辅助身份验证，请禁用隧道组列表。在 WebVPN 配置模式下，输入 no tunnel-group-list enable。禁用隧道组列表后，用户将不再能够从提供的列表中选择连接配置文件（tunnel-group 名称），而是需要知道正确的配置文件。

    情况 2：如果 DefaultWEBVPNGroup 使用辅助身份验证，请使用 no secondary-authentication-server-group CLI 命令移除辅助身份验证。禁用辅助身份验证后，远程访问 VPN 的安全态势会降低。

    尽管此缓解措施已在测试环境中部署并证实有效，但客户仍应确定其在自己环境及自身使用条件下的适用性和有效性。客户应意识到，根据客户自身的部署场景和限制，实施任何临时解决方案或缓解措施都可能会对其网络的功能、性能和/或安全态势产生负面影响。在首次评估其对自身环境的适用性及对该环境可能造成的任何影响之前，客户不应部署任何临时解决方案或缓解措施。

    Cisco 强烈建议升级至本公告固定软件部分列出的已修复软件。

固定软件

  • Cisco 认为，在可升级至固定软件版本之前，任何临时解决方案和缓解措施（如适用）都只是临时性方案。为修复此漏洞并避免出现本公告所述的未来暴露风险，Cisco 强烈建议客户升级至本公告中指定的固定软件。

    To use the tool, go to the Cisco Software Checker page and follow the instructions. Alternatively, use the following form to search for vulnerabilities that affect a specific software release. To use the form, follow these steps:

    1. Choose which advisories the tool will search-all advisories, only advisories with a Critical or High Security Impact Rating (SIR), or only this advisory.
    2. Choose the appropriate software.
    3. Choose the appropriate platform.
    4. Enter a release number-for example, 9.20.3.4 for Cisco Secure Firewall ASA Software or 7.4.2 for Cisco Secure FTD Software.
