中文原文

荷兰安全咨询公司 Midnight Blue 本周早些时候表示，Danfoss AK-SM800A 制冷控制器中的六个缺陷可能允许远程攻击者在无需登录的情况下接管控制器。

目前尚无补丁，研究人员称最新固件版本 5.4.0 并未修复这些缺陷。

比利时、爱尔兰和德国的政府网络安全机构本周告知运营方，应将控制器的管理接口从互联网上移除。

比利时和爱尔兰机构表示，对于仍连接到互联网的控制器，仅更新固件、更改默认密码或启用严格模式并不足够。严格模式是一种登录保护机制，要求使用加密连接和会话令牌，但这六个缺陷之一存在于负责执行严格模式的网关中。

AK-SM800A 用于运行商店的冷藏柜和冷冻柜，维护公司可以对其进行远程管理。自 10 月 11 日起，此类控制器成为法国攻击的目标；上周开始的第二波攻击波及欧洲多地。攻击导致非预期的除霜循环并损毁库存。

德国联邦信息安全局 BSI 在一份安全公告中表示，AK-SM800A 曾涉及此前发生的多起事件 wherein 多个国家的制冷设备遭到篡改。

该机构没有关于这六个新缺陷被利用的任何信息，其他机构和研究人员也未将这些缺陷与那些事件联系起来。

研究人员检查了当时最新的固件版本 5.3.2，并表示包括该版本在内的所有版本都受到影响。

目前尚未分配 CVE 编号。研究人员在与制造这些控制器的丹麦公司 Danfoss 开展披露工作的同时，对技术细节保密。

供应商将日期标注为 11 月的软件包 5.4.0 列为 AK-SM800A 的最新版本。其 5.4.0 readme 和 11 月升级指南包含升级步骤，该指南还增加了更严格的密码规则。两者均未提及修复任何漏洞。

在行业出版物 Cooling Post 刊载的后续声明中，研究人员表示 5.4.0 不会修补这些缺陷：“实际上也不可能，因为根据文件时间戳，此固件很可能构建于 10 月 29 日，即第二波网络攻击之前，也远早于我们的漏洞报告。”

德国机构本周首先在一份新闻稿中表示 5.4.0 不受影响。当天稍后，该机构在一份更正声明中修改了这一说法：目前尚不能排除 5.4.0 受影响的可能性。

截至今日，供应商的公告页面未列出针对这六个缺陷的任何公告，也未公布修复日期。

Midnight Blue 研究人员 Carlo Meijer 使用供应商提供的可下载固件，通过不到一小时的人工审查发现了这六个缺陷，并在一份技术文章中对其进行了描述。

其中五个缺陷存在于无需登录即可访问的 Web 请求处理程序中，这些处理程序位于一个以 root 身份运行的程序内。研究人员利用其中一个缺陷在较旧的固件版本 3.3.0 上以 root 身份运行了代码，并在 5.3.2 中发现了相同的漏洞。

严格模式几乎会对所有未登录用户关闭控制器的 Web 攻击面，包括上述演示中利用的缺陷。第六个缺陷存在于负责执行严格模式的网关中；这是一个独立的程序，在用户登录前会阻止除登录请求之外的所有请求。

研究人员在一台启用了 Strict 模式的模拟器中运行固件 5.3.2 时，该漏洞导致网关崩溃。研究人员表示，经过更多工作可以将该崩溃转化为代码执行，而且该网关缺少栈金丝雀等基本漏洞利用防御机制。

攻击者如果能以 root 身份运行代码，就可以更改控制器的设置、启动除霜周期，并向日志隐藏这些活动。

研究人员发现，这些控制器不使用安全启动，因此攻击者可以植入在恢复出厂设置和更新固件后依然存在的代码。攻击者还可以使控制器无法使用，直至将其更换。

研究人员表示，这段代码几乎肯定还存在更多类似漏洞，并称逐个修补漏洞或启用 Strict 模式是“对稀缺安全与人员资源的错误配置”。

运营商可以采取的措施

比利时网络安全中心表示，移除互联网暴露不能等待补丁发布，即使使用的是最新固件并启用了 Strict 模式，也需要采取这一措施。

比利时公告和类似的爱尔兰公告建议采取以下步骤：

  • 找出所有可从互联网访问其管理接口的控制器，包括通过 4G 或 5G 调制解调器访问的情况，并消除这些暴露。
  • 仅通过安全 VPN 或受保护的内部网络提供远程访问。只允许通过防火墙访问某服务公司的 IP 地址是一种短期措施。
  • 检查温度设定点、除霜计划、报警设置、用户账户和远程访问设置中是否存在并非由你实施的更改。

德国机构补充称，任何怀疑系统已遭入侵的人都应更改所有凭据，并检查连接到控制器的设备是否正常运行。

比利时公告称，在切断控制器向其制冷服务公司发送的数据之前，运营商应检查合同和保险条款。他们还应建立受保护的远程访问，以便继续进行监控。

Danfoss 自己的更新指南指出，AK-SM800A 不应可从公共互联网直接访问，并补充道：“此建议适用于所有软件版本，包括启用了 Strict Mode 的版本。”

爱尔兰国家网络安全中心也建议运行最新的受支持固件、更改默认密码并启用 Strict 模式，但表示运营商不应仅依赖这些措施。

Danfoss 于 10 月 12 日告诉 Cooling Post，在法国遭攻击的大多数设备，要么是已不再接收更新的旧型号，要么是运行过时固件的当前 AK-SM800A 设备。

该供应商曾于 2023 年和 2025 年修复 AK-SM800A 中的早期漏洞，其中包括登录绕过和命令注入漏洞。研究人员检查的版本 5.3.2 晚于所有这些修复。
