阿里云应急响应 2026-11-18 09:41 浙江

2026年11月18日，阿里云安全监测到 CVE-2026-114938 OpenJDK Java4Shell Base64解码远程代码执行漏洞

2026年11月18日，阿里云安全监测到 CVE-2026-114938 OpenJDK Java4Shell Base64解码远程代码执行漏洞。

01

风险描述

OpenJDK 是 Java SE 的开源实现。2026年11月18日，官方披露 CVE-2026-114938 OpenJDK Java4Shell Base64解码远程代码执行漏洞。C2 JIT 编译器将 Base64 解码热路径编译为使用 AVX-512 VBMI 指令的手写汇编，该汇编在处理带 = 填充的短输入块时输出长度掩码计算下溢，对结果数组产生越界写入。攻击者可据此在目标 JVM 内先获得固定值越界写与堆内信息泄露，再经堆布局整形升级为任意写、劫持执行流，最终在无需任何认证的情况下通过网络输入达成远程代码执行。 经研究目前已确认以下产品受直接影响：

 1、未授权（pre-auth）RCE：Keycloak、Atlassian Jira / Confluence、JFrog Artifactory、Jenkins、PingFederate 

2、认证后（post-auth）RCE：Kafka、Solr、Elasticsearch、Gerrit、Spinnaker

02

风险评级

CVE-2026-114938
OpenJDK Java4Shell Base64解码远程代码执行漏洞 严重

03

影响范围

Oracle Corporation / Oracle Java SE 

∘ JDK 8 企业性能变体： = 8u511b33-perf（点版本，仅 perf 变体；JDK 8 标准线不受此漏洞影响） 

∘ JDK 17： >= 17.0.6 且 <= 17.0.21.0.3（17.0.6 引入受影响 intrinsic，17.0.5 及更早安全） 

∘ JDK 21： >= 21 且 <= 21.0.13.0.3 

∘ JDK 25： >= 25 且 <= 25.0.5.0.3 

∘ JDK 27： >= 27 且 <= 27.0.1.0.3 

Oracle Corporation / Oracle GraalVM for JDK 

∘ JDK 17： >= 17.0.6 且 <= 17.0.21.0.3 

∘ JDK 21： >= 21 且 <= 21.0.13.0.3

Oracle Corporation / Oracle GraalVM Enterprise Edition 

∘ GraalVM EE 21.3 线： = 21.3.20.0.3（受支持版本；更早 EOL 版本以 Oracle 清单为准） 

OpenJDK 及全部 OpenJDK 系发行版（Eclipse Temurin、Amazon Corretto、Microsoft Build of OpenJDK、 Azul Zulu、BellSoft Liberica、SAP SapMachine、Red Hat OpenJDK；仅 x86-64 + AVX-512 VBMI 硬件， ARM64 平台不受影响） 

∘ JDK 17： >= 17.0.6 且 <= 17.0.21.0.3 

∘ JDK 21： >= 21 且 <= 21.0.13.0.3 

∘ JDK 25： >= 25 且 <= 25.0.5.0.3 

∘ JDK 27： >= 27 且 <= 27.0.1.0.3 

04

安全版本

 ∘ JDK 8 / JDK 11 标准线： 不受此漏洞影响（不含该 intrinsic） 

∘ JDK 17： >= 17.0.21.1（安全）

 ∘ JDK 21： >= 21.0.13.1（安全） 

∘ JDK 25： >= 25.0.5.1（安全） 

∘ JDK 27： >= 27.0.1.1（安全） 

∘ GraalVM for JDK 17/21： >= 17.0.21.1 / >= 21.0.13.1（同源修复） 

∘ 下游发行版： >= 各家对应 .1 版本（Temurin 等截至发文尚未跟发，以各发行版公告为准）

05

修复方案

1、Oracle官方已经发布安全更新，https://www.oracle.com/security-alerts/cspunov2026.html 

2、下游发行版（Temurin / Corretto / Zulu 等）会持续发布对应安全版本，以各发行版公告的版本号为准 

3、临时缓解：利用-XX:-UseBASE64Intrinsics 精确关闭 Base64 intrinsic，或者使用 -XX:UseAVX=2 禁用 AVX-512（ARM不支持） 

4、阿里云云安全中心资产暴露分析功能可对应筛选相关JDK版本支持进行初步影响面排查分析
