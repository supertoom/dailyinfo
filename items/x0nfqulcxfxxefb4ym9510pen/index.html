中文原文

人工智能（AI）、区块链和物流行业在欧洲和美国各地已成为一场大规模、工业化攻击活动的目标，该活动被称为 Trigram。

“Trigram 是一场大规模攻击活动，冒充区块链和 AI 领域的约 50 个品牌，诱骗开发者自行执行信息窃取器，”Stormshield 表示，其在一份于周一发布的深度技术报告中这样描述。

“三种社会工程场景（招聘、会议和软件包跟踪）、一次软件供应链入侵，以及被植入木马代码的代码仓库，最终都指向同一基础设施和同一有效载荷。”

据评估，该活动与关联朝鲜的入侵组织存在相似之处，尤其是 Kimsuky 和 UNK_DeadDrop。此前，Proofpoint、SafeDep、Jamf 和 Genians Security Center 已记录过此次活动的一些方面。

值得注意的是，被追踪为 UNK_DeadDrop 的集群与一个名为 Contagious Interview 的长期朝鲜关联活动存在相似之处。该活动利用以开发人员岗位招聘或代码审查为主题的钓鱼邮件，针对金融、加密货币、教育和技术行业的开发者部署信息窃取器。

在 Linux 和 macOS 系统上，攻击链最终会部署 Overlord，这是一个开源远程访问木马（RAT）框架，用于实施数据窃取。

随后，在 2026 年 8 月，Jamf Threat Labs 披露了利用虚假 Zoom 安装程序部署 Overlord RAT 的 macOS 活动细节；不过，这家 Apple 设备管理公司当时表示，未发现该活动与 UNK_DeadDrop 之间存在“直接重叠”。

“这里观察到的 Overlord 变种与 FlexibleFerret 共享一个 LaunchAgent 标签（com.zoom）和 plist 文件名（com.zoom.plist）；后者是一款被归因于朝鲜的 macOS 恶意软件家族，与 Contagious Interview 活动相关，”其补充道。

截至 2026 年 10 月下旬，Overlord 还通过另一种渠道传播：在 antd-img-crop GitHub 仓库中推送伪造的提交，一旦开发者运行“npm run build”命令，该提交就会通过预构建钩子（“prebuild.js”）安装恶意软件。该 npm 包本身未受影响。

该 JavaScript 有效载荷旨在下载并运行一个虚假安装程序，该程序会设置 Node.js 并获取下一阶段的加密 JavaScript；后者完全在内存中运行，并通过 GitLab 死信点定位其命令与控制（C2）服务器。第三阶段恶意软件负责窃取凭据并安装 OverLord 框架。

“该恶意软件会窃取 macOS、Linux 和 Windows 上的浏览器密码、Cookie、钥匙串、加密货币钱包、SSH 密钥和 .env 文件，然后安装一个伪装成 Google 软件的远程访问代理，”SafeDep 表示，其在一份恶意软件分析中这样描述。

2026 年 10 月 31 日，推送到“antd-img-crop⁠”的伪造提交

在 macOS 和 Linux 系统上，它还会显示一个虚假对话框，要求用户输入系统密码，以便“应用系统更新并验证驱动程序和安全设置”。有趣的是，同一有效载荷还通过另外两个初始访问向量投递——

  • 一个冒充合法加密货币公司 Amber Group 的虚假招聘门户 
  • 一个旁加载的 Microsoft Visual Studio Code (VS Code) 或 Cursor 扩展，名为 "google-dev-tools.google-update-support"，很可能通过编程能力评估启动，并在运行后被删除

"虚假招聘者、粘贴命令的‘验证’步骤，以及对开发者和加密货币持有者的关注，都与公开记录的 Contagious Interview 活动相符，"SafeDep 表示。"这种吻合基于技术手段，并不能证明攻击操作人员的身份。"

该活动的第三个分支涉及 Genians 追踪的另一组攻击活动，即 Operation GitPower。据称，该活动归因于 Kimsuky 组织，涉及使用 Ollama 和 GPT4All 操作本地大语言模型（LLM）环境，生成诱饵文档，并利用这些文档针对政策、学术、国际合作、外交和安全研究领域的专业人士与机构。

钓鱼邮件中包含一个 Windows 快捷方式 (LNK) 文件，启动后会运行 PowerShell 代码，通过 GitHub 的 raw 内容服务获取诱饵文档并打开，同时在后台隐秘下载 AsyncRAT 等其他有效载荷。

Kimsuky 利用 GitHub 进行 C2

该活动此后已演变为针对 乌克兰专家，涉及外交、安全和国际政策领域，利用国际会议邀请以及分析合作请求来引诱目标作出回应，最终以包含恶意 LNK 文件的 ZIP 压缩包形式分发恶意软件。

在至少一个案例中，发现钓鱼邮件会诱骗收件人点击虚假链接，以加入通过 Gmail 举行的 Zoom 会议为借口窃取其 Google 账户凭据。另一种方法则分发假冒的 Zoom 安装程序，该程序除了安装正版应用外， 还会运行可执行任意 PowerShell 脚本并将结果回传的恶意软件。

"这次攻击尤其值得关注，因为它表明 Kimsuky 已将目标范围从传统关注的韩国扩展至乌克兰的关键人士，"Genians 指出，并补充称这些行动大多未获成功。

"Kimsuky 针对乌克兰的攻击可能是网络间谍行动，旨在收集有关战争、朝鲜军队损失程度、战俘审讯与处理进展，以及韩国与乌克兰之间磋商细节的信息。"

Stormshield 的最新发现将这些彼此独立的发现整合为一幅完整且连贯的图景——这是一套由管理平台、受害者追踪控制台和邮件投递基础设施组成的工具集。整个攻击链是一条针对三种环境进行适配的单一感染链——

  • 向目标发送一封宣传工作机会的邮件，诱使其点击链接，并启动“招聘”流程。
  • 该网站伪装成招聘平台，访客可以查看职位列表并提交求职申请。
  • 该网页会在后台对访客进行指纹识别，并使用基于 IP 地址的地理围栏机制，将特定地区（可能是中国）的用户挡在门外。如果访问受到限制，用户看到的是精简版主页，且无法与之进行任何交互。
  • 如果“申请人”满足筛选条件，系统会向他们提供一份申请表，以填写其个人信息。
  • 随后会提示用户输入推荐（或邀请）代码，表明该活动针对的是预先确定的目标，而非广泛受众。如果代码被拒绝，网站会显示三条提示信息之一：“Already used”、“Locked to another IP”和“Invalid code.”
  • 如果代码被接受，候选人会看到一条确认消息，并被指示在 Linux 终端上复制并运行一条命令，作为技术检查的一部分。
  • 命令运行后，会通过 HTTP POST 请求将网页上显示的“nonce”信息发送到远程服务器。在此阶段，不会下载或执行任何文件或脚本到受害者机器上。
  • 该网页正在等待服务器确认，此时会返回一条错误消息，内容为：“Operation timeout. Please try again. Nonce Refreshed.”
  • 当网页显示相同的验证界面，但“Copy”按钮的行为经过修改，恶意命令会被直接注入受害者的剪贴板时，攻击便进入第二阶段。即使目标使用“Ctrl+C”键盘快捷键从网页复制命令，也会观察到相同的模式。
  • The actual command that gets executed depends on the operating system -
    • 在 Windows 上，它会启动 PowerShell，下载并运行名为“v.cmd”的文件
    • 在 Linux 上，它会启动 bash shell，下载并运行名为“u”的文件
    • 在 macOS 上，它会启动 bash shell，下载并运行名为“verify_m”的文件

法国网络安全公司解释道：“这些脚本充当加载器：它们准备执行环境、获取必要的组件，并启动从远程服务器获取的 JavaScript 有效载荷 install_guard.js。”

Trigram dropper 执行阶段

这一准备阶段还包括提取一个 Base64 编码的脚本，用于配置工作目录、建立锁定机制以防止并发安装，并检查是否已安装 Node.js。

如果未找到兼容版本（最低版本为 18），它会根据受感染主机的操作系统及其架构，继续下载并安装 Node.js 20.18.1。随后，它会下载“install_guard.js”，该脚本部署一个信息窃取程序，负责收集系统元数据、浏览器凭据、加密货币钱包以及机器上存在的敏感文件。

整个操作由多层架构提供支持，包括虚假招聘网站（如 Amber Group）、会议邀请 网站和包裹递送网站；托管 JavaScript 并通过 GitLab dead-drop 方式获取的 C2 服务器；以及托管在“170.205.30[.]27:8000”的后端管理系统，该系统通过名为“rms-platform”的平台实现活动管理和受害者追踪。

追踪控制台会记录用户执行的每项操作，同时持续关注机器人访问者和已被下架的仿冒域名。随后，每名“真实访问者”都会被评为“重要”、“中等”或“无用”，这表明系统会根据其价值进行某种筛选。

对与“rms-platform”关联的 API 路由进一步分析表明，该平台能够通过抓取 GitHub 资料来识别潜在目标、发送钓鱼邮件、管理诱饵、发放访问代码、查看和导出收集到的数据，以及监控加密货币钱包。

Trigram 基础设施架构

“这三个层级依赖被滥用的合法服务：GitHub 和 GitLab 用于托管代码和配置；Brevo、Resend、Mailgun 和 Smartlead 用于投递电子邮件；FullStory 用于记录访客会话，”Stormshield 解释道。

“这些追踪控制台并非独立应用：它们与诱饵由同一段 JavaScript 代码交付。同一个代码包会提供给所有访客，而对主机名或 URL 路径的检查将决定显示哪个界面。”

“下面列出了指向 UNK_DeadDrop 和 Kimsuky 的技术指标：

  • eros1030109@gmail[.]com，用于这些控制台的超级管理员账户，与 Operation GitPower 中使用的一个电子邮件地址相符。
  • 0xapp123，一个讨论 Web3 趋势的 Medium 账户，其 列表早在 2022 年 6 月就将“eros1030109@gmail.com”列为联系邮箱地址。
  • silviattech1129_db_user，一个标识符，以用户名形式出现在与“rms-platform”关联的 MongoDB 数据库中，也出现在“antd-img-crop”仓库劫持所用的 GitLab 死信投文件历史记录中，形式为“silviattech1129”。
  • alexlopez-g/rms-platform，一个托管“rms-platform”的备用 GitHub 仓库；该用户曾参与一个名为“Foxtopia-NFT/foxtopia-frontend”的独立项目，其中包含一个“.vscode/tasks.json”文件，镜像了 UNK_DeadDrop 中概述的策略。该提交使用电子邮件地址“harper.danie95@gmail[.]com”签名，该地址曾被用于以虚假工作机会针对 Contra 上的设计师。
  • asteara[.]org，一个被标记为 UNK_DeadDrop“关联基础设施”的域名，曾被用于托管或提供 Trigram 后台服务。
  • pichi_finance_hr，一个冒充 Pichi Finance 人力资源部的 Telegram 账户；Pichi Finance 是一个去中心化金融（DeFi）平台，曾于 2025 年 1 月下线，该账户很可能是通过冒充招聘人员来接近目标的一种方式。

“基于这些基础设施和工具方面的重叠，我们高度确信 Trigram 是 UNK_DeadDrop 集群的延续，同时也展示了其投递策略的演变，”Stormshield 总结道。

“Trigram 的显著特点在于其初始访问途径多样化，以及远程检索最终载荷，而非将载荷直接嵌入被植入木马的仓库中。”

“该系统自动筛选 GitHub 用户作为目标，通过四个电子邮件服务商协调大规模网络钓鱼活动，实时监控每名受害者遭入侵的情况，并通过加密货币钱包清洗所窃取的资金。”
