中文原文

攻击者正使用 Alibaba Cloud 托管自行管理的 AntiFox 实例。AntiFox 是一个开源的智能体式渗透测试平台，被用于攻击 Web 服务和 AWS 环境。

托管 AntiFox 的基础设施被用于各种恶意活动，包括漏洞利用、WebShell 部署、凭据验证、配置发现以及 AWS 密钥收集。

最初作为 ARTEX 0.1.1 的分叉创建，AntiFox 拥有中文界面，可让用户部署 AI 智能体并自动执行常见的渗透测试任务，例如绘制暴露服务以及探测目标端点是否存在漏洞。

Arctic Wolf 的安全研究人员观察到，与 AntiFox 相关的恶意基础设施托管在 Alibaba Cloud 上，并使用有效的 AWS 身份（包括 IAM 用户，在某些情况下还包括被扮演的 EC2 角色）向 Amazon Web Services API 发起经过身份验证的请求。

“在最近观察到的多起入侵事件中，托管 AntiFox 接口的 Alibaba Cloud 系统与针对面向互联网的 Web 服务及相关 AWS 环境的已确认恶意行为有关，”Arctic Wolf 表示。

报告中重点介绍的一个案例涉及在暴露于互联网的 IIS 服务器上部署 ASPX WebShell、执行操作系统命令、访问应用程序设置和数据库连接字符串，以及将配置和日志文件复制到可通过 Web 访问的目录。

研究人员称，攻击者还使用有效的 IAM 凭据和 EC2 角色探测 Amazon Web Services（AWS）端点。在一次入侵中，他们循环使用多个身份，并在约 30 分钟内发出了数百次 API 请求。

尽管其中大多数尝试均被阻止，但攻击者在某些情况下成功获取了生产环境密钥。

在另一起事件中，攻击者使用有效的 AWS 身份读取、复制并删除了 S3 对象。

Arctic Wolf 的报告包含威胁狩猎指南和防御建议，包括将 IIS WebShell 活动与异常 AWS 访问行为进行关联分析，并审查集中爆发的拒绝访问中成功的 API 调用。

研究人员还建议撤销受影响的 AWS 会话和密钥，并轮换通过应用程序文件暴露的凭据。

关于 AntiFox 的发现紧随近期涉及 ARTEX AI 的攻击事件。ARTEX AI 是中国开发的另一个智能体式渗透测试框架，在被用于针对韩国银行的攻击后转为闭源。

CrowdStrike 还将 ARTEX 与一场网络间谍活动联系起来。在该活动中，中国黑客组织Vapor Panda以 14 个国家/地区的 200 多个组织为目标。

目前，AntiFox 仍可在 GitHub 上获取，并已更新至 2.0 版本，改进了该工具记录和报告发现结果的方式。

其发布者禁止将该工具用于实时系统、真实世界渗透测试或安全演练，也禁止将其用于破坏性或非法活动，但他们没有描述任何用于强制执行这些限制的技术控制措施。
