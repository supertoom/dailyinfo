Oracle to Patch 11 Java Flaws Today as Critical OpenJDK RCE (CVE-2026-114938) Report Emerges

正文 · 原文

Oracle is preparing to release security patches for 11 vulnerabilities in Java SE on Tuesday, November 17, 2026, all of which may be exploited remotely without authentication, as separate reports warn of a potentially critical remote code execution (RCE) flaw affecting OpenJDK.

The 11 vulnerabilities carry a maximum CVSS 3.1 severity score of 8.1, according to Oracle's advance security notice. The company has not disclosed their CVE identifiers, affected components, or the individual consequences of exploitation.

The separate OpenJDK vulnerability, tracked as CVE-2026-114938, has reportedly been assigned a CVSS 4.0 score of 9.2 and affects OpenJDK 17.0.6 and later. However, those details remain unconfirmed, and there is no evidence yet that the reported flaw is among the 11 vulnerabilities Oracle plans to patch.

Security firm Calif said in a post on X that it discovered and reported the flaw, which it calls Java4Shell, and that the vulnerability had leaked. Calif said it would publish technical details by 1 p.m. Pacific time on November 17, after Oracle releases a patch.

Security company watchTowr acknowledged the reports in a post on X, but cautioned that the technical details were still unconfirmed.

The vulnerability's CVE record remains reserved without a public description. No official advisory has specified the vulnerable component, precise exploitation requirements, affected version range, or the availability of a fix.

Oracle's ops.java site now lists the replacement builds below as its current releases. Oracle's advance notice, release notes and download page still showed the earlier builds as of 16:59 UTC.

Oracle Prepares Java Security Updates

Oracle advises customers to stop using its current builds of Java 8, 11, 17, 21, 25, and 27 after the November 17 security update and move to the corresponding replacement releases.

The company's Java release notes contain the update guidance, while ops.java lists the following planned builds:

The November security notice identifies the following affected Oracle products and versions:

  • Oracle Java SE: 8u511, 8u511-perf, 11.0.33, 17.0.21, 21.0.13, 25.0.5, and 27.0.1.
  • Oracle GraalVM for JDK: 17.0.21 and 21.0.13.
  • Oracle GraalVM Enterprise Edition: 21.3.20.0.3.
  • Oracle JavaFX: 21.0.13, 25.0.5, and 27.0.1.

Oracle says all 11 Java SE vulnerabilities may be exploited over a network without requiring credentials. That does not necessarily mean they all allow remote code execution or that every application running an affected Java version can be attacked directly.

The advance notice does not identify the vulnerable Java components or specify what an attacker could accomplish by exploiting each flaw.

Oracle also warns that the information may change before the complete security advisory is published.

Critical OpenJDK RCE Report Remains Unverified

The reported CVE-2026-114938 vulnerability introduces a separate concern for organizations operating Java applications, particularly those exposed to the internet.

However, the public information does not establish whether the flaw affects the Java runtime itself, a particular library, or functionality that applications must expose for exploitation to succeed.

Oracle's November notice covers Oracle products and does not establish the patch status of third-party OpenJDK distributions.

The OpenJDK Vulnerability Group, which coordinates security disclosures affecting OpenJDK source code, had not published an advisory newer than October 24 at the time of the earlier review.

Until official details are available, organizations cannot determine from the reported CVE alone whether their Java deployments are vulnerable or which specific update addresses the issue.

Oracle began a monthly security patch cycle on May 28, introducing targeted security releases between its quarterly Critical Patch Updates.

Its Java security update plan, last updated September 10, identified November 17 as the next scheduled monthly release.

Organizations should inventory deployed Java runtimes, identify internet-facing applications, and prepare to test and install the relevant vendor updates once they become available.

This is a developing story. We will update this article as Oracle publishes its full vulnerability advisory and additional verified details about CVE-2026-114938, affected versions, and available patches emerge.
