Fake GTA VI Streaming Client Installs Data-Stealing Malware on Windows PCs

AI 导读

Bitdefender 发现网站 gta6cloud.nexus 以云端串流 GTA VI 为诱饵，通过 ZIP 下载或要求用户在 Win+R 中运行 PowerShell 命令投递恶意程序。

正文 · 原文

Grand Theft Auto VI’s scams have not gone away with the game’s release. Hackread.com has previously reported fake beta downloads, early-access offers and leaked-game scams. Now, scammers are using the lack of an official PC version to deliver a fake streaming client that infects Windows computers with malware.

Bitdefender discovered this new scam after identifying a website (gta6cloud.nexus) claiming its GTA VI cloud client lets PC users stream the game from an Xbox or PlayStation. The catch here is that this site offers a ZIP download but also gives visitors another way to install it- asking them to press Win+R, paste a PowerShell command and run it.

How the attack works

This is a ClickFix attack, where victims are tricked into running commands on their own computers. The command bypasses PowerShell’s execution policy, downloads a script from the site and runs it, eventually fetching and launching GTA6Cloud.exe.

The fake client plays the GTA VI trailer and displays a game-themed page while downloading two more files, loadperf.dll and unlodctr.exe, from velmontriq.net. The files are placed in a hidden folder on the computer.

A fake client hides a much bigger infection

The attackers use DLL sideloading to run their malicious code through unlodctr.exe, which is a legitimate Windows utility. A malicious DLL (loadperf.dll) is placed with it that gets loaded when the program runs. This gives the attackers a way to execute their code through a trusted executable.

Additionally, it contains another payload: PhotoCache.exe. This file is injected into legitimate Windows processes instead of being saved as a separate executable.

The injected payload is a Rust-based information stealer. In its research shared with Hackread.com, Bitdefender explained that it uses legitimate Windows tools and processes to stay hidden while collecting data from infected computers.

This includes browser passwords, cookies and tokens, Discord and Steam data, crypto wallets, AI service credentials and developer API keys. It can also access clipboard data and take screenshots. The malware sends stolen information to nimbuskeepcom and also attempts to connect to 192.30.240.26 on port 7777.

This campaign takes a different approach from previously reported GTA VI scams as it offers PC gamers an opportunity to stream the console version while they wait for an official PC release.

Anyone who ran the command should assume their computer is compromised. Bitdefender advises disconnecting it from the internet, scanning for malware and changing important passwords from a clean device, starting with email.
