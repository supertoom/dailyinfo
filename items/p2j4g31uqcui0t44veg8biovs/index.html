重要漏洞分析

漏洞分析

Microsoft Outlook欺骗漏洞 CVE-2026-124194

Microsoft Office Outlook 是微软办公套件中的邮件与日程管理客户端，负责邮件收发和日历管理，是办公通信的关键组件。

其中存在欺骗漏洞，未认证攻击者发送特制消息文件诱使用户以受影响 Outlook 打开，可能使其连接攻击者控制的网络位置并实施欺骗；该漏洞已发现在野利用，经过评估，该漏洞危害较大，建议用户及时更新微软安全补丁。

Windows Search远程代码执行漏洞 CVE-2026-116928

Microsoft Windows Search Component 是 Windows 的搜索索引组件，被 Exchange Server 用于自动索引邮件附件，对邮件检索与 Exchange 运行至关重要。

其中存在远程代码执行漏洞，未经认证攻击者可通过网络发送含特制附件的邮件，经 Exchange 自动索引触发越界写，可导致代码执行。经过评估，该漏洞危害较大，建议用户及时更新微软安全补丁。

Windows Schannel远程代码执行漏洞 CVE-2026-119952

Windows Schannel 是 Windows 的 TLS/SSL 网络安全组件，负责保障网络通信安全，是关键基础组件。

其中存在远程代码执行漏洞，未经身份验证的远程攻击者可发送特制数据包触发，成功利用可在目标系统执行代码，经过评估，该漏洞危害较大，建议用户及时更新微软安全补丁。

Active Directory域服务特权提升漏洞 CVE-2026-118148

Microsoft Active Directory Domain Services（AD DS）是 Windows Server 的核心目录服务，负责域内认证、授权与目录管理，是企业身份安全的关键基础。

其中存在权限提升漏洞，具备已授权身份的攻击者可通过网络并借助竞态条件利用身份认证不当问题，成功后将权限提升至 SYSTEM。经过评估，该漏洞危害较大，建议用户及时更新微软安全补丁。
