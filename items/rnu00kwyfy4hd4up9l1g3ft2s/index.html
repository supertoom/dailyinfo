Ravie Lakshmanan2026年11月18日企业安全 / 漏洞

The U.S. Cybersecurity and Infrastructure Security Agency (CISA) on Tuesday added a critical security flaw impacting Perforce Puppet, an enterprise infrastructure-as-code (IaC) and configuration management platform, to its Known Exploited Vulnerabilities (KEV) catalog, citing reports of active exploitation.

该漏洞编号为CVE-2026-115731（CVSS 分数：9.4），属于对不可信数据进行反序列化的问题，可能导致远程代码执行。

CISA 表示：“Perforce Puppet Enterprise 的 Puppet 报告处理代码中存在一个对不可信数据进行反序列化的漏洞，允许持有任意由 CA 签发的代理证书的客户端，通过 PUT 请求提交包含特制 rich-data 类型的报告，以服务用户身份在 Puppet Server 上执行任意代码。”

“如果证书颁发机构自动签署请求而未进行严格验证，未经身份验证的网络攻击者便能获取有效证书并利用该漏洞。”

该缺陷影响以下版本 -

  • Puppet Enterprise 2026.0.0 之前的 2026.0.1
  • Puppet Enterprise 2025.0.0 之前的 2025.12.1
  • Puppet Enterprise 2023.8.0 之前的 2023.8.13
  • Puppet Core 9.0.0 之前的 9.1.3
  • Puppet Core 8.x 之前的 8.22.2

Perforce Software 已于 2026年11月3日 在以下版本中修复了该问题 -

  • Puppet Enterprise 2026.0.1（Puppet Core 9.1.3）
  • Puppet Enterprise 2025.12.1（Puppet Core 8.22.2）
  • Puppet Enterprise 2023.8.13（Puppet Core 8.22.2）
  • Puppet Core 9.1.3
  • Puppet Core 8.22.2

值得注意的是，该问题还影响 Puppet 的开源实现 OpenVox，并已在以下版本中修复 -

  • OpenVox Agent 9.3.0 和 8.32.0
  • OpenVox Server 9.2.0 和 8.18.0

Neodyme AG 安全研究员 Alain Rödel 因发现并报告 CVE-2026-115731 以及 CVE-2026-115732（CVSS 分数：9.0）而获得致谢。后者是一个影响 Puppet 和 OpenVox 的严重证书名称授权绕过问题。这家德国网络安全公司补充称，这些问题是在人工智能（AI）辅助和精确引导下发现的。

Neodyme 在本月发布的报告中表示：“其影响在很大程度上取决于 Puppet 服务器的配置以及所使用的编排协议，以及是否启用了这些协议。”“无论配置如何，能够在 Puppet 服务器上实现 RCE 的攻击者都可以获取 CA 签名密钥并冒充其他主机。”

“Puppet 是一款功能强大的软件，通常拥有对企业网络中整个系统集群的完全访问权限。在此类核心且重要的系统上实现远程代码执行，可能导致最坏情况：部署勒索软件、大规模数据外泄，以及可能向网络其他部分横向移动。”

截至撰写时，尚无该漏洞如何在野外被武器化的详细信息。不过，一名为 transdimensia 的 Reddit 用户在 11月4日 的帖子中指出，该漏洞在公开披露后不久便遭到利用。

该用户表示：“在我的系统集群中发现一个配置严重不当的 CA 后，我反向追踪了 [CVE-2026-]115731 入侵过程中的活动。”

建议联邦文职行政部门（FCEB）各机构根据《约束性行动指令（BOD）26-04：基于风险优先处理安全更新》，在 2026 年 12 月 1 日前应用相关修复，以保护其网络。
