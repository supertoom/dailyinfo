中文原文

Cisco Talos 正在追踪 AI 赋能渗透测试框架在真实环境中的使用增长。AI 赋能的渗透测试和红队框架可以自动执行并串联侦察、漏洞测试及后续行动，从而降低攻击者的技能门槛，并在工具被滥用时加快入侵。Talos 已发现这些框架能够对攻击链进行完全自动化；它们不仅使用 nmap 和 nuclei 等免费开源工具，还会利用 Censys 和 Shodan 等互联网映射服务、CAPTCHA 绕过服务、凭据泄露管理服务、住宅代理，甚至哈希破解服务。Hephaestus 就是这种情况，我们曾在上一份报告中提到过它。

尽管这些框架目的相同，但形式各异。有些框架（如 Hephaestus）是命令行工具，只需通过单个脚本即可部署在 VPS 上，并且可以通过 Telegram 完全控制。

PentAGI提供了一个网页界面，用于监控代理活动，并采用完整攻击链图进行设计和监控。Talos 在互联网上发现了超过700 个实例，目前均可访问。HexStrike AI可与许多不同的客户端集成，例如 Claude Code、VS Code，或任何其他支持 MCP 的客户端。

一个备受关注的此类框架 ARTEX 已使威胁行为者能够扩大攻击行动的规模，将过去可能需要熟练团队花费数小时或数天完成的工作，压缩为能够以机器速度展开的活动。

Talos 对与 ARTEX 相关的 IP 地址进行分析后，发现该基础设施上同时存在多种不同工具，进一步印证了 ARTEX 在更广泛且多变的威胁环境中的角色。

AI 赋能框架：新现实

在深入探讨 ARTEX 之前，显然这些框架已成为新的现实。它们的发展很可能包括自主横向移动，随后进行数据识别和窃取。这一趋势的前兆已可在 Volta Infostealer 的受害者优先级划分中看到，Talos 的这份报告对此有详细介绍。未来涉及这些框架的攻击链极有可能最终导致数据外泄和勒索软件启动，且整个过程都将由其中某个框架自主完成。

此类演进给防御者带来了新挑战：

  • 如果在没有任何已知失陷指标（IOC）的情况下，它会缩短发现失陷所需的时间。我们在“建议”部分提供了相关指导，以帮助克服这一挑战。
  • 发现恶意活动后，控制事件至关重要。这些框架运行速度极快，可能使人工操作人员来不及识别、评估并及时采取行动来阻断攻击。

这些框架使缓解和遏制工作，以及经过实战检验的网络安全事件响应计划，成为组织具备韧性的必要条件。防御者使用 AI 能够形成力量倍增器，在响应此类攻击的速度和规模上实现亟需的改进。

ARTEX

ARTEX 是一个由化名 Autumn-27 开发的人工智能渗透测试框架，于 2026 年 7 月发布在 GitHub 上。操作员向其提供目标和任务，规划器智能体会将任务拆解为多个子任务，工作智能体使用安全工具执行这些子任务，该框架则在共享图谱中记录资产、发现和进度。ARTEX 可以使用不同的大型语言模型（LLM），并且在任务开始后仅需操作员提供相对少量的输入。它是为授权安全测试而设计的，但最近的公开报道记录了它在发布数周内即被用于犯罪活动和定向入侵活动。

需要注意的是，ARTEX 并未原生捆绑任何传统命令与控制（C2）框架，不过模型上下文协议（MCP）扩展层意味着操作员可以添加任何兼容的工具服务器。这也解释了我们为何观察到多个 ARTEX 实例与 VShell、GoPhish 和 AdaptixC2 等工具一同部署。

在攻击活动中利用 ARTEX 的威胁行为者

多个动机和技术手法各异的威胁行为者已被发现与 ARTEX 活动有关；其以开源软件形式发布，随后各分支和副本持续可用，几乎肯定促进了不同行为者群体对该工具的采用。公开报道（见下文）和 Talos 观察表明，ARTEX 主要被以牟利为目的的网络犯罪分子以及与中国有关联的威胁行为者使用。

已观察到的 ARTEX 活动涵盖机会主义扫描和凭据窃取，以及定向入侵和供应链活动，目标横跨多个地区的金融服务、加密货币、政府、电信、国防、制药、半导体和科技组织。报告的结果各不相同，既有未遂尝试，也有已确认的失陷和数据外泄。

已报告的活动：

  • VAPOR PANDA：CrowdStrike 将一场利用 ARTEX 针对中国关联行为者 VAPOR PANDA 的间谍活动（始于 2026 年 10 月 17 日）归因于该行为者。该行为者利用 ARTEX 攻击了至少 14 个国家的 200 多个组织，目标包括政府部委、电信提供商，以及国防、制药、半导体、核能和金融行业的组织。CrowdStrike 确认了九家组织在失陷后的活动，并报告了针对另外至少 12 家组织的凭据扫描和密码喷洒活动。
  • Storm-0940：Microsoft 将由 ARTEX 驱动的活动归因于 Storm-0940，并评估其为一个“与中国国家结盟的行为者”。在 ConnectWise 应用凭据失陷后，Storm-0940 使用 ARTEX 加快针对超过 2,250 个下游 Microsoft 365 租户的登录尝试，后续活动涉及 Microsoft Graph、应用凭据和权限变更。
  • Storm-3358：Microsoft 还报告了以牟利为目的、针对金融机构的 Storm-3358 活动，这些活动主要发生在东南亚，并将该集群描述为以柬埔寨为基地。其 ARTEX 活动包括利用面向互联网的系统以及部署远程访问木马（RAT）。Cisco 对该集群的观察结果与 Microsoft 的发现一致。我们发现，与该集群关联的 IP 地址在 2026 年 10 月进行了资产扫描。
  • 身份未明的讲中文威胁组织：CrowdStrike 报告了一场针对韩国金融机构的未归因活动，造成了数据外泄；其以中等置信度评估称，该行为者是讲中文的，且以牟利为目的。Talos 另行分析了这些攻击中与行为者关联的目录，发现了与 ARTEX 相关的构件，包括目录列表和命令历史记录引用。该归档不包含 ARTEX 可执行文件或源代码树，因此这些构件支持其与 ARTEX 环境存在关联，但单凭这些构件无法证明完整框架已存在或已用于成功攻击。
  • 身份未明的犯罪威胁行为者：Check Point Research 记录了其他犯罪操作者实施的多起行动，其目标包括窃取代码签名证书和游戏账户凭据，以及试图窃取加密货币。
  • 未归因的 ARTEX 关联活动：Microsoft 报告称，有代理使用 ARTEX 搜索公开的 GitHub 仓库，以寻找泄露的凭据，包括应用程序凭据和 AI 服务 API 密钥，然后利用发现的机密信息开展后续活动。在一个案例中，该代理在从搜索 GitHub 到从 Azure Key Vault 外泄数据的过程中仅用了五分钟。Datadog 另行观察到 AWS 环境中的 ARTEX 活动，涉及已被攻陷的长期访问密钥和公开的 Cognito 用户池。这些活动包括搜索云日志中的财务信息和机密信息、注册账户、收集令牌，以及尝试枚举云资源。Datadog 未将这些观察结果归因于任何具名行为者。最后，Dosu 披露了一起独立的 ARTEX 相关事件，其中攻击者从创建账户和利用授权漏洞，推进到访问涉及集成、CI、数据库和云系统的资源。Dosu 报告称，该攻击者在 90 分钟内生成了超过 80,000 个请求。

观察到的战术、技术和程序

在各类活动中，ARTEX 一直充当编排层，用于快速并行地开展侦察和入侵活动，使行为者能够将泄露的凭据或应用程序弱点转化为更广泛的访问权限、持久性和数据窃取。操作者通常设定目标并提供有限的方向指引，而代理则根据目标调整其方法。由此产生的行为因活动而异，不应被视为一套单一固定的作战手册。

规划与侦察： ARTEX 操作员提供目标，并可跨多个目标分派任务；其规划代理和工作代理随后可以并行开展活动，并记录结果以供后续任务使用。Check Point 的审查发现，代理在初始目标设定后通常交互很少，而VAPOR PANDA则被观察到在选定决策节点引导代理。已报告的侦察活动包括扫描面向公众的应用和服务、测试身份验证流程、枚举云资源，以及在公共代码仓库中搜索暴露的密钥。ARTEX 活动可能产生多样化的请求和快速重试，但工具特征和用户代理可能发生变化，因此应将其视为辅助性指标，而非确定归属的依据。

初始访问与漏洞利用：已报告的 ARTEX 攻击活动中的初始访问方式包括密码喷洒、使用暴露或被盗的凭据，以及利用应用程序和授权缺陷。在这些攻击中被利用的观察到的弱点包括薄弱或硬编码的管理员凭据、缺失的 API 身份验证、不安全的直接对象引用、命令注入或模板注入漏洞、匿名文件上传和服务器端请求伪造弱点，以及缺乏针对权限提升的防护。这些观察到的战术表明，ARTEX 能够自动发现并利用 Web 应用程序和身份系统中的弱点，但具体技术取决于目标和攻击活动。

凭据访问与云滥用：多次 ARTEX 攻击利用凭据的发现或滥用，作为从初始立足点通往云资源和下游系统的桥梁。例如，观察到代理在公共 GitHub 仓库中搜索凭据和 API 密钥，然后使用暴露的密钥开展后续活动，包括访问 Azure Key Vault。另一次攻击活动涉及 AWS 活动，包括匿名 S3 请求、被攻陷的长期访问密钥、CloudWatch 日志搜索和公开的 Cognito 用户池。在 Cognito 活动中，代理注册账户、收集令牌，并尝试枚举 AWS 资源。Microsoft 的 Storm-0940 报告描述了被攻陷的应用程序凭据如何被用于访问下游 Microsoft 365 租户，并通过 Microsoft Graph 开展后续活动。

权限提升、持久化与横向移动：观察到的后续行为包括更改应用程序权限、滥用令牌或凭据、访问特权账户，以及部署 Web shell 或 RAT。CrowdStrike 描述了 VAPOR PANDA 使用历史身份验证材料伪造管理员令牌、读取邮箱，并利用恢复的 VPN 信息接入内部网络。其报告还提到了终端安全发现、Web shell 部署，以及在该攻击活动其他部分使用BLOODALCHEMY后门。Microsoft 报告称，Storm-3358部署 WISP、VShell 和 AdaptixC2 以实现持久化和横向移动。值得注意的是，这些行动是特定行为体的示例，而非 ARTEX 的默认行为。

收集、外泄与影响：如上述活动所详述，威胁行为者的目标包括凭据和数据窃取、获取经济利益以及破坏供应链。观察到的影响从访问云端机密和邮箱数据，到使用被入侵的应用程序触达互联环境。

在 ARTEX 相关基础设施上观察到的并发工具  

ARTEX 是一种智能体渗透测试平台，可在工作流中指挥和协调其他安全工具。Talos 发现了 2,500 多个 ARTEX 相关的 C2 IP 地址，随后分析了这些系统上观察到的工具，并将其观察时段与 ARTEX 进行比较。以下工具按重叠时段内观察到的情况由多到少排列。尽管同时出现并不能确定 ARTEX 调用了每一种工具，也不能确定所有工具均由同一行为者操作，但此列表有助于确定针对潜在 ARTEX 相关活动的防御措施优先级。

  • ScopeWeaver：ARTEX 的本地化衍生版本，已重新品牌化并翻译成英语和韩语
  • AntiFox：增强交付能力的 ARTEX 版本，已就地捕获其复现过程，并提供易于了解的攻击链发现结果
  • CyberStrikeAI：一款基于 AI 的安全测试平台，可协调智能体和外部工具来执行自动化评估
  • PentAGI：一款开源、自托管平台，使用多个 AI 智能体在隔离环境中规划并执行渗透测试
  • ScopeSentry：一款资产发现和漏洞扫描平台，由与 ARTEX 相同的匿名作者开发
  • VShell：一款跨平台 C2 框架，主要用于后渗透活动；鉴于其具备重叠的进攻能力，常被拿来与 Cobalt Strike 比较
  • Nessus：Tenable 的漏洞评估扫描器，用于识别系统和网络中的漏洞与配置问题
  • Interactsh：ProjectDiscovery 的开源工具，用于检测带外交互，这些交互可揭示由外部回调触发的漏洞
  • Acunetix：一款自动化 Web 应用程序安全扫描器，可爬取网站并测试漏洞
  • Fscan：一款开源内网安全扫描器
  • Net Proxy Server (NPS)：一款开源代理和隧道服务器，旨在提供对网络边界之后服务的访问
  • AdaptixC2：一款可扩展的 C2 和后渗透框架，旨在用于获得授权的红队评估
  • Mimikatz：一款开源后渗透工具，用于从 Windows 内存中提取明文密码、哈希、PIN 码和 Kerberos 票据
  • Cobalt Strike：Fortra 的商业对手模拟和红队平台，包含后渗透活动能力
  • Gophish：一款用于开展和跟踪钓鱼模拟的开源平台
  • Chisel：一款开源 TCP/UDP 隧道工具，通过 HTTP 传输连接并使用 SSH 对其进行保护；它还可以通过代理或反向隧道配置中继流量

建议 

对于通过可适应的工作流和支持工具来追求操作员定义目标的框架，相关活动会因目标和操作员而异。防御方应专注于根本性措施，限制攻击的速度和规模，减少暴露面，保护凭据和云身份，并快速检测可疑活动。

  • 监测快速、异常的活动：关联身份验证、云 API 和端点日志，以检测高流量请求、不熟悉的应用程序、令牌使用和权限变更。
  • 加固面向公共的系统：及时修补漏洞、删除默认凭据，并测试身份验证和授权控制。
  • 防御凭据攻击：对远程访问和特权访问强制要求多因素身份验证 (MFA)；设置速率限制，并对密码喷洒模式发出警报。
  • 强化端点检测：启用端点检测与响应 (EDR) 防篡改保护和传感器健康监测，对服务或配置变更发出警报，并保留独立的遥测数据以调查试图规避防御的行为，正如 ARTEX 已展示的 EDR 绕过能力。
  • 保护暴露的秘密：扫描公共代码仓库中的凭据和 API 密钥；立即撤销并轮换任何已暴露的秘密。
  • 限制身份和应用程序权限：对服务账户和应用程序应用最小权限原则，限制用户同意权限，并审查权限或角色变更。
  • 保护云资源：禁用不必要的公共或匿名访问，并审查存储、身份和秘密服务是否存在暴露。
  • 迅速检测失陷后活动：维护针对 Web shell、远程访问工具、C2 流量和横向移动的端点与网络检测；将工具签名视为线索，而非唯一的检测方法。
  • 做好快速隔离准备：预先制定撤销凭据和令牌、禁用可疑应用程序以及隔离受影响系统的流程。

覆盖范围 

ARTEX 是一种编排框架，恶意行为者可以利用它大规模、高速度地调用现有的攻击工具。Talos 可检测我们见过被部署的许多最常用工具，包括 Mimikatz、Cobalt Strike 和 Acunetix 等较旧工具。鉴于篇幅所限，逐一列出对这些工具的完整覆盖并不现实，请参阅这份 Snort 和 ClamAV 覆盖示例，其中展示了我们检测与 ARTEX 相关双重用途工具的某些方式。Talos 将继续监测利用 ARTEX 的攻击，以发现新部署的工具。
