攻击者借 GitHub 分发仿冒 ChatGPT 与 Claude 应用，Yoba 恶意软件借 DLL sideloading 安装挖矿程序

Fake ChatGPT and Claude Apps Use Signed Executables to Install Yoba Malware

正文 · AI 翻译
中文原文

假冒的 ChatGPT 和 Claude 应用通过 GitHub 传播 Yoba 恶意软件，利用已签名的可执行文件在 Windows PC 上加载加密货币挖矿程序，并支持投放其他有效载荷。

攻击者正通过 GitHub 分发假冒的 ChatGPT 和 Claude桌面应用，并将恶意软件与由 OpenAI 和 Anthropic 签名的真实可执行文件打包在一起。Check Point 的研究披露了这一活动；其分析人员观察到，Windows 计算机上一个能够投放其他恶意软件的加载程序会安装加密货币挖矿软件。

在研究中，Check Point 将该活动称为 Yoba，并描述了 虚假的 GitHub 项目，这些项目声称提供“GPT-5.6 Sol”、“GPT-6 Astra”和“Claude Opus”桌面应用。攻击者将恶意软件与真实的已签名可执行文件捆绑在一起，但并未攻破 OpenAI 或 Anthropic。

GitHub Pages 将用户引向恶意下载

攻击者通过 GitHub 项目页面（包括 GitHub.io）推广这些假冒应用，这些页面描述其功能，并链接到托管在 GitHub Releases 上的 ZIP 下载文件。推广页面和下载文件均保留在一个用户熟悉的平台上，使这些产品对正在搜索 AI 软件的人而言显得更可信。

其中一些页面出现在 Google 搜索结果的前列。Check Point 未发现 GitHub 星标或分叉数量被人为抬高的迹象，但表示这些措辞和搜索可见性表明，攻击者对页面进行了优化，以通过 Google 吸引用户。

任何下载并运行该软件包的人都会启动一个真实的、已签名的应用程序可执行文件。攻击者在其旁边放置了一个名为 winmm.dll 的恶意文件，随后该应用程序通过一种称为 DLL 侧加载的技术加载该文件。尽管可执行文件的签名有效，但它加载的文件中包含恶意软件。

恶意软件要求管理员访问权限

研究人员将恶意 DLL 命名为 YobaDropper；它会先检查执行环境，然后再继续运行。如果没有管理员权限，它会显示一条请求提升权限的消息并退出。

它还会排除包括俄语和白俄罗斯语在内的多种键盘语言，而乌克兰语仍然符合条件。然而，键盘设置仅是一种筛选机制，不能可靠地识别用户所在的位置。

安装后，计划任务会在启动三分钟后运行一个复制出的 Windows 可执行文件。该程序会加载 YobaLoader，使感染能够在重启后继续存在。

Telegram 图片有助于定位下一个有效载荷

根据 Check Point 的详细技术研究，YobaLoader 会下载某个 Telegram 频道的头像，并使用其最后 50 个字节生成域名。更改图片即可让运营者更改该目的地。

随后，加载程序会查询 Google 的 DNS-over-HTTPS 服务，以获取存储在 DNS TXT 记录中的指令。它会先验证并解密这些指令，再获取加密的有效载荷；在所分析的投递链中，有效载荷通过 Catbox 投递。

研究人员观察到加密货币挖矿软件 XMRig 通过 Tor 通信。它可以在用户使用计算机时暂停，从而降低明显的资源消耗引起用户注意的可能性。该加载器还支持 Windows 可执行文件和 PowerShell 有效载荷，因此其功能并不局限于挖矿。

文件已签名并不意味着非官方安装程序安全

Check Point 建议从经过验证的来源获取 AI 工具，并限制运行来自未知发布者或存储库的应用。熟悉的产品名称、GitHub 下载页面和已签名的可执行文件都可能同时出现在同一个恶意包中。

该活动针对的是选择从何处下载 AI 工具的人群。在安装前检查来源，尤其是在授予管理员权限之前进行检查，是用户可以采取的实际措施，有助于避免这些假冒应用。
