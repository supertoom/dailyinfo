中文原文

QNAP 敦促用户将 Plex Media Server 更新至 QNAP App Center 中可用的最新版本，因为黑客正在利用 Plex2Shell 漏洞链。

该厂商表示，已收到多起疑似入侵事件的报告，涉及客户的网络附加存储（NAS）设备。

“QNAP 已收到部分用户的报告，称其 NAS 上的 Plex Media Server 似乎已通过 [Plex2Shell] 漏洞遭到入侵，QNAP 技术支持正在协助受影响的用户，”该公司在今天发布的安全公告中表示。

Plex2Shell 是 Plex Media Server 中的四个漏洞组成的漏洞链，编号分别为 CVE-2026-96652、CVE-2026-96654、CVE-2026-96655 和 CVE-2026-96656。

安全研究员 Zach Main 发现并向 Plex 报告了这些漏洞，时为 7 月 27 日。10 月 16 日完整技术细节公开后不久便开始遭到利用。

CISA 于 2026 年 10 月 20 日将这四个漏洞全部加入其已知被利用漏洞目录，敦促联邦机构在三天内升级至 Plex 1.43.3.10861 或更高版本，并给予最高优先级。

QNAP 的 NAS 设备是内置存储的专用计算机，使用户能够跨网络存储、访问和共享文件。它们通常用于备份计算机和存储媒体文件。

用户还可以通过 QNAP App Center 安装应用程序来扩展设备功能，例如 Plex Media Server，它可直接从 NAS 驱动器串流电影、电视节目和音乐。

QNAP 建议用户将 Plex Media Server 更新至通过 QNAP App Center 提供的最新版本，目前为 1.43.3.10861，以防范 Plex2Shell 攻击。

“QNAP 产品安全事件响应团队（QNAP PSIRT）已确认，这些漏洞仅存在于 Plex Media Server；QTS、QuTS hero 和其他 QNAP 操作系统本身不受影响，”该厂商表示。

需要用户采取行动

QNAP 表示，如果用户运行的是暴露在公共互联网上的易受攻击 Plex 服务器，则应将其 NAS 设备及所有个人内容视为已遭入侵。

该厂商警告称，立即更新不会移除攻击者已经安装在设备上的任何有效载荷。

建议采取的措施是检查安全公告中分享的入侵迹象，对操作系统（QTS 或 QuTS hero）执行全新重装，然后重置 Plex 和 NAS 凭据。

不需要远程访问 Plex 的用户应禁用相关功能并停止转发 32400 端口。需要远程访问的用户则建议通过 VPN 连接。

QNAP 已发布详细的分步修复指南，介绍如何执行上述操作。

该公司还提供对疑似入侵事件日志的调查服务，用户可通过 QNAP 技术支持门户提交日志。
