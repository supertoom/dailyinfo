CERT-FR 披露 Microsoft Visual Studio 安全策略绕过漏洞 CVE-2026-118147

Vulnérabilité dans Microsoft Visual Studio (02 novembre 2026)

AI 导读

Microsoft Visual Studio 存在安全策略绕过漏洞 CVE-2026-118147，可导致攻击者绕过安全策略。受影响版本包括 Visual Studio 2017 15.9 之前、2019 16.11 之前、2022 17.14 之前及 2026 18.11 之前的版本；CERT-FR 建议参考 Microsoft 2026 年 10 月 30 日安全公告获取修复补丁。

Avis du CERT-FR

Objet : Vulnérabilité dans Microsoft Visual Studio

Gestion du document

Référence CERTFR-2026-AVI-1441
Titre Vulnérabilité dans Microsoft Visual Studio
Date de la première version02 novembre 2026
Date de la dernière version02 novembre 2026
Source(s) Bulletin de sécurité Microsoft CVE-2026-118147 du 30 octobre 2026

Une gestion de version détaillée se trouve à la fin de ce document.

Risque

  • Contournement de la politique de sécurité

Systèmes affectés

  • Microsoft Visual Studio 2017 version 15.9 antérieures à 15.9.84
  • Microsoft Visual Studio 2019 version 16.11 antérieures à 16.11.62
  • Microsoft Visual Studio 2022 version 17.14 antérieures à 17.14.44
  • Microsoft Visual Studio 2026 version 18.11 antérieures à 18.11.3

Résumé

Une vulnérabilité a été découverte dans Microsoft Visual Studio. Elle permet à un attaquant de provoquer un contournement de la politique de sécurité.

Solutions

Se référer au bulletin de sécurité de l'éditeur pour l'obtention des correctifs (cf. section Documentation).
