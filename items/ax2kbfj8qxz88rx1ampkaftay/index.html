漏洞分析

组件介绍

Microsoft Windows（官方名称 Microsoft Windows，由微软公司开发的闭源桌面及服务器操作系统）是全球部署最广泛的操作系统，内置远程访问 API（rasapi32.dll）管理拨号与 VPN 连接，RasMan 服务以 LocalSystem 运行并经 netman 提供网络连接管理接口。Windows 为系统组件，随系统发行。在本次漏洞中，受影响的 Windows 版本在 RAS 挂断路径加载用户电话簿中用户可控的 CustomDialDll，导致本地低权限用户可提升至 SYSTEM 权限。

漏洞简介

2026年11月24日，深瞳漏洞实验室监测到一则Microsoft Windows组件存在权限提升漏洞的信息，漏洞编号：CVE-2026-119853，漏洞威胁等级：高危。

Windows 远程访问 API（rasapi32.dll）存在不可信搜索路径漏洞（CWE-426）。每用户电话簿 rasphone.pbk 中的 CustomDialDll 可由用户任意指定；自定义拨号器的信任校验仅在拨号阶段进行，连接建立后用户即可改写该字段。挂断时，以 LocalSystem 运行的 RasMan 服务经 netman 调用 rasapi32!DwCustomHangUp，用 LoadLibraryExW 加载用户指定 DLL 并以 SYSTEM 权限调用其 RasCustomHangUp 导出，本地低权限用户可借此以 SYSTEM 权限执行任意代码。

解决方案

官方修复建议

通过Windows自动更新或手动安装补丁修复此漏洞修复方式：

启用Windows自动更新检测并安装最新安全更新，或手动下载安装对应系统补丁

下载链接：https://msrc.microsoft.com/update-guide/vulnerability/CVE-2026-119853

临时修复建议

  • 关闭未使用的功能模块，减少潜在攻击入口。

  • 遵循最小权限原则，严控各类敏感操作权限范围。

  • 非必要不暴露服务到公网，限制访问源为可信范围。

  • 定期更新系统及各类组件至安全版本，及时修补已知隐患。
