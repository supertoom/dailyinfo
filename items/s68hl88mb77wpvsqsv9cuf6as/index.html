危害描述：攻击者利用 save/restore 机制造成释放后使用（Use-After-Free），获得写任意地址的原语，进而破坏 -dSAFER 状态并执行任意代码。成功利用该漏洞后可在 Ghostscript 进程权限下执行系统命令。

01

漏洞详情

>>>>

影响组件

Ghostscript 是由 Artifex Software 开发的开源解释器，主要用于处理 PostScript、PDF、PCL 等页面描述语言，广泛应用于打印系统、文档转换、图像处理及预览生成场景。它可作为独立工具运行，也可被 ImageMagick、Pillow、CUPS、PHP Imagick 等组件调用，是许多 Linux 发行版和服务器应用的基础依赖组件。其 -dSAFER 模式旨在限制文件访问与命令执行，以隔离不可信文档。

>>>>

漏洞描述

近日，奇安信CERT监测到官方修复Artifex Ghostscript -dSAFER 沙箱绕过漏洞(CVE-2026-125396)，该漏洞源于 gs_fonts.ps 中的 .putgstringcopy 过程在调用特权操作符 .forceput 前未对操作数类型进行检查。攻击者可构造恶意 PostScript 或 PDF 文档，故意触发类型错误，并通过自定义错误处理程序恢复可用的 .forceput 引用。随后利用 save/restore 机制造成释放后使用（Use-After-Free），获得写任意地址的原语，进而破坏 -dSAFER 状态并执行任意代码。成功利用后，攻击者可在 Ghostscript 进程权限下执行系统命令。目前该漏洞PoC和技术细节已公开。在实际部署中，该漏洞可通过公开上传、邮件附件、打印服务等路径实现远程触发，影响面极广。建议客户尽快做好自查及防护。

>>>>

利用条件

1.文档处理流程启用或默认调用 Ghostscript（常见于打印、缩略图、预览、转换服务）。

2.攻击者能够将恶意 PostScript/PDF 文档提交到该处理流程（上传表单、邮件、打印队列等）。

3.处理时通常以 -dSAFER 模式运行。

02

影响范围

>>>>

影响版本

Artifex Ghostscript < 10.08.0

>>>>

其他受影响组件

所有在 -dSAFER 沙箱模式下处理不受信任 PostScript/PDF 文档的 Ghostscript 部署环境均受影响，包括打印服务（CUPS）、邮件附件缩略图（Roundcube）、文件上传/预览（WordPress 插件、MediaWiki、DokuWiki 等）、文档转换管道（ImageMagick、Pillow 等）及云端文档渲染器。

处置建议

>>>>

安全更新

官方已发布安全补丁，请及时更新至最新版本：

Artifex Ghostscript >= 10.08.0

下载地址：

https://www.ghostscript.com/releases/index.html

对于使用发行版包的系统，安装对应安全更新：

Debian 13：10.05.1~dfsg-1+deb13u2 / +deb13u3 及以上

Ubuntu：参考 USN-8949-1 对应版本

openSUSE Tumbleweed、Arch、Alpine、Gentoo 等已提供 10.08.0 包

重启依赖 Ghostscript 的服务（CUPS、PHP-FPM、预览/转换工作进程、容器等）。

容器镜像与内嵌 Ghostscript 的应用需重新构建。

WordPress 用户升级至 7.0.4 或对应分支修复版本；Roundcube 应用相关加固更新。

临时缓解措施：

1.限制仅处理来自可信来源的文档，禁用或严格控制公共上传、预览、打印队列与邮件附件自动渲染功能；

2.以最低权限运行 Ghostscript 相关进程，并结合容器/沙箱隔离；

3.对图像处理库配置严格策略，避免不必要的 PostScript/PDF 委托；

4.监控渲染进程异常子进程创建、异常错误日志与命令执行行为；

5.在无法立即升级的环境中，暂时禁用相关预览/转换功能或增加文件类型与内容校验。
