中文原文

ESET 发现与俄罗斯有关联的 APT 组织 Turla 正在哈萨克斯坦和罗马尼亚的政府 Exchange 服务器上使用一套名为 Cereal 的新工具集。

ESET Research 详细介绍了一套此前未有公开记录、名为 Cereal 的工具集，该工具集旨在 Microsoft Exchange 服务器上运行。研究人员于 2025 年 11 月 28 日在哈萨克斯坦的一个政府机构发现了它，随后又在罗马尼亚的一个政府机构发现了它；该罗马尼亚机构已于 12 月 23 日遭到入侵。研究人员发现，在罗马尼亚，该工具集被设置用于识别发往或来自 NATO 和 European Union 的电子邮件。ESET 高度确信其归属于 Turla APT 组织（又称 Secret Blizzard、 Snake、 Uroburos、 Waterbug、 Venomous Bear 和 KRYPTON） ，该组织 至少自 2004 年起一直活跃 ，目标包括中东、亚洲、欧洲、北美和南美以及前苏联加盟国的外交和政府组织及私营企业。

据 U.S. Cybersecurity and Infrastructure Security Agency（CISA）称，这个与俄罗斯有关联的威胁行为者被评估为隶属于俄罗斯 Federal Security Service（FSB）第 16 中心。

Cereal 这一名称源自序列化（serialization），即程序用于打包数据和代码以便传输的过程。该工具集主要由模块化 .NET 代码构成，这些代码以加密形式传入，在内存中自行解包，并且在磁盘上几乎不留下任何文件。只有第一个加载器会保存为常规 .NET 文件。

一项不同寻常的特点是，ESET 未发现由攻击者控制的服务器。主后门 CerealNeuron 不会连接外部服务器，而是在受害者的 Exchange 服务器上运行，并通过形似正常 Outlook Web Access、Autodiscover 和 ActiveSync 流量的网页路径等待命令。这使得相关活动很难在防火墙日志中被发现。如果请求未正确加密或未通过安全检查，服务器只会返回一个外观正常的 Exchange 错误页面。

“CerealNeuron 是一种被动后门，本身不含内置命令，但能够执行网络请求中 CerealRunner binaries 所包含的程序集；”ESET 发布的分析 如此写道。

“其后果十分严重：

  • 恶意流量与合法的 Exchange Web 服务流量共存——而这正是防御者最不可能拦截的一类流量。”
  • 没有可供发现、拦截或关闭的专用 C&C 基础设施。受害者自身面向互联网的 Exchange 服务器就是操作人员可访问的控制点。
  • 基于网络的追踪受到严重限制。我们无法确定操作人员使用的入口 IP 地址。他们可能是直接连接、通过匿名化服务连接，或者从其他已遭入侵的主机发起连接。”

因此，防御者没有可供拦截或关闭的外部服务器。ESET 甚至无法确定攻击者的 IP 地址。第二个版本名为 CerealHermit，不具备网络功能，而是直接从磁盘读取加密的命令文件。这意味着部分受害者面临攻击者访问其系统的两种独立途径。

命令就像一次性程序。操作人员并非使用带内置菜单的单一后门，而是将每项任务作为由名为 CerealRunner 的组件携带的小型已编译 .NET 程序发送。任务包括通过 Exchange Web Services 提取邮箱、查询 Active Directory、执行 WMI 查询、提取本地存储的 Windows 凭据以及处理文件。ESET 发现了大量几乎相同的二进制文件，因此认为操作人员运行着一套会自动构建它们的内部系统。

.NET 技巧使其与众不同。第一个加载器滥用一项极少使用的功能，在任何 .NET 代码运行之前执行本机代码，因此分析人员看到的入口点毫无作用。操作人员还将其放入 Windows 管理文件夹，名称包括 ncobjapi.dll；并放入 .NET 本机映像缓存，名称包括 Microsoft.Exchange.Search.Mdb.ni.dll，从而让受信任进程代为加载。

邮件窃取是 ESET 称为新出现的部分。模块 CerealBox 将自身注入 EdgeTransport.exe，即处理邮件流的进程，并包装已在内存中运行的传输代理处理程序。

报告继续称：“CerealBox 采用了一种更隐蔽的方法。它并不注册自身，而是直接注入 EdgeTransport.exe，即处理邮件流的 Exchange 进程。” “然而，要到达这一位置并不简单：CerealBox 通过一条由嵌套 Cereal 组件构成 intricate 链投递。”

它不会注册新的代理，因此 Exchange 的配置中不会出现任何异常。邮件需携带 .doc、.docx 或 .pdf 文件，并匹配硬编码的发件人、收件人、主题词或文件名列表，才会符合条件。选定的邮件会被压缩、加密并暂存在磁盘上，操作人员随后会收集并删除它们。

受害者与 Turla 惯常的目标相符。据 ESET 称，自 2022 年以来，该组织所针对的国家中约有 70% 曾是苏联加盟共和国，或曾与莫斯科关系密切的欧洲国家。对罗马尼亚北约和欧盟电子邮件系统的关注，与俄罗斯长期以来的情报利益相符。ESET 还将哈萨克斯坦境内的攻击与该国自 2026 年 1 月以来驱逐俄罗斯流亡者的事件联系起来。该国境内的活动于 1 月 15 日增加，即旧新年假日后的第二天。

运行 Exchange 的组织应检查标准配置中可能看不到的可疑活动。这包括 Windows 管理文件夹中的异常 DLL 文件、本机映像缓存中的意外文件，以及针对后门所使用的三个 Web 路径的可疑请求。Exchange 传输代理列表干净，并不一定意味着邮件系统未遭入侵。

报告总结称：“Cereal 工具集是一件经过精心打造、用于长期隐蔽网络间谍活动的工具。” “Cereal 工具集表明，对 Turla 而言，Exchange 服务器不仅是邮件服务器——它们还是持久的收集点、内部执行枢纽，以及隐藏复杂 .NET 技术的合适环境。”
