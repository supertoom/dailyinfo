Ravie Lakshmanan2026年11月11日网络攻击 / 勒索软件

据观察，威胁行为者在2026年10月针对 Qlik Sense 服务器发起攻击，试图针对多个环境投放 PowerShell 反向 shell 命令，但未能成功。

Cynet 的 CyOps 和研究团队表示，他们在2026年10月发现了一个时间窗口仅略超过三分钟的针对数家欧盟客户的可疑活动。

研究发现，该活动与 Arctic Wolf 记录的2023年11月攻击活动存在一定程度的重叠；在那次活动中，与 CACTUS 勒索软件行动有关的威胁行为者很可能利用了当时新披露的 Qlik Sense 漏洞，以获取目标环境的初始访问权限。

相关漏洞已由 Qlik Sense 分别于2023年8月和9月修补，影响 Windows 版 Qlik Sense Enterprise：

  • CVE-2023-41265（CVSS 分数：9.6）——一项 HTTP 隧道漏洞，可能导致权限提升，并允许攻击者在托管存储库应用程序的后端服务器上执行 HTTP 请求。
  • CVE-2023-41266（CVSS 分数：8.2）——一项路径遍历漏洞，可能允许未经身份验证的远程攻击者生成匿名会话，并向未经授权的端点发送 HTTP 请求。
  • CVE-2023-48365（CVSS 分数：9.6）——一项未经身份验证的远程代码执行漏洞，源于对 HTTP 标头验证不当，允许攻击者通过隧道传输 HTTP 请求来提升权限，并在后端服务器上执行 HTTP 请求。

值得注意的是，CVE-2023-48365（又称 DoubleQlik）是针对 CVE-2023-41265 的不完整修复。

在2023年11月的 CACTUS 勒索软件攻击活动中，曾观察到威胁行为者利用这些漏洞建立立足点并下载额外载荷，通过部署 ManageEngine Unified Endpoint Management and Security（UEMS）、AnyDesk 和 Plink 来建立持久化及远程控制。

Cynet 最新检测到的活动涉及使用一条包含单行反向 shell的 PowerShell 命令，该命令连接到端口 4455 上的"45.115.26[.]23"。目前尚不清楚用于入侵 Qlik Sense 服务器的确切漏洞。

这家网络安全公司表示："该命令在 scheduler.exe 下执行，与2023年的 Cactus Qlik 入侵活动相似。"

尽管生成反向 shell 的尝试被阻止，但 Cynet 在受控环境中对该反向 shell 进行测试后发现，其交互式通信通道用于开展侦察并投放 PowerShell 脚本，以实现持久化。

这是通过一个连接到"45.115.26[.]23:4456"的 Windows Go 反向 shell 实现的。随后，该后门用于查找与 Apache ActiveMQ 相关的正在运行的进程。在 Linux 上，该恶意软件还会尝试收集系统信息，并读取"/etc/shadow"和"/etc/passwd"文件。

该 PowerShell 脚本的第二个变体尝试安装 OpenSSH，并创建一个名为"WinUpdCheck"的计划任务，每五分钟启动一次写入"C:\ProgramData\ssh\winc.ps1"的 PowerShell 反向 shell。 

“如果 sshd 仍然不可用，它会从暂存服务器下载 OpenSSH-Win64.zip，解压并运行 install-sshd.ps1，”Cynet 表示。“它将 sshd 设置为自动启动，启动该服务，并为 TCP 22 添加了一条入站防火墙规则。该压缩包是由操作者重复使用的合法 OpenSSH 软件包。”

对该基础设施的进一步分析发现了一个暴露的目录（"45.115.26[.]23:8012"），其中包含一个针对 Windows 的定制 Go 后门、SSH 持久化脚本、一个针对 CVE-2023-46604 的 ActiveMQ 利用程序，以及一个针对 CVE-2024-40711 的经修改的公开 Veeam 工具链，这表明该威胁行为者可能正在为更大范围的攻击做铺垫。
