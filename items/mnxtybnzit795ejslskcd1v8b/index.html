Ravie Lakshmanan2026年10月28日漏洞 / 企业安全

据威胁情报公司 Defused Cyber 称，攻击者已开始探测 Oracle E-Business Suite (EBS) 中一个刚刚修补的关键漏洞。

相关漏洞是 Oracle E-Business Suite 中 Oracle Application Object Library 的 CVE-2026-101767（CVSS 分数：9.8）。Oracle 上周将其作为关键补丁更新的一部分进行了修补。

Horizon3.ai 的安全研究人员 Brandon Peterson、Jimi Sebree 和 Noah King 因发现该漏洞并于 2026 年 7 月 24 日向 Oracle 报告而获得致谢。

Defused Cyber 在一则 X 帖文中表示：“我们的 Oracle E-Business Suite 诱捕系统在今天早上，即 10 月 27 日，记录到了针对 CVE-2026-101767 的探测性利用；该漏洞是 EBS Thin Client Framework servlet 中未经身份验证的 SQL 注入，可串联利用以实现远程代码执行。”

Horizon3.ai 在该漏洞的公告中将其描述为一个未经身份验证的 SQL 注入漏洞，可串联利用以实现远程代码执行。

这家网络安全公司表示：“该漏洞允许具有受影响 Thin Client Framework (TCF) servlet 网络访问权限的攻击者，以 APPS 数据库用户身份执行 SQL，随后以 EBS 应用账户身份运行操作系统命令。”

具体而言，攻击者可以向存在漏洞的 TCF servlet“/OA_HTML/AppsTCFServer”发送特制请求，以 APPS 数据库用户权限执行 SQL，并最终能够以 EBS 应用账户权限执行系统命令。

成功利用 CVE-2026-101767 可使攻击者读取或修改 APPS 可访问的应用数据，并在应用主机上执行命令。

Horizon3.ai 警告称：“根据部署情况，受影响的数据可能包括财务、薪资、HR 和采购记录。操作系统访问权限取决于遭到入侵的 EBS 应用账户所拥有的权限。”

虽然面向互联网的 EBS 部署面临的风险最高，但如果攻击者能够从已遭入侵的系统或其他可访问的网络段访问存在漏洞的 servlet，内部 EBS 系统同样可能遭到利用。

建议用户尽快更新至最新版本。如果无法立即修补，可以采用以下临时缓解措施 -

  • 从 EBS URL 防火墙允许列表中移除 /OA_HTML/AppsTCFServer，其关联组件为 oracle.apps.fnd.tcf.SocketServer。
  • 将 EBS web tier 的访问限制为可信网络。
  • 监控 EBS 应用主机和数据库，查找遭到入侵的迹象。

Horizon3.ai 还分享了以下失陷指标 -

  • 未经身份验证的 POST 请求会访问 /OA_HTML/AppsTCFServer 并实例化 Gantt 数据服务器类（oracle.apps.jtf.gantt.server.GanttDataServer），随后在后端数据库中产生活动。
  • 未经身份验证的 Web 请求发出后不久，会进行 SQL 侦察（数据库版本、当前用户、目录对象）。
  • $APPLPTMP 中出现异常文件，以及 oracle 账户通过 Concurrent Manager 启动 /bin/sh 来运行操作系统命令。

EBS 中的漏洞是攻击者的热门目标。过去一年中，同一产品中的两个关键漏洞（CVE-2025-61882 和 CVE-2026-46817，CVSS 分数：9.8）遭到积极利用，其中前者被 Cl0p 勒索软件和勒索团伙利用。
