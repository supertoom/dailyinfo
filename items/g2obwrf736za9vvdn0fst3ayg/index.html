中文原文

通过 Meta 广告投放的新版本 SYS01 信息窃取恶意软件正在将浏览器纳入企业风格的管理机制，以强制安装一个会窃取敏感数据（包括 Gmail 和 Outlook 电子邮件）的扩展。

这些广告诱骗 Windows 用户下载免费的动态壁纸；这些壁纸确实能正常发挥作用，但也会在安装期间于后台部署恶意软件。

该活动以 Facebook 和 Meta 商业账户为目标，使操作人员能够访问 Chrome 中近期的 Gmail 和 Outlook 消息，并能够永久删除电子邮件。

Bitdefender Labs 将该活动追踪为 SYS010，并表示该恶意软件很可能是SYS01 信息窃取器的新版本；研究人员至少自 2022 年起就在 Facebook 上的恶意广告活动中观察到了它。

这一名称反映了研究人员的评估：该变种相比其前代实现了重大改进，因此他们将其标记为版本 2，并以二进制形式表示为 010。

研究人员于 10 月 16 日发现了一则恶意的 SYS010 广告，并发现该活动仍在持续，已创建了数百则广告。

公司遥测数据显示，对威胁行为者服务器的请求来自亚洲、欧洲、北美洲、非洲和南美洲的多个国家。

Meta Ad Library 的透明度页面显示，仅一则广告就触达了欧盟的 6,275 名用户 targeting 任何年满 18 岁的人。

Bitdefender 在今天发布的报告中表示，大多数请求来自菲律宾、泰国、孟加拉国、波兰、墨西哥、阿尔及利亚、比利时、蒙古和美国，但强调这些数字并不代表已确认的感染。

壁纸会安装窃取信息的附加组件

这些广告冒充合法的 Wallpaper Engine（一个基于 Electron 构建、经过更名并具有数字签名的 MeisterTask 桌面应用版本）和 Lively Wallpapers 应用程序，将用户引导至恶意下载网站，其中一些网站使用旨在显得官方的域名。

安装恶意 Windows 应用后，用户会获得广告宣传的动态壁纸功能，这有助于掩盖在后台运行的恶意软件。

据 Bitdefender 研究人员称，攻击者通过滥用为企业组织设计的管理工具，强制 Chrome、Edge 和 Firefox 安装恶意浏览器附加组件。

一个名为 eclient.php 的脚本通过修改浏览器管理策略，负责安装恶意扩展。

在 Chrome 中，它会将浏览器注册到攻击者控制的 Google 管理控制台，从而允许强制安装扩展。

在 Firefox 中，它使用 ExtensionSettings 策略强制安装附加组件，同时禁用开发者工具和滥用举报功能。

对于 Edge，它可以将受害者的 Windows 设备注册到攻击者控制的移动设备管理（MDM）服务器，以启用强制扩展安装。

这些更改需要管理员权限，而攻击者通过触发用户账户控制（UAC）提示，并每隔三秒重复一次、最多重复 99 次，直到用户批准该操作来解决这一问题。

据 Bitdefender 表示，这些控件可阻止用户禁用或移除扩展插件。随后，这些扩展插件可以窃取会话 Cookie，使恶意软件操作者无需输入密码或完成双因素身份验证质询，即可访问已登录的账户。

Bitdefender 判定，这些恶意扩展插件伪装成文档工具，包括 Chrome 中的 Docs Helper 和 Firefox 中的 Document Hub。

他们指出，伪造的 Chrome Docs Helper 扩展插件使用了类似 Google Docs 标志的图标，但通过 Chrome Web Store 之外的渠道分发。

这些扩展插件还会收集受害者有权访问的 Facebook 主页、广告账户和商业账户信息，包括支出和付款详情。

Gmail 和 Outlook 电子邮件访问

Bitdefender 的研究还指出，该 Chrome 扩展插件可以读取 Gmail 和 Outlook 账户中的近期邮件，并将其内容发送给攻击者，还可以永久删除选定的邮件。

这种能力可能让攻击者拦截登录代码，并在受害者看到安全警报前将其删除， Bitdefender 警告称。

此外，对同一收件箱的访问还可能使恢复已遭入侵的账户变得更加困难。

最近在另一款名为 Remus 的信息窃取程序中也发现了类似行为，该程序同样使用恶意扩展插件读取 Gmail 收件箱中的邮件。

Remus 信息窃取程序采用了不同方式在 Chrome 中安装扩展插件：它直接在受害者的浏览器配置文件中注册该插件，并启用开发者模式，以允许未打包的扩展插件运行。

尽管恶意广告通常被认为风险较低，但它仍可能造成重大损害，因为被盗广告账户通常会被用来以可信企业的身份为恶意广告活动提供资金。

受影响公司会产生未经授权的广告费用，还可能失去社交媒体账户的访问权限，并且客户对话内容会遭到泄露。

Bitdefender 建议避免从社交媒体广告下载软件，并拒绝用途不明确的管理员权限提示。

此外，如果浏览器中出现意外的“由您的组织管理”消息，应当引起警觉。使用受工作管理的设备的个人应向其 IT 团队核实，而个人电脑上出现此类消息则需要进一步调查。

这家网络安全公司建议企业审查谁有权访问其 Meta 账户，移除不再需要的权限，并检查是否出现陌生广告、付款变更或支出。
