Ravie Lakshmanan2026年11月25日Web 安全 / 恶意软件

WordPress 已移除由 WP Connect 开发的六款 WordPress 插件；这些插件于 2026 年 11 月 22 日被植入后门，使用户能够在已安装这些插件的站点上执行任意代码，疑似原因是开发者账户遭到入侵。

WordPress 插件团队已独立检测并拦截该威胁，阻止其被正式发布。现在访问每个插件的列表页面都会显示以下消息：“此插件已于 2026 年 11 月 22 日关闭，不再提供下载。此次关闭为永久性关闭。”

受影响插件的名称及恶意版本如下——

  • Air WP Sync – Airtable to WordPress（2.9.1 – 2.9.4）
  • WP Sync for Notion – Notion to WordPress（1.7.4）
  • Add-on Brevo for Gravity Forms（2.6.3）
  • Add-On for Contact Form 7 to Airtable（2.5.4）
  • Add-On for Contact Form 7 to Notion（1.6.4）
  • Orders Sync to Airtable for WooCommerce（1.0.2）

据 WordPress 安全公司 Wordfence 称，这些插件合计安装在超过 3,600 个 WordPress 站点上。此次供应链入侵事件被追踪为 CVE-2026-135202（CVSS 分数：9.8）。目前仍未修复。

安全研究员 Chloe Chamberland 表示：“每个发布版本都会悄无声息地加载同一个远程控制模块，该模块会向攻击者控制的服务器回传数据、执行服务器发送的任意 PHP 代码，并提供用于运行 shell 命令、窃取密码哈希和植入 Web shell 的完整命令集。”

具体而言，这些插件附带了一个后门模块（"includes/airwp-online.php"），该模块会在每次请求时运行，将站点信息（站点 URL、PHP、WordPress 和操作系统版本，以及服务器用户）发送到一个硬编码的命令与控制服务器（"tascredit-pay[.]com"），并通过 eval() 运行该服务器返回的 PHP 代码。

它还可以执行以下操作——

  • 接受排队中的命令并运行 shell 命令
  • 读取、写入和删除任意文件
  • 查询任意数据库表
  • 导出用户表，包括登录名、电子邮箱地址和密码哈希
  • 将 Web shell 放入 uploads 目录或攻击者指定的路径
  • 注册每小时的 WP-Cron 钩子，用于运行攻击者提供的代码

因此，未经身份验证的攻击者在控制该站点后，便可在服务器上执行任意代码并取得完全控制权，从而通过 Web shell 和 cron 钩子窃取凭据并维持持久化，即使插件被移除，这些手段仍可能存续。

由于这些恶意版本从未发布，并因 WordPress 的新冷却期保护机制而在 Protect The Shire 计划的一部分中得到拦截，因此运行这些插件的站点不太可能受到影响。不过，站点所有者仍必须检查自己的网站，确保没有运行受影响的版本，并尽快将其移除。

Chamberland 表示：“与典型的漏洞不同，这并非编码错误，也不存在补丁：恶意代码是被故意添加到每个插件中的，并提交至各插件的 WordPress.org 仓库。综合来看，这强烈表明开发者的 WordPress.org 账户遭到入侵并被用于推送恶意版本，而非供应商有意发布这些代码。”

此次披露源于 URLscan.io 曝光：一个未指明的 WordPress 网站感染了多个网络犯罪团伙的活动，攻击者试图禁用或删除属于竞争威胁行为体的脚本。

该网站携带了来自三个不同工具包 [LOM、ErrTraffic 和 Macfinger] 的“十三处独立的 ClickFix 注入”，此外还有七个恶意加载器，“它表示：‘其中数个注入程序试图移除彼此的代码和覆盖层，还有一个注入程序通过 JavaScript 命名冲突禁用另一个。十三处注入中有五处通过 Polygon 智能合约解析其下一阶段基础设施，这一技术称为 EtherHiding。’”
