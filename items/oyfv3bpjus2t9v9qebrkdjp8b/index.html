中文原文

据称，与朝鲜有关联的 Lazarus Group 实施了名为 Operation FlashHole 的网络间谍活动，目标至少涉及韩国建筑、软件和线缆通信设备制造行业的三个组织。

据俄罗斯网络安全公司 Kaspersky 称，该活动至少自 2025 年 7 月起持续运行。据评估，它是在 Operation SyncHole 结束后接续开展的。

Kaspersky GReAT 高级安全研究员 Sojun Ryu 在一篇详尽分析中表示：“该组织更有选择性地锁定受害者，发送带有指向捏造但相关网站链接的鱼叉式钓鱼邮件，例如为每个目标定制的作品集和简历页面。”

Kaspersky 于 2025 年 4 月首次记录了 Operation SyncHole，详细介绍了这个受国家支持的对手自 2024 年 11 月以来针对韩国软件、IT、金融、半导体制造和电信行业的攻击活动，并投放 ThreatNeedle、AGAMEMNON、wAgent、SIGNBT 和 COPPERHEDGE 等恶意软件。

这些攻击的特征是利用 iniLINE Cross EX 中的一个安全漏洞来投递恶意软件。Cross EX 是一款强制性金融安全软件程序，韩国互联网用户会将其安装在自己的计算机上，以便在访问网上银行和政府服务时支持各种浏览器环境中的安全软件。

该漏洞利用旨在启动合法的“SyncHost.exe”进程，并向其中注入 shellcode，以加载 ThreatNeedle 后门。攻击链还利用了 Innorix Agent 文件传输解决方案 9.2.18.496 版本中的一个一天漏洞进行横向移动。

Operation FlashHole 延续了此前针对韩国软件的攻击活动，以突破目标。SyncHole 利用的是 Cross EX，而据发现，FlashHole 滥用了 Initech 的 INISAFE CrossWeb EX，这是韩国另一款强制性金融安全解决方案，是访问该国网上银行和政府门户所必需的。

据 iniLINE 网站称，该公司早在 2010 年便与 Initech 结成战略联盟，共同开发 CrossWeb。目前，Initech 将其作为基于证书的身份验证和电子签名解决方案进行推广。

尽管如此，Lazarus Group 长期以来一直滥用该软件来实现其目标。2021 年第三季度，该软件被用于在一项名为 DeathNote 的长期活动中投放名为 Racket 的下载器。

Operation FlashHole 初始入侵期间的攻击流程

2022 年至 2023 年间，AhnLab 还披露了多起攻击，其中威胁行为者利用该软件中的安全漏洞，通过水坑攻击分发 DLL 恶意软件（“SCSKAppLink.dll”）；该 DLL 载荷从遭该威胁行为者入侵的 IIS web 服务器获取。

AhnLab 在 2023 年 7 月的一份报告中指出：“该组织首先入侵韩国网站，并修改网站所提供的内容。” “当使用存在漏洞的 INISAFE CrossWeb EX V6 版本的系统通过 web 浏览器访问该网站时，Lazarus 恶意软件（SCSKAppLink.dll）便会通过 INISAFECrossWebEXSvc.exe 漏洞从分发站点安装。”

初始感染链

这些发现还正值2026 年 7 月联合通告发布的背景之下，该通告由 Korea Internet and Security Agency（KISA）与韩国国内网络安全厂商联合发布，强调了 Lazarus Group 利用此类金融安全程序中的漏洞（例如 AnySign4PC），在通过鱼叉式网络钓鱼和水坑技术诱骗受害者访问恶意 URL 后，分发 Struggle（又名 SIGNBT 3.0）和 Brandoor（又名 COPPERHEDGE）等后门。

“攻击者通过包括水坑攻击和鱼叉式网络钓鱼攻击在内的多种方法，诱导目标访问恶意 URL，随后利用漏洞最终安装后门恶意软件，”AhnLab 表示，并将此次行动称为 Operation Double Barrel。

FlashHole 最初的精确入侵途径尚不清楚，但迹象表明其源头是托管在 GitHub Pages 上的恶意网站。其中一个版本托管了一名高级网络设备开发人员的履历，以及一张可能使用人工智能（AI）生成的个人照片。

获得持久性后扩展感染链

据推测，目标会收到包含恶意网站链接的鱼叉式网络钓鱼邮件；访问该网站会触发涉及 CrossWeb EX 的感染序列，用于启动合法的 Windows 二进制文件“fsquirt.exe”，随后再通过该文件启动名为 TechHub 的恶意 DLL，实施 DLL 侧加载。

“这条感染链相当复杂，揭示了 Lazarus Group 在目标主机上的高级行动技术，”Kaspersky 表示。“这些技术隐藏了他们的恶意载荷、意图及其复杂的恶意软件交付框架。”

“尤为值得注意的是，下述执行链仅在初始渗透期间存在于内存中，凸显出攻击者为隐藏初始入侵所付出的巨大努力。” 

TechHub 本身会从 GitHub 下载名为 TouchHub 的恶意软件，后者利用 DLL 侧加载启动第二个 DLL，以启动名为 TOUCHSHIFT（“mscoree.dll”）的恶意 DLL 载荷，通过在内存中执行另一个 TechHub 实例来建立持久性。

Lazarus Group 攻击之间的重叠之处

第二个 TechHub 实例会获取另一个名为 ClientHub 的恶意软件家族，用于将 LPEClient 下载并加载到内存中。LPEClient 是通往 Cubridge 的通道；Cubridge 是该恶意软件框架的编排组件，负责获取各种插件、模块和工具。

该恶意软件工具集的更多详细信息如下——

  • TechHub，是 CLOUDBURST 和 NickelLoader 下载器的进阶版本，可与 GitHub 通信，以获取 TouchHub 和 ClientHub 等额外载荷，同时收集设备及其运行进程的信息。
  • Cubridge，是 SIDESHOW 和 LightlessCan 的改进版本，能够与命令与控制（C2）服务器通信，并下载可重复使用的插件、用于一次性任务的 DLL 工具以及扩展其功能的额外模块，从而收集全面的系统信息、执行命令，并窃取文件和网页浏览器数据。据评估，它也是 CookiePlus 的进阶版本。
  • TouchHub，TouchShift 的父级安装程序。
  • TouchShift，一种恶意软件投放器，能够交付键盘记录器、屏幕截图工具和后门。
  • ClientHub，一种此前未经披露的后门，分为两个版本：一个通过 HTTPS 与攻击者控制的服务器通信，另一个则与 Dropbox API 交互。该恶意软件的最终目标是部署额外的插件和 DLL。这些插件使恶意软件能够创建 ZIP 归档文件、收集与搜索模式匹配的文件、删除特定文件，并监控本地驱动器的更改及返回收集到的状态信息。
  • LPEClient，一种长期使用的受害者画像分析与载荷投递工具，自 2019 年起使用。

2026 年 8 月，Check Point 披露，LPEClient 是在 CVE-2026-68820 零日漏洞被利用后部署的；该漏洞是影响 Windows Ancillary Function Driver for WinSock 的权限提升漏洞，用于部署 FudModule rootkit。

该恶意软件最新版本的特点在于，它使用 ML-KEM-1024 这一后量子密码算法，在直接于内存中下载并运行更多恶意软件之前，与攻击者的服务器建立加密连接。

Kaspersky 表示：“Operation FlashHole 是更广泛的 Cascade Hole 行动中的最新一波，该行动涉及使用韩国软件作为潜在入口，以投放针对该国的恶意软件。”

这家网络安全公司表示，Operation FlashHole 的出现与利用 COPPERHEDGE 后门针对韩国各类组织的新一轮攻击同时发生。据称，至少有一种情况下，该后门感染以类似于同期针对韩国实体的 Gunra 勒索软件攻击的方式，导致数据被外传至名为 ULOSE 的暗网泄露网站。 

Ryu 在与 The Hacker News 分享的一份声明中表示：“Lazarus 继续扩大其行动，在推出新活动的同时引入新工具，并对熟悉的工具进行改造，以满足自身需求。”

“更值得关注的是 Lazarus 开始采用旨在抵御未来量子威胁的密码技术。我们的研究发现，其使用历史最早可追溯至 2024 年 9 月，表明早在此次披露一年多以前，这些能力就已用于保护该组织的恶意软件通信。”
