Fireworks AI 密钥泄露导致 Cursor Marketplace 供应被植入 Claude Code 恶意扩展

Cursor Says Stolen Fireworks AI Key Led to Trojanized Claude Code Extension Incident

Cursor 确认，攻击者利用 Fireworks AI 泄露的访问密钥复制共享数据，进而取得 Cursor 使用的 SaaS 工具凭据及部分内部数据。

Ravie Lakshmanan2026年11月15日人工智能 / 软件安全

Anthropic 官方 Claude Code 扩展在 Cursor 扩展市场遭到篡改，起因是一次针对 Fireworks AI 的数据泄露事件过后，一个访问密钥被窃取并暴露。

Cursor 在周五的更新中表示：“攻击者获得了我们签发给 Fireworks 的访问密钥。该密钥由 Fireworks 暴露，攻击者利用它复制了我们用于与其共享数据的只读存储桶中的数据。”

此次披露距离 Anthropic 官方 Claude Code 扩展的木马化版本通过 Cursor Marketplace 作为合法更新分发，已近两周。该版本试图在受感染系统上安装持久 SSH 后门。

据这个人工智能（AI）驱动的编码平台称，该只读存储桶据存有数量有限的编码代理轨迹，来自未启用隐私模式的会话。隐私模式是一项Cursor 专属设置，启用后允许用户选择退出将其数据用于训练。

这些会话大多可追溯至 2025 年，并获准用于模型训练。这些轨迹中包含未经过编辑删除的凭据，导致不足 0.01% 客户的 API 凭据随之暴露。

Cursor 补充称，攻击者将这些凭据作为切入点，访问 Cursor 所使用的特定软件即服务（SaaS）工具，随后获取了以下数据——

  • 选定的已归档 Cursor 非生产源代码存储库，其中包括一些含有业务联系信息的存储库
  • 有限的客户支持数据和电子邮件往来记录
  • 产品使用指标和联系详情
  • 部分编码代理对话的摘要
  • 一些用户发送给 Cursor 支持团队的凭据

Cursor 表示，在“我们发现进一步访问”之后，它已采取措施停用供应商的密钥、撤销并轮换凭据、查找更深层访问的迹象并加以遏制。该公司还表示，它临时停用了内部和产品服务，导致部分 Cursor 功能无法访问。

攻击的下一阶段发生于 2026 年 10 月 29 日。攻击者利用从其内部系统暴露数据中窃取的凭据，将 Anthropic Claude Code 扩展的木马化版本直接放入用于提供 Cursor 扩展市场服务的缓存中。

Cursor 表示：“在 10 月 29 日请求特定缓存版本扩展的最多 5,000 名用户，可能收到了恶意构建版本。该恶意版本可用约 11 小时后被我们移除。我们将其下架、关闭扩展市场，并与托管攻击者服务器的云服务提供商合作将其下架。”

该公司表示，已通知在暴露窗口期间从市场安装 2.1.312 或 2.1.313 版本且受影响的用户，并协助撤销暴露的凭据。它还将所有推理流量迁移出 Fireworks，停用了向其签发的密钥，并切断了其对我们与其共享的所有数据集的访问。

此外，Cursor 强调，自 2026 年 11 月 1 日以来，未检测到额外的恶意活动。

没有证据表明，该事件影响了启用了隐私模式的用户、客户代码仓库、Cursor 自身的生产环境、Cursor 应用及其官方更新、其其他应用，或从 Cursor Marketplace 下载的任何其他扩展或插件。

Uber 也受 Fireworks 事件影响

在 Uber 确认未知威胁行为者在获取内部凭据后窃取了数千名驾驶员的驾照信息之际，这一进展出现了。

该公司在向美国加利福尼亚州提交的文件中表示：“2026 年 10 月 9 日，一家服务提供商通知 Uber，一个未经授权的第三方已攻破该服务提供商的内部凭据，并使用这些凭据访问了 Uber 在该服务提供商的账户。2026 年 10 月 13 日，我们的调查确定，未经授权方已使用被攻破的凭据访问了与该服务提供商关联的 Uber 数据。”

尽管该提供商的名称未被披露，但 TechCrunch 报道称，相关提供商是 Fireworks AI。Uber 尚未披露此次数据泄露影响了多少用户。上周，在线生产力初创公司 Notion 也确认其数据在 Fireworks AI 黑客事件中被窃取。
