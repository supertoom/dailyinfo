Citrix 已为多个影响 NetScaler ADC、Citrix NetScaler Gateway 和 NetScaler Console 的严重安全漏洞发布补丁，这些漏洞可能导致拒绝服务（DoS）或身份验证绕过。

影响 NetScaler ADC 和 NetScaler Gateway 的严重漏洞如下——

  • CVE-2026-120868（CVSS 分数：9.3）——数据包处理中的内存溢出漏洞可能导致不可预测或异常行为或 DoS。（所有 NetScaler ADC 和 NetScaler Gateway 部署）
  • CVE-2026-107407（CVSS 分数：9.3）——SMPP 流量中的内存溢出漏洞可能导致不可预测或异常行为或 DoS。（配置了负载均衡或内容交换虚拟服务器且类型为 SMPP 的 NetScaler ADC）
  • CVE-2026-107408（CVSS 分数：9.3）——DNS / DNS-over-HTTPS（DoH）中的内存损坏漏洞可能导致不可预测或异常行为或 DoS。（配置为 DNS 负载均衡和递归 DNS 解析的 NetScaler ADC）
  • CVE-2026-107409（CVSS 分数：9.3）——DNS-over-HTTPS（DoH）中的内存损坏漏洞可能导致不可预测或异常行为或 DoS。（配置为通过 HTTPS 进行 DNS 负载均衡的 NetScaler）
  • CVE-2026-107410（CVSS 分数：9.3）——NetScaler Push 中的内存溢出可能导致不可预测或异常行为或 DoS。（配置为 PUSH 类型负载均衡虚拟服务器的 NetScaler）
  • CVE-2026-107412（CVSS 分数：9.5）——多个内存溢出漏洞可能导致不可预测或异常行为以及 DoS。（配置为 Gateway 或 AAA 虚拟服务器的 NetScaler）
  • CVE-2026-107415（CVSS 分数：9.3）——电子邮件 OTP 身份验证中的内存溢出漏洞可能导致不可预测或异常行为或 DoS。（配置了电子邮件动作的 NetScaler ADC 或 NetScaler Gateway）
  • CVE-2026-111344（CVSS 分数：9.3）——端点分析（EPA/EPAS）中的内存溢出漏洞可能导致不可预测或异常行为或 DoS。（配置为 VPN 虚拟服务器或启用了端点分析的身份验证（AAA）虚拟服务器的 NetScaler）
  • CVE-2026-120864（CVSS 分数：9.3）——ICA 代理中的内存溢出漏洞可能导致不可预测或异常行为或 DoS。（配置为 Gateway VPN 虚拟服务器、AAA 虚拟服务器或 HDX 类型 CR 虚拟服务器的 NetScaler）

所有问题均已在以下版本中修复——

  • Citrix NetScaler ADC 和 Citrix NetScaler Gateway 14.1-73.57 及更高版本
  • Citrix NetScaler ADC 和 Citrix NetScaler Gateway 13.1-64.39 及 13.1 的更高版本
  • Citrix NetScaler ADC 14.1-FIPS 14.1-73.58 FIPS 及 14.1-FIPS 的更高版本
  • Citrix NetScaler ADC 13.1-FIPS 和 13.1-NDcPP 13.1-37.293 及 13.1-FIPS 和 13.1-NDcPP 的更高版本

Citrix 还修复了适用于 Windows 和 Linux 的 NetScaler Console 与 Secure Access Client 中的若干缺陷——

  • CVE-2026-120869（CVSS 分数：9.4）——NetScaler Console 中的身份验证不当漏洞可能允许未经身份验证的攻击者绕过身份验证控制，以访问设备上的受限资源。（在 NetScaler Console 14.1-74.34 及更高版本中修复）
  • CVE-2026-118268（CVSS 分数：8.5）— Windows 版 Secure Access Client 中存在权限管理不当漏洞，可导致低权限用户将权限提升至 SYSTEM。（已在 Windows 版 Secure Access Client 26.11.1.6 及更高版本中修复）
  • CVE-2026-118269（CVSS 分数：8.5）— Linux 版 Secure Access Client 中存在权限管理不当漏洞，可导致低权限用户获得 root 权限。（已在 Linux 版 Secure Access Client 26.10.4 及更高版本中修复）

Citrix 表示，这些安全更新源于对其代码库进行更深入的审查，并整合了人工智能（AI）辅助的代码分析，以检测和解决漏洞，力求在潜在威胁成为现实之前强化产品安全。

该公司表示，目前尚未发现针对任何已公布漏洞的利用，但敦促客户应用这些更新，因为这些更新旨在“提升 NetScaler 的安全防护水平”。
