长亭安全应急响应中心 2026-11-22 20:04 浙江

检测业务是否受到此漏洞影响，请联系长亭应急服务团队！

VMware vCenter Server 是 VMware vSphere 环境的核心管理平台，用于集中管理 ESXi 主机、虚拟机、集群、存储与网络资源，同时承担单点登录、权限管理与告警等职能，广泛应用于企业私有云与虚拟化数据中心。

2026 年 11 月，长亭安全应急响应中心监测到 VMware vCenter 目录服务认证绕过风险。攻击者无需任何凭据，只要能够访问 vCenter 的管理网络，即可通过目录服务 RPC 接口绕过身份认证，取得内置管理员会话，进而读取目录数据库、伪造 SSO 身份并创建管理员账号。截至通告发布，Broadcom 已发布修复版本，公开研究显示该漏洞已被在野利用。建议受影响用户尽快升级至安全版本，并收敛管理接口的暴露面。

漏洞描述 Description 

01

漏洞成因

VMware Directory Service（vmdird）在 DCE/RPC 接口上实现 SRP-6a 认证，用于处理目录服务的身份校验。该实现允许未认证调用方取得与认证会话关联的 SRP 会话密钥，而相关会话句柄的生成具有可预测性。攻击者据此可以在不具备任何凭据的情况下完成 SRP 证明，使服务端接受其管理员身份，并建立受隐私保护机制约束的 RPC 上下文。

问题根源在于认证路径设计缺陷，官方将其归类为 VMware Directory Service 认证绕过。目录服务 RPC 接口默认在 TCP 2012 端口提供服务，该端口可达即构成攻击前提。

漏洞影响

攻击者可以内置 SSO 管理员（administrator@vsphere.local）身份访问 vCenter，读取目录数据库及其中的凭据与证书材料，伪造 SAML 断言并创建持久化管理员账号。在此基础上可进一步操作 ESXi 主机与虚拟机，可能导致虚拟化平台整体失陷、业务中断与敏感数据泄露。

处置优先级：高

漏洞类型： 认证绕过

漏洞危害等级： 高

触发方式： 网络远程

权限认证要求： 无需权限

系统配置要求： 默认配置

用户交互要求： 无需用户交互

利用成熟度： POC 未公开

修复复杂度： 低，官方已提供修复方案

影响版本 Affects 

02

VMware vCenter 9.1.x（低于 9.1.1.0200）

VMware vCenter 9.0.x（低于 9.0.2.0200）

VMware vCenter 8.0（低于 8.0 U3m）

VMware vCenter 7.0

VMware Cloud Foundation 5.x（低于 5.2.5）

VMware Telco Cloud Platform 3.0、4.x、5.0.x、5.1.x、5.2

VMware Telco Cloud Infrastructure 3.0

解决方案 Solution 

03

升级修复方案

建议升级至以下安全版本或更高版本：

  • VMware vCenter 9.1.x 升级至 9.1.1.0200

  • VMware vCenter 9.0.x 升级至 9.0.2.0200

  • VMware vCenter 8.0 升级至 8.0 U3m

  • VMware Cloud Foundation 5.x 升级至 5.2.5

  • VMware vCenter 7.0 请联系 Broadcom 支持获取修复

  • VMware Telco Cloud Platform 与 Telco Cloud Infrastructure 的修复方式参见 KB463116

官方公告与修复说明：

https://support.broadcom.com/web/ecx/support-content-notification/-/external/content/SecurityAdvisories/0/39495

临时缓解方案

Broadcom 未提供官方临时缓解方案，以下措施为应急临时手段，可能影响正常管理运维，升级完成后应及时恢复。

  • 通过防火墙或安全组限制 TCP 2012、443、389、636 等管理端口仅对运维网段开放，禁止来自办公网、业务网及互联网的直连访问。

  • 收敛 vCenter 管理面（含 /ui、/sdk）的对外暴露，确需远程管理的场景应通过跳板机或 VPN 接入。

  • 加强 vCenter 与 SSO 账号审计，排查是否存在非预期创建的管理员账号与异常 SAML 登录记录。
