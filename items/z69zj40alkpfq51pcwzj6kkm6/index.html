中文原文

黑客入侵了 Microsoft 官方 Agent Framework 的 PyPI Python 软件包，发布了两个恶意版本，旨在从开发者的系统中窃取云凭据和其他敏感信息。

Microsoft Agent Framework 是 Microsoft 的开源工具包，用于构建 AI 智能体并协调其工作流。它是一款相当受欢迎的工具，在 PyPI 上每月约有 200,000 次下载。

恶意版本 1.26.1 和 1.26.2 于 2026 年 11 月 17 日发布，其中包含一个凭据窃取程序，可在受影响环境中的 Python 正常启动期间自动执行，即使未导入 Agent Framework 软件包也会运行。

这两个版本都保留了对正版 agent-framework-core 1.26.0 软件包的依赖，使框架能够正常运行，同时恶意软件在后台运行。

多家安全公司发现并记录了此次攻击，包括 Socket、Step Security 和 Ox Security。

版本 1.26.1 包含一个凭据窃取程序，用于收集环境变量、本地配置文件以及其他运行进程中的机密信息（取决于权限），目标包括 Azure、AWS、GitHub、Docker、Hugging Face、OpenAI 等服务。

该恶意软件还试图获取 Azure 托管标识访问令牌和 Azure DevOps OIDC 令牌，这可能使攻击者能够访问更多云资源。

版本 1.26.2 新增了对 GitHub Actions OIDC 令牌的请求，以及对 GitHub runner 目录的搜索。

据 Socket 和 StepSecurity 表示，第一个恶意版本使用 agent_framework_meta.pth 在 agent_framework_meta/_telemetry.py 中执行凭据窃取程序，触发时机为 Python 启动期间。

第二个版本恢复了原始软件包初始化程序，并将恶意代码移入 af_runtime_diag.pth 和 af_runtime_diag.py。

两个版本都将收集到的数据外传至同一个由攻击者控制的端点 https://webhook[.]site/d381fd80-ec62-42ad-8f5c-d1b15103c9bb。

PyPI 隔离了第一个恶意版本，但攻击者在大约 2.5 分钟后发布了第二个版本，该版本也在约八分钟后被隔离。第二个版本的发布表明，在首次隔离后攻击者仍拥有发布权限。

目前尚不清楚攻击者是如何获得访问权限并以 Microsoft 官方 PyPI 项目的名义发布恶意版本的。

BleepingComputer 已联系 Microsoft，以了解此次入侵的突破点，但截至发布时仍未收到回应。

安装了任一恶意版本的开发者应立即隔离受影响环境，在确保安全之前避免运行 Python 或 pip，并从已知干净的环境中使用安全的 1.26.0 版本重新构建。

任何可能已暴露且可被入侵环境访问的凭据都应立即轮换。

为确定具体的入侵程度，调查人员应查找出口日志中的特定 webhook URL 路径，并区分被阻止的请求与已完成的传输。
