AI 导读

Cisco 披露 UCS 及基于 UCS 的设备存在 UEFI Shell Secure Boot 绕过漏洞，并按服务器产品线、管理模式及设备类型列出首个修复版本。

正文 · 原文

  • Cisco considers any workarounds and mitigations (if applicable) to be temporary solutions until an upgrade to a fixed software release is available. To remediate this vulnerability and avoid future exposure as described in this advisory, Cisco strongly recommends that customers upgrade to the fixed software indicated in this advisory.

    In the following tables, the left column lists Cisco software releases.
