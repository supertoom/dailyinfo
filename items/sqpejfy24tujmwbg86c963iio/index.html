中文原文

DreamHost 警告称发生数据泄露：攻击者入侵其 File Manager 平台长达两个月，并窃取了客户的 FTP/SFTP 用户名和密码。

此前，这家美国网页托管服务商和域名注册商宣布，其遭遇网络安全事件，用户需要重置电子邮件及 FTP/SFTP 密码。

DreamHost 在数据泄露通知中表示，此次泄露从 2026 年 8 月持续至 2026 年 10 月 23 日，即事件被发现之日。

通知称：“我们发现未经授权的第三方访问了运行 files.dreamhost.com 上基于网页的 File Manager 的服务器，”通知中写道。

“该未经授权的第三方利用了上述软件中的漏洞，因此能够获取大约在 2026 年 8 月至 2026 年 10 月 23 日期间登录此 File Manager 的个人用户的 FTP/SFTP 用户名和密码。”

此外，DreamHost 表示，入侵者可能还访问了网页邮件系统，导致数量有限的用户会话信息（包括凭据）泄露。

该公司称，此次攻击似乎是有意为之，员工一直 nonstop 地开展工作，以彻底遏制此次攻击。

DreamHost 表示，目前尚未发现攻击者访问控制面板登录信息或客户账单/付款详情的证据；这些信息由外部服务商处理。

该公司表示，已阻止攻击者访问，并修复了此次攻击所利用的漏洞。

该公司还终止了可能受影响用户的活动会话，并使密码失效。

BleepingComputer 已多次联系 DreamHost，询问有关该事件及受影响账户确切数量的问题，但尚未得到答复。

通知接收者应检查网站文件是否遭到未经授权的更改，审查网页邮件转发规则和筛选器，并更改其可能使用相同凭据的任何其他账户的密码。

为降低此次信息暴露带来的风险，DreamHost 通过 Equifax 向受影响的个人用户提供一年的信用监控和身份盗窃保护服务。

信件接收者还应考虑在信用报告中设置欺诈警报，或申请安全冻结。
