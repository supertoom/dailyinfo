漏洞名称：

Vite 开发服务器虚拟模块注入远程代码执行漏洞(SF_2026_47139)

组件名称：

Vite

Vite 4.x - 6.x：>= 4.0.0 且 <= 6.4.5

漏洞类型：

代码执行

利用条件：

1、用户认证：否

2、前置条件：开发服务器通过 --host / server.host 暴露到网络，无需认证与用户交互

利用难度：容易，无需授权即可远程代码执行。

漏洞分析

组件介绍

Vite 是新一代前端构建工具与开发服务器，内置开发服务器为浏览器端代码提供模块转换与热更新，被 Vue、React 等前端项目广泛用作默认构建方案。其虚拟模块 stub 生成、import-analysis 模块图分析与 import.meta.glob 选项求值均在开发服务器进程内执行，当开发服务器通过 --host / server.host 暴露到网络时，远程请求可直接触达上述代码路径，本次漏洞即位于该链路。

漏洞简介

2026年11月19日，深瞳漏洞实验室监测到一则Vite组件存在代码执行漏洞的信息，漏洞威胁等级：高危。

Vite 开发服务器的虚拟模块标识符处理存在注入缺陷：请求 /@id/__vite-browser-external: 后的 URL 内容未经转义即拼入生成的 JS 源码，攻击者通过闭合模板字符串注入任意模块级代码，进而利用模块图信任机制绕过文件访问限制实现任意文件读取，并通过服务端求值 import.meta.glob 选项实现任意代码执行。开发服务器仅需通过 --host / server.host 暴露到网络即可被无认证利用，server.fs.allow / fs.deny 配置无法缓解；生产构建产物不受影响。

漏洞验证

搭建受影响的 Vite 6.4.5 环境并以 --host 暴露开发服务器，发送单个 GET 请求即可 RCE：URL 中的模块标识符被未转义拼入生成的 JS 代码，注入的 import.meta.glob() 第二参数在服务端被 new Function 求值，经 globalThis.process.getBuiltinModule 取得 execSync 执行任意命令。回显利用了 Vite 自身的报错机制：把命令输出拼接为 options 对象的属性名（computed key），求值返回后该属性名不在 Vite 的已知选项白名单内，Vite 便抛出 Unknown glob option "<命令输出>" 异常，错误消息随 HTTP 500 响应体原样返回——无需外带通道，单请求完成执行与回显。

影响范围

目前受影响的Vite版本：

Vite 4.x - 6.x：>= 4.0.0 且 <= 6.4.5（修复 6.4.6）

Vite 7.x：>= 7.0.0 且 <= 7.3.7（修复 7.3.8）

Vite 8.0 - 8.1：<= 8.1.6（修复 8.1.7）

Vite 8.2：<= 8.2.4（修复 8.2.5 / 8.2.6）

Vite 8.3：<= 8.3.6（修复 8.3.7）

Vite-plus：<= 1.5.0（修复 1.5.1）

解决方案

官方修复建议

升级至官方已修复版本：
Vite 4.x - 6.x：>= 6.4.6
Vite 7.x：>= 7.3.8
Vite 8.0 - 8.1：>= 8.1.7
Vite 8.2：>= 8.2.5 / 8.2.6
Vite 8.3：>= 8.3.7
Vite-plus：>= 1.5.1

官方安全通告：https://github.com/vitejs/vite/security/advisories/GHSA-p4f5-76q4-ffq7

临时修复建议

  • 在完成升级前，避免将 Vite 开发服务器通过 --host / server.host 暴露到网络；确需远程访问时，以防火墙限制开发端口（默认 5173）的访问来源为可信地址。

  • 关注 Vite 官方发布渠道，按受影响分支尽快升级至 6.4.6 / 7.3.8 / 8.1.7 / 8.2.6 / 8.3.7 或 vite-plus 1.5.1。
