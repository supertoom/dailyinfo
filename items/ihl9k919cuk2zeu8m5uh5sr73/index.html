中文原文

预测市场平台 Polymarket 周四暂时暂停交易，此前黑客攻陷了一家第三方服务，通过其分发可清空加密货币的 JavaScript，约 250 万美元资产已被追踪至一个疑似攻击者钱包。

该公司确认了这起安全事件，称已识别并修复影响其国际平台 Polymarket.com 的问题，并将该入侵事件移交执法部门处理。

Polymarket 表示：“我们的一家第三方提供商遭到攻陷，我们已将此事移交相关执法部门。”

“所有受到影响的用户都将获得全额补偿。出于高度谨慎，我们已暂时停止交易，并正在努力让平台恢复上线。”

Polymarket 最初于美国东部时间下午 2:05 将其交易所置于仅可取消模式，并在调查事件期间暂停了中继操作。下午 2:37，该公司宣布问题已修复，出于高度谨慎暂时停止了交易。

交易在最初暂停约一小时后恢复，美国东部时间下午 3:05，该事件被标记为已解决。

该公司在 X 上宣布：“交易现已完全恢复上线。我们会解决此事，并将为所有受影响的交易者全额赔付。”

Polymarket 未披露有多少用户受到影响、被盗走了多少加密货币，也未说明补偿流程将如何进行。

Hudson Rock 的安全研究人员在一个恶意 JavaScript 中发现了疑似由攻击者控制的钱包（0x3F99139F1C5854bb628c2e576Aaf638e99dFfc18）。

BleepingComputer 对该钱包的区块链活动进行检查，发现其向另外三个钱包转移了约 2860 万枚 POL，价值约 257 万美元。

区块链记录还显示，该钱包在交易所暂停交易前不久的美国东部时间下午 1:50 至 1:56 之间，针对 Polymarket 的预测市场代币合约进行了多笔交易。

Hudson Rock 报告称，该钱包在其调查期间持有约 219 万美元的加密货币。

用于清空钱包的恶意 JavaScript

Hudson Rock 的安全研究人员发现了恶意 JavaScript，该脚本通过 cdn.debugbear[.]com/C7xcKKrjUnXK.js 分发，旨在窃取 Polymarket 用户的加密货币和预测市场持仓。

该脚本托管在 DebugBear 所属的基础设施上。DebugBear 是一家网站性能监控服务，可帮助组织跟踪网站加载速度和用户体验。

DebugBear 的真实用户监控（RUM）服务使用嵌入网站的 JavaScript，从访问者的浏览器收集性能指标。

DebugBear 此后确认正在调查一起持续中的安全事件，并警告客户从其网站中移除监控 JavaScript。

DebugBear 在X 的一则帖子中表示：“我们受到了一起持续中的安全事件的影响。”

“如果您使用我们的 RUM 产品，请从您的网站中移除嵌入代码。”

截至撰写本文时，DebugBear 的网站无法访问，显示 Cloudflare 错误。目前尚不清楚该网站中断是否与遏制措施有关，还是此次事件造成的其他后果。

Hudson Rock 的研究人员还发现，Polymarket 的生产构建元数据中包含提交消息“chore(polymarket): remove debugbear rum script (#15337)”， 这表明该平台已移除 DebugBear 监控集成。

该构建的时间戳为10月29日美国东部时间下午1:59 shortly Polymarket公开宣布该事件之前。 

BleepingComputer分析了恶意 JavaScript 文件（VirusTotal）的一份副本，发现该文件旨在劫持已通过身份验证的 Polymarket 交易会话、清算用户的预测市场头寸，并将加密货币和其他资产转移到攻击者控制的钱包。

该恶意软件会检查访问者是否已登录 Polymarket，并尝试使用其现有交易会话和平台的交易功能执行未经授权的交易。

随后，它会检查用户的加密货币余额和预测市场头寸，以确定其持仓价值。

根据用户向 Polymarket 进行身份验证的方式，该恶意软件会尝试以不同方式窃取其资产。

对于部分用户，它会尝试自动出售其预测市场头寸。对于其他用户，该恶意软件会尝试将预测市场代币直接转移到攻击者控制的钱包。

该恶意软件还会利用 Polymarket 现有的交易功能，尝试将用户的加密货币持仓转换为可转移到攻击者控制钱包的资产。

BleepingComputer 发现，该恶意脚本会与 data.debugbear.com 通信，以接收指令并发送有关目标账户、钱包地址、余额和交易结果的数据。

该恶意软件使用 DebugBear 的基础设施来分发恶意脚本，并将其用作命令与控制（C2）和数据外泄服务器，这引出了一个问题：攻击者对该公司的系统拥有多大访问权限。

BleepingComputer 已就此次事件联系 Polymarket 和 DebugBear 提出疑问，如果收到回应，将更新本文。
