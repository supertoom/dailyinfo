1

漏洞概述

近日，绿盟科技CERT监测到Broadcom发布安全公告，修复了VMware vCenter Server身份认证绕过漏洞（CVE-2026-123903）；由于VMware Directory Service（vmdird）组件在特定认证流程中存在访问控制缺陷，未经身份验证的攻击者可通过访问vCenter的LDAP接口（默认TCP 389端口）绕过系统验证创建管理员账号，从而接管vCenter并非法访问及管理虚拟化基础设施。CVSS评分9.8，目前漏洞细节与PoC已公开，请相关用户尽快采取措施进行防护。

VMware vCenter Server是Broadcom公司的一种服务器管理解决方案，可帮助IT管理员通过单个控制台管理企业环境中的虚拟机和虚拟化主机；是VMware Cloud Foundation、VMware vSphere Foundation及Telco Cloud等环境的核心管理组件。VMware Directory Service（vmdir）为其SSO提供身份目录服务。

2影响范围

受影响版本

  • VMware vCenter Server = 7.0

  • 8.0 <= VMware vCenter Server < 8.0 U3m

  • VMware Cloud Foundation 5.x < 5.2.5

  • VMware Cloud Foundation（vCenter）9.1.x.x < 9.1.2

  • VMware vSphere Foundation（vCenter）9.1.x.x < 9.1.2

  • VMware Cloud Foundation（vCenter）9.0.x.x < 9.0.2.0300

  • VMware vSphere Foundation（vCenter）9.0.x.x < 9.0.2.0300

  • VMware Telco Cloud Platform = 3.0/4.x/5.0.x/5.1.x/5.2

  • VMware Telco Cloud Infrastructure = 3.0

注：官方停止维护的vSphere 6.5、6.7等旧版本也可能受影响。

不受影响版本

  • VMware vCenter Server 8.0 >= 8.0 U3m

  • VMware Cloud Foundation 5.x >= 5.2.5

  • VMware Cloud Foundation（vCenter）9.1.x.x >= 9.1.2

  • VMware vSphere Foundation（vCenter）9.1.x.x >= 9.1.2

  • VMware Cloud Foundation（vCenter）9.0.x.x >= 9.0.2.0300

  • VMware vSphere Foundation（vCenter）9.0.x.x >= 9.0.2.0300

  • VMware Telco Cloud Platform/Infrastructure KB463501

注：具有延长支持合同的vCenter 7.0用户可联系Broadcom Support获取补丁，其他用户应尽快迁移至受支持版本。

3漏洞检测

3.1 人工检测

相关用户可通过检查vCenter Server版本判断当前环境是否在受影响范围：

使用管理员账户登录vCenter Server管理界面（VAMI），在VAMI的“摘要”或“更新”页面查看vCenter Server版本及构建号；也可登录vSphere Client中通过“帮助 > 关于”查看版本信息。

若当前vCenter Server及补丁版本处于受影响范围，则可能存在安全风险。
