中文原文

伪造的美国法院通知针对超过 100,000 家企业，诱骗收件人下载 LodaRAT 恶意软件；该恶意软件可窃取密码、记录活动并控制计算机。

ThreatDown 的网络安全研究人员发现了一场大规模网络钓鱼活动，其冒充美国佛罗里达州南区联邦地区法院。该行动迄今已利用有关替代性争议解决（ADR）案件的虚假通知针对超过 100,000 家企业，诱骗收件人下载恶意软件。

这些电子邮件包含唯一的民事案件标识符，以及指向虚假法院门户网站的链接；该网站会显示每家目标公司的名称和联系方式。为规避安全筛选机制，该网站会根据访问者所使用的浏览器软件限制访问，仅向使用 Microsoft Edge 访问的用户显示内容。

美国佛罗里达州南区联邦地区法院已发布官方警报，提醒公众注意这些欺诈通信。

三种途径投放同一恶意软件

一旦进入该网站，目标用户会被催促下载一个受密码保护的压缩文件，以查看其案件文档。该文件包含一个光盘映像（ISO），其中含有三种不同类型的文件：一个 MSC 文件、一个批处理文件和一个 Windows 快捷方式。打开其中任何一种文件都会触发不同的执行路径，但这三种途径最终都会下载同一恶意软件。

攻击载荷来自一个仿冒域名 us.wind0ws.net，并使用与合法 Windows 组件相关的文件名：Taskmgr.exe, SystemSettings.exe 和 msedge.exe。

ThreatDown 将该恶意软件识别为 LodaRAT，这是一款远程访问木马（RAT），可使攻击者远程控制受感染的系统。Hackread.com 曾在 2021 年报道过 LodaRAT，当时研究人员记录了一款能够针对 Android 设备的版本。

ThreatDown 发现，LodaRAT 包含广泛的监视机制。它能够捕获按键输入、窃取主流网络浏览器中保存的登录凭据、录制音频和视频，并提取 Wi-Fi 密码。它还可以启用远程桌面协议（RDP）连接，并在本地网络中进行传播。

LodaRAT 如何维持访问权限

LodaRAT 会设置注册表 Run 键、启动快捷方式和计划任务，以便在重启后再次启动，并投放一个 VBScript 看门狗，用于检查恶意软件是否正在运行。如果该进程被停止，它会重新启动。

研究人员将该活动的基础设施追溯至 courtadr.com，这是一个约有 20 年历史的域名。他们观察到，自 2026 年 3 月起，该域名的证书管理发生了变化，随后创建了配套子域名。然而，现有证据无法确定原始域名是否遭到入侵。

研究人员在与 Hackread.com 分享的博客文章中解释道：“威胁行为者如今正大力投资于攻击前端（被入侵的域名、可信的品牌形象、个性化 Targeting），正是因为后端（通用恶意软件）仍然既廉价又有效。”

这些发现凸显了个性化的法律主题电子邮件如何被用于投放恶意软件，同时使欺诈请求显得可信。
