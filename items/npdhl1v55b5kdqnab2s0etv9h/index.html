Rapid7发现CVE-2026-90436已被用于攻击Atlassian Confluence Data Center和N-able N-central

Rapid7 Detected Exploitation of CVE-2026-90436 against Atlassian Confluence Data Center, N-able N-central also Exploited

概述

2026年11月6日，Apache Software Foundation 披露了 CVE-2026-90436，这是 Axis 1.x 中的一个严重不安全反射漏洞（CWE-470），可导致未经身份验证的远程代码执行（RCE）。Apache Axis 是一种简单对象访问协议（SOAP）实现，用于创建 Java Web 服务。CISA 为 CVE-2026-90436 分配的 CVSS 评分为 9.8 严重。

自11月6日首次披露以来，现已发现 Atlassian Confluence Data Center 和 N-able N-central 的某些版本使用了受影响的 Axis 库，容易受到 CVE-2026-90436 的影响。这两款产品都需要采用非默认配置才会存在该漏洞。

CVE-2026-90436 现正被actively利用在野，针对两个已知受影响产品。 2026年11月13日，Rapid7 MDR 在某客户环境中检测到针对 Atlassian Confluence Data Center 的 CVE-2026-90436 利用活动。 另外，2026年11月13日，N-able 报告 了针对 N-central 的在野利用，该漏洞与 CVE-2026-90436 高度相关。一个利用 CVE-2026-90436 并针对 N-central 的概念验证漏洞利用代码于 2026年11月12日公开，属于针对 N-central 的一系列公开零日漏洞披露的一部分。

Rapid7 建议在正常补丁周期之外，以紧急方式修复暴露的系统。

缓解指导

应优先处理可从互联网访问且已启用相关 API 的实例，并检查内部部署情况。应用下述针对各产品的措施，然后调查曾暴露的系统是否存在失陷证据。

Axis 1.x 至 1.4 均受影响，但已停止生命支持（EOL），Apache 不计划发布修复后的 Axis 1.x 版本。Apache 建议迁移到其他 SOAP 引擎（例如 Apache Axis 2），或使用已应用此 补丁 的 Axis 1.x 构建版本。使用受此问题影响产品的组织应遵循产品供应商提供的具体修复说明。

Atlassian Confluence Data Center

Atlassian 列为受影响版本的是 1.x 至 9.x，但前提是启用了“Remote API (XML-RPC & SOAP)”。9.2.28 是修复版本。自 3.0 版本起，新安装默认关闭此设置。Confluence 10.x 及更高版本已移除该功能，因此不受影响；Atlassian Cloud 也不受影响。

受影响用户应升级至 9.2.28 或当前不受影响的 10.x 版本。如果必须等待补丁，管理员可以打开“General Configuration”和“Further Configuration”，编辑设置，清除“Remote API (XML-RPC & SOAP)”并保存。更改无需重启 Confluence 即可生效，但使用该 API 的集成可能会停止工作。

有关最新修复和缓解说明，请遵循 Confluence 公告。

N-able N-central

本地部署管理员应确认“Legacy API”已禁用，即使在 2026.4 HF2 中也是如此。N-able 表示该功能默认处于关闭状态，并提供了禁用 Legacy API 的说明。其 11 月 13 日的指导说明指出，托管环境已直接获得临时保护；采用两种托管模式的客户仍必须遵循供应商有关 Agent 和 Probe 升级的指导。N-able 还出于谨慎考虑，临时禁用了 Intune 集成。请参阅N-able 安全更新以了解这些责任事项。

N-able 表示 2026.4 HF3 将永久移除 Legacy API 访问权限。其11 月 16 日发布通知指出，托管环境的升级已完成，本地部署的正式发布工作正在收尾。本地部署管理员应确认可用性，并在更新可用时遵循发布说明。
