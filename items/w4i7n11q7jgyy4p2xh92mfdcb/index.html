中文原文

Microsoft 11 月补丁星期二安全更新修复了 1,090 个缺陷，其中包括一个已被利用的 Outlook 漏洞和 30 个可能具备蠕虫传播能力的问题。

Microsoft 11 月补丁星期二处理了约 1,090 个新漏洞，少于上个月约 1,400 个。连续两个月超过 Microsoft 此前任何年份的总漏洞数，而整体数量也显得有些令人困惑，因此其他追踪机构报告的总数有所不同。

此次更新涵盖 Windows 及其组件、Office、网络和远程访问、图形、媒体和打印、存储和文件系统、.NET 与 Visual Studio、安全和身份、Azure 和云、Exchange Server、Dynamics 和 Xbox。只有一个漏洞正遭到主动攻击，且没有漏洞已公开被利用。ZDI 表示，这并不意味着实际利用减少，只是零日漏洞更少；并推测 AI 在逆向补丁方面比在闭源软件中寻找和利用漏洞方面更擅长。

被利用的漏洞是 CVE-2026-124194，这是一个 Outlook 欺骗漏洞，而它的名称低估了实际影响。攻击者发送 specially crafted message file（特制消息文件）并诱骗用户打开，Outlook 随后会在没有通常的外部内容警告的情况下连接至攻击者控制的位置，从而泄露用户的 NTLMv2 哈希。

“未经身份验证的攻击者可以发送特制消息文件，并说服用户在受影响版本的 Microsoft Outlook 中打开它。打开该文件可能导致 Outlook 在不显示常规外部内容警告的情况下连接至攻击者控制的网络位置，从而可能泄露可用于冒充用户的身份验证信息。利用需要网络连接和用户交互。”公告如此写道。“攻击者必须向用户发送恶意 Office 文件，并说服他们打开该文件。”

随后，攻击者便能以该用户身份进行身份验证。预览窗格不是攻击路径，CVSS 分数也只有 6.5，但 ZDI 表示应优先处理它，因为 Microsoft 将其标记为已被利用。

CVE-2026-116928 是一个可通过 Exchange Server 触发的 Windows Search 远程代码执行漏洞。未经身份验证的攻击者通过电子邮件发送特制附件，服务器自动建立索引时便会触发该漏洞，因此收件人无需打开任何内容。它属于零点击漏洞，CVSS 评分为 9.8，ZDI 认为它比本月 Exchange 获得的九个补丁中的任何一个都更严重。

CVE-2026-119958 影响 Windows LDAP 服务。未经身份验证的攻击者通过网络发送特制 LDAP 调用，触发越界写入，并在服务上下文中执行代码，这在域控制器上可能造成破坏。ZDI 表示应迅速测试并部署修复。CVE-2026-119952 是一个 Schannel 远程代码执行漏洞，被标记为“Exploitation More Likely”，是少数获此评级的 Critical 补丁之一，其较高的攻击复杂度使评分相对较低。

CVE-2026-119990 是 Azure OpenAI 权限提升漏洞，其公告最初写着“Customer Action Required: Yes”，随后却没有列出任何需要采取的措施。未经身份验证的攻击者可以通过互联网发送特制请求，访问编排信息、更改工作流或中断服务。Microsoft 此后将其修订为无需客户采取任何措施。一份声称需要采取措施、却又没有列出任何措施的公告，是本月最宽松的紧急通知。

另外还有两个漏洞因其组件而格外引人注目。CVE-2026-95962 是鲜为人知的 Windows Virtual Filtering Platform 中的释放后重用漏洞，可通过精心构造的网络数据包触发，且无需身份验证或用户交互。它涉及竞态条件，但 ZDI 指出，在 Pwn2Own 上这类漏洞经常会被攻破。CVE-2026-112967 是 Xbox Live Networking Service 中的堆溢出漏洞，CVSS 评分为 9.8；ZDI 认为其被利用的可能性不高，但乐于想象 Xbox Live 漏洞在真实环境中被利用的场景。

ZDI 统计了本月 30 个可蠕虫化漏洞，低于上个月的 59 个。其中 17 个采用了关于未经身份验证的攻击者通过网络运行代码且无需交互的公告措辞，另有 13 个使用变体措辞、没有 FAQ，或在其摘要和 CVSS 向量中呈现相同模式。ZDI 警告称，其中一些判断可能有误，因为少数公告对细节的描述较为简略。

DNS、DHCP、LDAP 和 Exchange 等面向网络的服务最值得优先关注。

“由于少数公告对细节的描述较为简略，我关于其中一些漏洞的判断可能有误。”ZDI 总结道。“一如既往，我建议尽快测试并部署这些补丁，尤其是 DNS、DHCP、LDAP 和 Exchange 等面向网络的服务”
