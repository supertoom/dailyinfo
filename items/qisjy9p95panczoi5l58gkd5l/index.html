官网页面保留正常安装包的 SHA-256 校验值，实际下发的同名文件却具有不同哈希，Electron 主程序入口已被替换为高度混淆的恶意 JavaScript

· DLSS 5 Swapper　· 供应链替换 · 信息窃取　· 2026.11.23

官网页面保留正常安装包的 SHA-256 校验值，实际下发的同名文件却具有不同哈希；用户看到的是正常文件名和校验值，拿到的却是被替换的安装包。官网分发入口由此成为恶意程序的投递渠道。

01 背景

DLSS 5 Swapper 是一款面向 Windows PC 游戏玩家的第三方工具，可扫描本地游戏，按游戏情况替换 DLSS 组件或安装相关模组，并提供备份、还原功能。其目标是改善兼容游戏的画面表现，实际效果取决于游戏、显卡和安装方案。

2026 年 11 月底，奇安信威胁情报中心红雨滴团队通过私有情报 AI 生产流程发现一起 DLSS 5 Swapper 官网安装包供应链替换事件：官网页面保留正常安装包的 SHA-256 校验值，实际下发的同名文件却具有不同哈希，且 Electron 主程序入口 app.asar/main.js 已被替换为高度混淆的恶意 JavaScript。

用户启动该应用后，恶意脚本按预设流程检查运行环境、请求管理员权限、添加 Windows Defender 排除项，随后解密内嵌数据，在本机释放并启动二级可执行文件。官网分发入口由此成为恶意程序的投递渠道。

02 官网安装包供应链入口

官网页面标注版本为 v2.2.9，安装包名为 DLSS5-Swapper-Setup-2.2.9.exe，公布的 SHA-256 为 e89fb5e59b4304e1fb2bccba7d24353ef83ea22b7b699c68a33828ae4420f735。这一数值也见于 v2.2.9 项目文件镜像的校验清单：https://sourceforge.net/projects/dlss-5-swapper.mirror/files/v2.2.9/。

图3｜官网页面展示的版本、文件名及安装包校验值

本次从官网下载的安装包 SHA-256 为 a473ba884eab3b951300358535cb44067299612b1d075a2de7aa3af19b01e544，与页面公布值不符。校验值不匹配是此次供应链事件最直接的预警信号：用户看到的是正常文件名和校验值，拿到的却是被替换的安装包。

对比显示，正常安装包的 main.js 以游戏扫描与 DLSS 模组安装逻辑开头；被替换的安装包相同位置则出现字符串数组旋转、解码函数和大量混淆表达式。入口文件在应用启动时加载，使恶意逻辑能够借正常桌面程序的外观触发。

03 武器组件

混淆 JavaScript 投递器

恶意入口脚本使用自定义 Base64 字母表、逐项 RC4 字符串解密、数字表达式和无效分支隐藏真实流程，并把大体积数据伪装为 PNG 图片。静态还原后的主链如下：

用户启动应用 → 环境检查 → 请求管理员权限 → 尝试添加 Defender 排除项 → 从内嵌数据解密 PE → 写盘并隐藏启动 → 显示伪造错误提示。

脚本检查 Windows 平台、CPU、内存、显卡及主机信息，对虚拟机和分析环境设置退出条件。若当前进程没有管理员权限，代码通过 PowerShell Start-Process -Verb RunAs 请求 UAC 提升并重新启动自身。

获得管理员权限后，脚本调用 PowerShell 将落地目录和相关进程加入 Windows Defender 排除项，降低二级文件被防护软件拦截的概率。

PNG 附加数据中的二级程序

随后，投递器随机显示类似系统组件缺失或应用启动失败的错误信息，制造程序故障的表象。

二级 PE 的版本资源中出现 Cleaner.exe 和 GoldBrook Street Software SRL 等名称，具有伪装特征。

二级文件 ZfMFTB.exe：信息窃取、外传与任务接收

我们取得上述异常安装包原件，校验其 SHA-256 后离线解包，并按照入口脚本中的拼接、PNG 尾部提取和 AES-256-CBC 解密流程，还原出实际写入磁盘的 ZfMFTB.exe。还原文件大小为 3,502,520 字节，SHA-256 为 90c29fe361b543511f22038c162f22872f93fbf0de518f6f20d377e6c78ecb34。该哈希也出现在公开沙箱对异常安装包的落地文件记录中，能够与脚本中指定的文件名相互印证。

静态恢复与调度。对 ZfMFTB.exe 的五个 LZMA 数据流离线解压，恢复出约 247 万字节的业务代码和数据；五段恢复结果的 MD5 与所附二级载荷分析报告逐项吻合。还原的原生调度链包含环境、语言和重复实例检查，随后进入通信寻址与分阶段信息收集。外层保护逻辑仍可能改变执行路径，以下描述的是已恢复代码中的预设行为。

窃密与外传能力。二级程序收集主机、进程、软件、剪贴板和桌面截图；读取浏览器数据库及密钥、钱包与密码管理器数据、Telegram 和 Steam 等平台会话，以及开发和云服务凭据，并按条件搜集用户文件。采集结果被封装，用 AES-128-CBC 加密后经 HTTP POST 发往当前 C2。目标文件是否存在、权限和运行条件决定实际获取的内容。

内置 C2 与备用寻址。二级文件中的 AES-256-CBC 配置密文解得 ping8.southbazaar.work:443；本次已用相同样本独立解密并重加密校验。程序先 GET https://ping8.southbazaar.work:443/health，要求成功响应中出现 active；内置地址不可用时，代码依次尝试从特定 Telegraph 页面和 Polygon 合约取得备用地址。后两者是寻址媒介，不能将公共服务域名整体列为攻击者 C2。

服务端任务与证据边界。完成上报后，程序可向当前 C2 请求 /joy/ypmjd.citf?h=<主机标识>，按返回的 dl、ex 指令下载并启动文件或执行命令。任务内容由服务端提供；现有静态证据不能证明样本曾成功外传、收到特定任务，或在所有主机上走完该流程。

04 总结

此次攻击利用面向 PC 游戏玩家的官网下载链路：页面保留正常校验值，下载到的同名文件却含有恶意 Electron 入口脚本。投递器将环境检查、权限提升请求、防护排除、二级 PE 释放和伪造报错串成执行链；二级程序进一步具备敏感数据窃取、加密外传和按服务端任务下载或执行的能力。内置 C2 已从样本中静态解密。

建议已下载该版本的用户先计算安装包 SHA-256；若命中下列异常哈希，停止运行并保留文件与下载记录。已运行的主机应重点检查落地路径、Defender 排除项、Electron/Node 进程拉起 PowerShell 和 ZfMFTB.exe 的进程链，以及至内置 C2 的通信。对确认执行过二级程序的主机，应进一步取证并评估浏览器、钱包、游戏账号和开发凭据的暴露风险。
