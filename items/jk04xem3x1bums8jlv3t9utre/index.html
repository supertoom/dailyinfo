漏洞概述

近日，绿盟科技CERT监测到Linux发布安全更新，修复了Linux内核IPv4 TCP释放后重用漏洞（CVE-2026-98432）；由于Linux内核IPv4网络子系统在并发处理TCP连接请求或套接字迁移时存在竞争条件问题，未经身份验证的攻击者可通过发送特制的TCP数据包触发释放后重用（use-after-free），从而造成内核信息泄露、拒绝服务或权限提升，在特定条件下可实现远程代码执行。CVSS评分9.8，目前漏洞细节与PoC已公开，请相关用户尽快采取措施进行防护。

Linux内核是Linux操作系统的核心组件，负责进程管理、内存管理、设备驱动、文件系统及网络协议栈等关键功能，广泛部署于服务器、桌面系统及嵌入式设备中。

• 4.4 <= Linux Kernel

• Linux Kernel 5.10.x < 5.10.272

• Linux Kernel 5.15.x < 5.15.223

• Linux Kernel 6.1.x < 6.1.190

• Linux Kernel 6.6.x < 6.6.159

• Linux Kernel 6.12.x < 6.12.113

• Linux Kernel 6.18.x < 6.18.56

3漏洞检测

3.1 人工检测

Linux系统用户可以通过查看内核版本来判断当前系统是否在受影响范围内，查看操作系统版本信息命令如下：

cat /proc/version

使用下列命令查看MPTCP是否启用：

sysctl net.mptcp.enabled

若当前版本在受影响范围内且启用了MPTC，则可能存在安全风险。

4漏洞防护

4.1 官方升级

目前官方已发布新版本与安全补丁修复此漏洞，请受影响的用户尽快更新进行防护，下载链接：https://www.kernel.org 

https://git.kernel.org/stable/c/e3f33b0a1d89d738e2b913dab519226eaf76e15b

4.2 其他防护措施

若相关用户暂时无法进行升级操作，在不影响业务的情况下可使用下列措施进行缓解（不可替代补丁）：

1、关闭MPTCP并禁用请求套接字迁移，移除sk_reuseport类型的BPF迁移程序，从而降低已公开利用路径的风险；

sysctl -w net.mptcp.enabled=0
sysctl -w net.ipv4.tcpmigratereq=0

2、使用防火墙对携带options的IPv4 SYN数据包进行过滤（需业务评估）；

3、对非必要开放的TCP服务进行访问控制。
