ConnectWise 正在调查一起针对托管服务提供商（MSP）的活跃恶意软件活动。该活动利用已被入侵的 ScreenConnect 环境，向客户设备部署 rogue 远程访问客户端。

该活动最初由网络安全公司 Huntress 于周三发现。Huntress 表示，目前已识别出六家遭到入侵的 MSP，以及 47 家组织中受影响的 286 个端点，受害者数量仍在增加。

Huntress 在 Reddit 上发布称：“我们的 SOC 正在处理一起始于今天约 17:47 UTC 的活跃活动，目标是云托管的 ScreenConnect 实例。”

“我们目前正在追踪 6 家遭到入侵的 MSP 和 286 个以上端点，而且这些数字还在上升。ConnectWise 已介入，正与我们共同处理此事。”

ScreenConnect 是一个远程访问和支持平台，MSP 与 IT 团队使用它远程管理和排查客户设备故障。

据 Huntress 表示，攻击者正在利用 ScreenConnect 的 Run Command 功能，在受管理的端点上部署 ScreenConnect 客户端，从而在合法 MSP 的 ScreenConnect 环境之外提供远程访问。

研究人员还警告称，一种可能更加危险的技术是：当 MSP 技术人员与受感染的客户设备发起 ScreenConnect 会话时，攻击者可能会入侵该技术人员的工作站。

目前尚不清楚这种所报告的反向枢轴技术具体如何运作，包括它是否利用了软件漏洞，或滥用了合法的 ScreenConnect 功能。

ConnectWise 在向 BleepingComputer 发表的声明中确认，正在调查这些攻击，并敦促合作伙伴避免与可能已遭入侵的设备建立交互式远程会话。

ConnectWise 告诉 BleepingComputer：“我们已收到关于影响有限数量 ScreenConnect 合作伙伴的恶意活动的报告，目前正在积极调查。”

“作为预防措施，合作伙伴应避免向疑似已遭入侵的设备开启交互式 ScreenConnect 会话，并使用独立的安全工具进行调查。合作伙伴还应审查账户活动、撤销活动会话、从受信任设备重置凭据，并验证多重身份验证。”

该公司表示，将通过 ConnectWise Trust Center 提供进一步信息和指导。

Huntress 尚未确定攻击者如何获得受影响 MSP 环境的访问权限，但称目前的遥测数据指向凭据泄露和被劫持的 MSP 支持会话。

Huntress 还警告称，攻击者使用的顺序标识符表明，可能还有更多 MSP 此前已遭到入侵。

Huntress 告诉 BleepingComputer：“攻击者分配的顺序标签表明，其他 MSP 可能更早就已遭到入侵，因此 ScreenConnect 用户即使没有收到警报，也应检查其 Run Command 历史记录。”

Huntress 还共享了入侵指标（IOC），以帮助组织识别恶意活动，包括 rogue ScreenConnect 客户端 ID 和攻击者使用的基础设施。

这些指标包括：

  • 攻击者中继： 185.99.255[.]28（主机名：screen）

  • C2 域： newnewnew.gotdns[.]org、soxnewwork.homedns[.]org

  • 可能的额外 C2： cdn007-digitaldownloads[.]com

  • 次级 C2： sc.payproofkit[.]com（155.94.150[.]39，主机名：WIN-FB5CKHMU4E1）

  • Stager： hxxps://ns.mo7sen[.]dev/EadF.php?p=4

  • Rogue ScreenConnect 客户端 ID： 2588ef5c15954b10、ed630cc2c873b091

  • 安装程序模式： /Bin/ScreenConnect.ClientSetup.msi?...&c=Exploited<N>

  • 攻击者名称： Addmin

  • 文件： Panel-Lateral.ps1、runnew.cmd、ToolboxRelayUploader.exe、Run-Lateral-Full.bat

研究人员敦促 MSP 检查其环境是否存在入侵迹象，并避免与可能已受感染的端点发起交互式 ScreenConnect 会话。

BleepingComputer 就此次攻击向 Huntress 提出了更多问题；如果收到回应，将更新这篇文章。

此前与恶意 ScreenConnect 标识符相关的恶意软件活动

BleepingComputer 发现了一个更早的恶意批处理脚本，其中引用了 Huntress 列出的一个恶意 ScreenConnect 客户端 ID，表明该 ID 在此次攻击被披露数个月前就已用于恶意活动。

该脚本名为 SSA-2026-STATEMENT-15518787.bat [VirusTotal]，似乎冒充美国社会保障局声明，并已于 July 25, 2026 首次上传至 VirusTotal。

该批处理文件试图添加 Microsoft Defender 排除项，并通过 Windows Startup 文件夹和 Run 注册表项建立持久化。

随后，它会联系 amexsafekeyupdate.com，以获取两个独立安装程序的安装命令。

与该样本相关的 VirusTotal 沙箱活动包括从 cdn007-digitaldownloads[.]com 和 cyberrexdesign.screenconnect[.]com 下载 ScreenConnect MSI 安装程序；Huntress 将 digitaldownloads[.]com 列为潜在 IOC。

启动第二个安装程序后，该脚本会使用 PowerShell 在正在运行的进程和 Windows 服务中搜索 ed630cc2c873b091，这是 Huntress 识别出的恶意 ScreenConnect 客户端 ID 之一。

如果找到该标识符，脚本便认为安装成功，并通过 Telegram 向攻击者发送通知。

这个更早的脚本似乎是为另一种分发活动设计的，其以社会保障局为主题的文件名表明它可能被用于网络钓鱼攻击。

目前尚不清楚 July 的活动与当前针对 MSP 的攻击是否属于同一波活动。
