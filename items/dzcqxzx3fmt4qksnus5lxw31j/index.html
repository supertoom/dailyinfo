DDEV 不完整 tar 符号链接修复仍可覆盖宿主机文件

DDEV incomplete tar symlink traversal fix allows host file overwrite - Incomplete fix of CVE-2026-32885

AI 导读

DDEV 对 CVE-2026-32885 的不完整修复允许恶意归档通过绝对路径符号链接和后续文件条目覆盖宿主机文件。作者在 HEAD 上执行 Untar 测试，确认文件可写出目标目录、既有文件可被截断并覆盖，而相对路径逃逸与普通 ZipSlip 条目均被正确拒绝。
