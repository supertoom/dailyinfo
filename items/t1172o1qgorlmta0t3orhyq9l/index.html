OpenAI 发布 GPT-6 Cyber，发现 81 个未知 Firefox 高危漏洞

OpenAI’s GPT-6 Cyber found 81 Firefox flaws earlier AI testing missed

AI 导读

OpenAI 发布面向授权安全测试的 GPT-6 Cyber，用于发现漏洞、验证攻击路径并协助开发修复。该模型与 OpenAI 其他模型在受控测试中组合漏洞，从隔离虚拟环境逃逸并在宿主机执行代码；研究人员借此发现 81 个此前未知、被 Mozilla 评为高危的 Firefox 漏洞，并为 948 个 Linux 内核漏洞开发可用 Exploit。

正文 · AI 翻译
中文原文

OpenAI 推出了 GPT-6 Cyber，这是 GPT-6 Astra 的一个版本，经过训练可发现软件漏洞、测试攻击者可能如何利用这些漏洞，并协助开发修复方案。该模型旨在用于对网站和应用程序进行经授权的安全测试。

漏洞研究与安全测试

OpenAI 使用 GPT-6 Cyber 帮助保护其系统，包括用于训练其 AI 模型的基础设施。在受控安全测试中，使用 GPT-6 Cyber 和其他 OpenAI 模型的智能体组合漏洞，从隔离的虚拟环境中逃逸，并在主机计算机上运行代码。该公司表示，其利用相关发现修补软件、收紧网络限制，并向维护者和供应商报告问题。

OpenAI 研究人员还使用该模型识别出 81 个此前未知、被 Mozilla 列为高危级别的 Firefox 漏洞，并为 948 个 Linux 内核漏洞开发了有效利用程序。Mozilla 已为许多 Firefox 漏洞发布修复方案，该模型也贡献了建议的补丁。

研究人员将 GPT-6 Cyber 与其他 OpenAI 模型结合使用，开发并验证了相关利用程序，演示了一个严重的Brotli 漏洞如何允许在受影响应用程序中远程执行代码。

“GPT 6 Cyber 是网络防御领域的世界级模型。Firefox 进入 2026 年时，已经是全球经过最多强化和审查的代码库之一。即便在多代前沿模型进一步强化之后，GPT 6 Cyber 仍发现了此前未知的高危漏洞、识别出架构改进，并帮助我们向数百万用户发布修复方案。”Firefox 的杰出工程师 Brian Grinstead 表示。

安全防护与关键基础设施

该公司表示，其新增或强化了多项安全防护，以应对该模型的网络安全能力带来的风险。这些措施包括：监控超出用户授权范围的行为、针对新出现威胁的定向监控、Private Safety Processing、针对被盗凭据的保护，以及阻止高风险网络协助的检查。此外，还建议对高风险工作流实施沙箱隔离、操作审查和人工监督。

OpenAI 与 Dragos 合作，使用允许网络攻击的 Daybreak Red 模型在受控实验室中测试防护措施。评估范围涵盖从网络发现与侦察，到敏感数据提取和未经授权的设备操作等逐步推进的请求。

“Dragos 让一个前沿模型面对模拟发电厂靶场，几乎没有向它提供任何信息。它自行将 OT 资产与 IT 噪声区分开来，随后在管理保护继电器数据的工程软件中发现了两个零日漏洞，暴露了保护设置和断路器跳闸逻辑。”Dragos 首席 AI 官 Rob T. Lee 表示。

网络安全基准测试结果

OpenAI 在多项任务中评估了 GPT-6 Cyber，这些任务要求模型理解软件、识别漏洞并开发有效利用程序。该公司表示，在大多数网络安全任务中，该模型的表现优于 GPT-6 Astra，包括 Astra 在未拒绝请求的情况下尝试完成的任务。

ExploitGym（来源：OpenAI）

在 ExploitGym 中，模型需要判断其能否利用远程目标中的指定漏洞，GPT-6 Cyber 的得分为 48.5%。其前代模型 GPT-5.6 Cyber 的得分为 32.1%。

在单独的 ExploitGym Honeypot 评估中，GPT-6 Cyber 在未部署安全指令的情况下，99.93% 的测试中避免利用范围之外的服务；部署安全指令后，这一比例为 100%。

该公司在其 Preparedness Framework 中将 GPT-6 Cyber 归类为网络安全领域的 Critical。

客户访问权限与计划扩展

GPT-6 Cyber 最初通过 API 和 Codex 向经选定并获批准的 Daybreak Red 客户提供。OpenAI 计划将该项目的访问权限扩展至所有客户。

该公司还在努力扩大与安全提供商、关键基础设施运营商和国家实验室的合作，以评估利用 AI 辅助测试工业系统。公司增加了对威胁调查的投入，以检测涉及运行技术和工业控制系统的模型使用行为。
