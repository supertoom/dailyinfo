Swati Khandelwal2026年11月6日人工智能 / 浏览器安全

Forever Security（一家端点安全公司）的研究人员在一项测试中展示，一个能够在 claude.ai 上运行脚本的浏览器扩展，可以让 Claude Desktop 在某人的计算机上运行代码。

该攻击需要 Dispatch，这是 Claude 的一项功能，允许用户从手机向 Claude Desktop 发送任务。研究人员本周早些时候表示，使这一攻击成为可能的漏洞目前仍可被利用。

Claude Desktop 是一个 AI 代理，能够在安装它的计算机上运行命令。研究人员发现，Dispatch 还会接受用户在 claude.ai（Claude 网站）上的普通登录会话，尽管该网站上并未显示任何指向 Dispatch 的链接。这使得在该网站上运行的扩展可以向 Claude Desktop 发送指令，就好像是用户本人发送的一样。

研究人员表示，Claude 的开发商 Anthropic 于10月13日告知他们，Dispatch 将被停用，目标是在10月底完成停用。Dispatch 帮助页面最后更新于上周晚些时候，其中并未提及停用事宜。

页面称 Dispatch 已停止向新用户开放，而已经在部分 Pro、Max 和 Ultra 方案中使用该功能的用户“目前仍可继续使用”。

攻击方式

根据 Forever Security 研究人员 Gal Weizman 撰写的技术报告，该攻击需要两个条件：一个能够在 claude.ai 上运行脚本的扩展，以及一个同时登录了 claude.ai 和 Claude Desktop 并启用了 Dispatch 的用户。

该扩展可能是恶意扩展、接收了被入侵更新的合法扩展，或者存在安全漏洞的合法扩展。Dispatch 本身仅在计算机处于唤醒状态且桌面应用处于打开状态时才能工作。

在测试中，一个运行在用户 claude.ai 页面上的脚本打开 Dispatch，并像是用户本人一样向 Claude 发送了四条提示。这些提示要求 Claude 安装一个 npm 包。

Claude 起初对这个不熟悉的包有所犹豫，但一条以用户口吻发出的后续消息让它决定继续执行。

Claude 在执行操作前会请求批准，但这些批准提示出现在扩展所控制的网页中。脚本每秒都会点击“Allow”按钮，因此无需任何人在旁查看。

随后，Claude 运行了一次全局 npm install，该包的安装脚本打开了计算器应用。无需任何浏览器漏洞利用。研究人员表示，鉴于 Claude 在计算机上拥有的权限，同一步骤也可能会窃取文件或安装后门。

测试是在浏览器和 Claude Desktop 位于同一台计算机上的情况下进行的，研究人员报告称未发现真实攻击。他们表示，由于 Dispatch 会连接设备，该扩展还能够访问登录了同一 Claude 账户的另一台计算机上的 Claude Desktop。报告描述了这一情况，但未予展示。

如果某人在家用计算机和工作笔记本上使用同一个个人 Claude 账户并启用了 Dispatch，这种可达性同样可以将家用计算机与工作笔记本连接起来。研究人员在其客户的工作计算机上见到过启用了跨设备 Dispatch 的个人 Claude 账户。

研究人员于5月14日向 Anthropic 报告了该漏洞。据研究人员称，该公司在5月19日确认其有效，但随后将报告关闭，理由是其与公司内部已经发现的一个问题重复。

研究人员写道：“Anthropic 正在弃用 Dispatch，但其背后的设计仍会保留。”他们补充称，Claude 的另外两项功能——Claude Code Remote Control 和 Claude Cowork sessions——也会让扩展程序执行同样的攻击。他们的文章没有对这些功能进行测试，并计划在后续文章中介绍。

Dispatch 用户可以采取的措施

在 Claude Desktop 中，Dispatch 是 Cowork 的一部分，显示在左侧面板中。Dispatch 帮助页面表示，用户应了解如何在启用该功能前快速断开连接或撤销访问权限，但并未说明具体方法。

研究人员建议采取以下步骤：

  • 如果不需要跨设备 Dispatch，请将其关闭。如果确实需要，请审查设备的配对、批准和移除方式。
  • 像对待计算机上的其他软件一样对待浏览器扩展：检查其权限、控制安装的内容，并审查使其获得更多访问权限的更新。
  • 监控 AI agents 在计算机上执行的操作，包括意外的软件包安装、设置更改、对凭据的访问以及外部连接。
