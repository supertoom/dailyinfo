2026年11月25日，深瞳漏洞实验室监测到一则GeoServer组件存在远程代码执行漏洞的信息，漏洞编号：CVE-2026-129242，CVE-2026-129243，CVE-2026-129244，CVE-2026-129245，CVE-2026-120705，漏洞威胁等级：严重。

漏洞名称：

GeoServer 认证前远程代码执行漏洞利用链(CVE-2026-129242 等)

组件名称：

GeoServer

影响范围：

3.0.x <= GeoServer < 3.0.2

2.28.x <= GeoServer < 2.28.6

GeoServer < 2.27.7

漏洞类型：

远程代码执行

利用条件：

1、用户认证：否

2、前置条件：默认配置，WFS/REST 服务端点可达

3、触发方式：远程

综合评价：

<综合评定利用难度>：容易，整条利用链无需任何有效凭据即可远程代码执行。

<综合评定威胁等级>：严重，可造成未授权远程代码执行。

官方解决方案：

已发布

漏洞分析

组件介绍

GeoServer 是 OpenGeo（现 Crossware/OSGeo 社区）维护的开源地理空间数据服务器，用于发布和共享 WFS/WMS 等 OGC 标准地理数据服务，基于 Java 构建，并非编程语言标准库内置组件，常作为地图服务基础设施暴露于内外网。在本次漏洞链中，其匿名可用的 WFS stored query 功能、remember-me 认证机制、REST API 与 HSQLDB JDBC 用户组服务被串联滥用，成为未认证攻击者从信息泄露走到远程代码执行的完整路径。

漏洞简介

2026年11月25日，深瞳漏洞实验室监测到一则GeoServer组件存在远程代码执行漏洞的信息，漏洞编号：CVE-2026-129242，CVE-2026-129243，CVE-2026-129244，CVE-2026-129245，CVE-2026-120705，漏洞威胁等级：严重。

该利用链由五个漏洞组合构成（核心为 CVE-2026-129242）： GeoServer匿名 WFS stored query 相关缺陷允许未认证攻击者探测数据目录路径并创建携带延迟 XInclude 的存储查询；查询信息被回显时，DescribeStoredQueries 响应泄露 remember-me 密钥与管理员口令摘要，攻击者据此伪造 remember-me Cookie向 REST API 换取管理员会话；取得管理员权限后，上传恶意 HSQLDB 数据库并注册 JDBC 用户组服务，通过用户属性查询触发 HSQLDB 反序列化，最终在服务器上以服务进程权限执行任意命令。整条链路无需任何有效凭据。

解决方案

官方修复建议

官方已于 2026 年 11 月 23 日发布公告，建议升级至 GeoServer 3.0.2、2.28.6 或 2.27.7(对应 3.0.x、2.28.x、2.27.x 及更早 2.x 系列)。

下载链接：https://geoserver.org/download/

临时修复建议

  • 限制 WFS 与 REST 端点(/geoserver/web、/geoserver/rest)仅对可信来源开放；

  • 关闭或限制匿名 WFS stored query 功能；

  • 拦截对 /geoserver/ows、/geoserver/wfs 的匿名 GET/POST 请求中包含以下特征的流量：

  • DescribeStoredQueries、storedQuery、xinclude:、xi:include、href="file: 等 WFS stored query + XInclude 组合特征

  • GetConfig、/rest/security/usergroup/ 等 REST API 匿名调用特征

以上措施不可替代升级方案，需尽快升级至修复版本
