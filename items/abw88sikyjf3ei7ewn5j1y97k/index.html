中文原文

网络安全研究人员发现了 13 个恶意 NuGet 包，它们以虚假的带回家作业评估为掩护，专门针对 Windows .NET 开发人员。

“大多数包伪装成 WinUI 3 和 WPF [Windows Presentation Foundation] 按钮控件，”Socket 安全研究员 Kush Pandya 表示，“在我们分析的版本中，构建或运行使用这些包的项目会从 GitHub 下载文件，在 Microsoft On-Screen Keyboard（osk.exe）周围暂存一对 DLL 侧加载文件，或者下载并运行可执行文件。”

截至撰写本文时，所有已识别的 NuGet 包均已从该库中删除。这些包的名称如下——

  • WinUI.Button
  • VS_Builder.MSBuildAnalyzer
  • VS_Builder.WinUI3Controls
  • HappyOne.MSBuildAnalyzer
  • HappyOne.WinUI3Controls
  • Web3TotalButton
  • RevertButtonIcon
  • WinUI3IconButton
  • WindowsAccentColorName
  • SetButtonColor
  • InitializeCustomButton
  • StyledAppButton
  • StyledComponent

第一个 NuGet 包 WinUI3IconButton 于 2026 年 7 月 23 日上传到注册表，表明这场活动已经在未引起注意的情况下持续了相当长一段时间。最后两个上传的包 HappyOne.MSBuildAnalyzer 和 HappyOne.WinUI3Controls 于 2026 年 11 月 4 日上传，此前 NuGet 已于 2026 年 11 月 2 日移除了 VS_Builder.MSBuildAnalyzer 和 VS_Builder.WinUI3Controls。

起点是一个于 2026 年 11 月 3 日创建的 GitHub 仓库（“stevenleedig-ux/WinUI3_Home_Assessment”）。该仓库提供了一组评估任务，任务是增强 FileButton 控件并实现异常处理，候选人必须在三到四小时内完成。目前尚不清楚目标是如何被引导至这些诱饵项目的。

README 文件还允许参加测试的人使用 GitHub Copilot、ChatGPT 或 Claude 等人工智能（AI）开发助手，但不建议他们将整个项目复制粘贴到工具中，并在没有“理解它”的情况下直接生成解决方案。

评估仓库中包含一个“WinUI3_Home_Assessment.csproj”文件，其中引用了“ version 1.2.7 和 VS_Builder.WinUI3Controls version 1.0.7。”

“VS_Builder.MSBuildAnalyzer 后来以 HappyOne.MSBuildAnalyzer 的名义重新发布，它附带一个 MSBuild 目标文件 build/VS_Builder.MsBuildAnalyzer.targets，该文件会在每次构建后运行随包的 DLL ['MSBuildAnalyzer.dll']，”Pandya 表示。“在诱饵包所捆绑的版本中，该 DLL 会从 GitHub 下载文件至 %LOCALAPPDATA%\osk\OskSupport.dll，并将 C:\Windows\System32\osk.exe 复制到其旁边。”

随后，VS_Builder.WinUI3Controls 包会通过“将点击路由至 Windows 文件和文件夹”的 FileButton 控件启动复制后的二进制文件，从而通过一种称为 DLL 侧加载的已知技术触发 DLL 的执行。

同样，从 WinUI.Button 包创建 WUIButton 控件会启动“lib/net8.0-windows10.0.19041/WinUI.Button.dll”中的后台例程，该例程使用嵌入的访问令牌，通过 GitHub API 从“Carol-White-Super/cloud”仓库下载“avast.exe”，将其保存为“%TEMP%\Launcher.exe”，然后运行。

Socket 还表示，它发现了两个冒充 axios JavaScript 库的虚假仓库——

  • jason-code-super/axios
  • stevenleedig-ux/axios-http（与托管该评估项目的 GitHub 账户相同）

这两个仓库都被标记为一个名为“axios-test-one”的恶意 Node.js 库的副本。该库冒充 Axios HTTP 客户端，但包含可启用代码执行和 shell 访问的功能。这些仓库提供一个名为“lib/env/axios.csproj.”的 Windows 可执行文件。

对其提交历史的分析揭示了两个仓库中的多个二进制文件，包括 -

  • 一个加载器（“updater.exe”和“msedgewebview2.exe”），使用一个 GitHub 仓库（“James-White-Super/React_prj”）作为双向命令与控制（C2）
  • 一个 PyInstaller 程序，用作 Google Chrome 配置文件窃取器，并将信息上传至 GitHub（“gabsantosbus-star/EngineeringRepository”），以及
  • 一个“WeapF”载荷，将计算机名称、用户名、时区和 CPU 型号报告给攻击者控制的 Telegram 机器人

更值得注意的是，已发现名为“gabsantosbus-star”（又名 Gabriel）的 GitHub 账户为上述两个虚假 Axios 仓库以及第三个虚假 Axios 仓库“figma-share/axios-http”创建了首次提交。

“2026 年 11 月 13 日，gabsantosbus-star [...] 发布了‘Crypto Wallet Analyzer’的 GitHub Release，这是一个单文件 .NET 应用，”Socket 表示。“README 将该应用描述为第一阶段客户端交付物，用于盘点 Chrome 配置文件中的八种加密钱包扩展，并且不会发起任何网络请求。”

“可见的应用确实只做这些，但其反编译后的 MainWindow 构造函数还会加载可执行文件中捆绑的原生 DLL。该 DLL 加载后会启动一个后台线程，而关闭窗口只会将其隐藏，因此进程会继续运行。”

相关 DLL 是加载器的一个新版本，使用另一个仓库（“Best-Seller-Dev/dexTrader”）进行 C2。截至撰写本文时，该 GitHub 账户已无法访问。

进一步调查发现，该诱饵于 2026 年 11 月 7 日在名为 LaborX 的 Web3 自由职业市场上以相同人设发布，威胁行为者自称是“注重细节、寻求与熟练自由职业者合作开展各类项目的客户”。

这份标价 $8,500-10,000 的招聘启事目前仍可访问，声称正在寻找一名 C# WPF 开发者，参与开发其轻量级 Windows .NET 桌面应用，该应用“盘点本地 PC 上安装的加密钱包软件，包括浏览器钱包扩展和桌面钱包应用”。

在其 X 资料页上，他们自称是位于佛罗里达州迈阿密的“区块链和 DeFi 专家”及“加密货币专家”。但查看其“关于此账户”可知，该资料页实际位于韩国。该账户创建于 2026 年 7 月。

这层关系网并未就此结束，因为有证据表明，“axios-test-one”npm 库是一个更大规模包集合的一部分。该集合包含六个包，由三个 npm 账户 gsanbus、jasonsuperstar 和 jasonsayman 于 2026 年 7 月 14 日至 23 日之间发布 -

  • axios-test-one
  • telemetry-metrics
  • telemetry-axios
  • axios-native
  • fs-extra-core
  • vitest-axios

使用“jasonsayman”这一名称尤其值得注意，因为它显然是在试图冒充“jasonsaayman”，即 Axios 开发者兼维护者所属的合法 GitHub 账户 belonging。

“telemetry-metrics 和 telemetry-axios 从 ThoSuperstarDev/axios-http 下载 Windows 可执行文件并运行，fs-extra-core 从 jason-code-super/axios 下载一个可执行文件并将其保存为 msedgewebview2.exe，而 axios 克隆包会拉取这些包，”Socket 表示。

值得注意的是，"ThoSuperstarDev"是"figma-share"之前使用的 GitHub 账户名，而后者恰好还托管着一个ClickFix 风格页面，该页面显示伪造的 reCAPTCHA 验证提示，并引导访客将安全令牌复制并粘贴到 Windows 运行对话框中，以处理所谓的"Security Handshake Error"。

这起欺诈性招聘活动尚未被归因于任何已具名的威胁行为者或组织。不过，Socket 指出，其 tradecraft 与朝鲜和伊朗策划的类似招聘主题活动存在相似之处。

Pandya 表示："我们没有发现任何指标或代码与任何已公开的 Contagious Interview 或其他朝鲜活动共享；在我们恢复的各个阶段中，也没有发现公开与 Contagious Interview 关联的恶意软件家族（例如 BeaverTail、InvisibleFerret 和 OtterCookie）；也没有发现与该加载程序相符的公开记录在案的恶意软件家族。"
