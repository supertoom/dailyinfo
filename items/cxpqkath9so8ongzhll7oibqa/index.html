Chrome 158 稳定版发布，修复 204 项安全问题

Stable Channel Update for Desktop

AI 导读

Google 将 Chrome 158 推送至 Windows、Mac 和 Linux 稳定渠道，版本为 Linux 158.0.8127.36、Windows/Mac 158.0.8127.36/.37，更新将在未来数日或数周内逐步推出。

值得关注

公告集中列出 Chrome 158 的 204 项安全修复及对应 CVE、等级和报告者，便于按组件与风险级别梳理升级影响。

正文 · AI 翻译
中文原文

 Chrome 团队很高兴宣布 Chrome 158 已推广至适用于 Windows、Mac 和 Linux 的稳定渠道。这将在未来几天/几周内逐步推出。

Chrome 158.0.8127.36 (Linux) 158.0.8127.36/.37 Windows/Mac 包含多项修复和改进——变更列表可在日志中查看。请关注即将发布的关于新功能以及 158 版本所交付重大成果的Chrome和Chromium博客文章

安全修复与奖励
