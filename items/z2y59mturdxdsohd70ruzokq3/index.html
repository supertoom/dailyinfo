中文原文

Cursor 证实其遭受了一起安全入侵，攻击者在窃取 AI 基础设施提供商 Fireworks AI 的凭据后，通过其市场分发了恶意的 Claude Code 扩展。

这次入侵还使攻击者得以访问内部系统并窃取客户数据，包括历史 AI 编程代理轨迹，其中包含未编辑处理的凭据，后来这些凭据被用于入侵更多服务。

Cursor 在周五发布的新事件报告中披露了此次入侵。报告解释了攻击者如何在 10 月 29 日通过 Cursor 的市场分发Anthropic 的 Claude Code 扩展恶意版本。

此次攻击使最多 5,000 名开发者接触到一种会安装持久 SSH 后门的恶意软件。

Cursor 是一款基于 Microsoft 开源 Visual Studio Code（VS Code）构建的 AI 编程代码编辑器，可让开发者借助 AI 助手编写、修改和调试软件。

据 Cursor 称，此次攻击始于攻击者取得存储在 Fireworks AI 上的访问密钥。Fireworks AI 是一家用于 AI 模型训练和推理的第三方提供商。

攻击者使用泄露的密钥，从 Cursor 用于与 Fireworks 共享信息的只读存储桶中复制了数据。

该存储桶包含从 2025 年起收集的大部分历史 AI 编程代理轨迹，来源是未启用隐私模式且其数据可用于模型训练的用户。其中一些轨迹包含未编辑处理的 API 凭据，使攻击者得以访问更多 Cursor 系统。

Cursor 表示，编程代理轨迹遭泄露的用户不足 0.05%，API 凭据遭入侵的客户不足 0.01%。

攻击者使用泄露的凭据，从 Cursor 的多项软件即服务（SaaS）工具中窃取了数据，包括：

  • 已归档的 Cursor 非生产源代码仓库，其中一些包含业务联系信息。
  • 有限的客户支持信息和电子邮件往来记录。
  • 产品使用指标和客户联系信息。
  • 部分 AI 编程代理对话的摘要。
  • 客户此前提供给 Cursor 支持团队的凭据。

Cursor 表示，其监控系统检测到了未经授权的活动，促使公司撤销 Fireworks 访问密钥、轮换泄露的凭据，并调查其他未经授权的访问。

随着调查推进，Cursor 暂时关闭了一些内部和产品服务，以防万一。

然而，攻击者已经取得了一项凭据，使其能够通过 Cursor 的市场分发扩展。

10 月 29 日，攻击者使用该凭据，在 Cursor 的 VS Code 扩展市场上发布了 Anthropic 的 Claude Code 扩展恶意副本。

Cursor 解释道：“10 月 29 日，攻击者利用从我们内部系统泄露数据中取得的被盗凭据，将 Anthropic 的 Claude Code 扩展恶意且未经授权的副本直接放到了用于提供 Cursor VS Code 扩展市场服务的缓存中。”

此次攻击并未入侵 Anthropic 的官方扩展或 Open VSX；后者是 Cursor 使用的扩展市场。

这些恶意扩展的版本为 2.1.312 和 2.1.313，在 Cursor 将其下架前可获取约 11 小时。

正如 BleepingComputer 此前报道的，攻击者修改了正版 Claude Code 扩展，使其执行恶意 JavaScript，试图在开发者计算机上安装持久 SSH 后门。

该恶意软件收集系统信息、安装攻击者控制的 SSH 密钥、尝试启用 SSH 访问，并配置持久化机制以维持远程访问。

然而，安全研究人员发现了代码错误，该后门很可能无法在许多尚未启用 SSH 的 Windows 和 macOS 系统上运行。

Cursor 估计，在暴露期间请求受影响扩展版本的最多 5,000 名用户可能收到了恶意构建版本。

该公司表示，其生产基础设施、官方应用发布版本、客户代码存储库，以及启用了隐私模式的用户所属的代码和提示词均未受到影响。

Cursor 表示，作为预防措施，已将所有推理流量迁移 away from Fireworks，撤销并轮换了暴露的凭据，重建了扩展市场，并重新部署了生产基础设施。

建议在攻击期间安装或更新了受影响 Claude Code 扩展的客户遵循 Cursor 的补救指南。

黑色十月

这起事件发生在一波针对 AI 开发平台的攻击浪潮之中，网络安全公司 Wiz 将其称为 “黑色十月”。

这些攻击针对开发基础设施，以窃取身份验证凭据，尤其是那些可访问 AI 模型的凭据。

被盗凭据已被用于未经授权的 AI 推理，为受影响客户产生了巨额费用，部分事件还与尝试进行 AI 模型蒸馏有关。

这些攻击影响了众多公司，包括 Railway、Northflank、Lightning AI、OpenCode 和 Warp。

在 Railway，攻击者窃取了客户身份验证密钥，随后利用这些密钥产生了约 $740,000 的欺诈性 AI 费用。OpenCode 也报告了 API 密钥暴露和未经授权的 AI 使用。

Fireworks AI 也受到影响，于 10 月 披露了多起安全事件，其中一起涉及 API 密钥和令牌暴露，另一起则是攻击者通过遭入侵的第三方云提供商访问了开发人员计算机。

Fireworks 事件还影响了其他客户，包括 Notion；该公司最近披露，少数工作区的 AI 聊天记录遭到暴露。
