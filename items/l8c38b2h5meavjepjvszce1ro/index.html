VOLTA-AUTODOXER 利用 LLM 对窃取数据进行受害者价值评估

Appraisal by AI: Model-driven victim prioritization in the VOLTA infostealer

AI 导读

Cisco Talos 分析了自删除型 Windows 信息窃取程序 VOLTA-AUTODOXER：它采集浏览器凭据、会话、支付卡、加密钱包种子、OAuth 令牌、云端密钥、Wi-Fi 密码及截图后，将结构化证据发送至 OpenRouter，由 LLM 生成包含“WHAT THEY'RE WORTH”和“THEIR OPSEC”的受害者评估。

值得关注

文章拆解了 VOLTA 将 LLM 接入受害者筛选流程的方式，并给出模型拒绝时的回退链与事件响应处置要点。

正文 · AI 翻译
中文原文
  • VOLTA 是一种成熟的信息窃取植入程序，带有可选的 AI 集成层。在窃取凭据、会话和加密货币钱包后，VOLTA 会将结构化证据包发送给 LLM，按照变现价值对受害者的资产进行排名。
  • 如果模型拒绝执行目标评估，VOLTA 会故障转移至三模型链，这意味着背后存在直接的工程投入，并且预期会触及模型防护栏。 
  • 该窃密程序会自我删除，且不存在攻击者控制的基础设施。其 AI 集成的创新之处在于，它并非用于支持传统恶意软件能力，而是作为操作人员的情报分析员开展工作。 

网络犯罪领域出现了一个新思路——广泛撒网、窃取一切，再让 AI 筛选具体目标。一款自称为“VOLTA-AUTODOXER”的新型恶意软件通过CAIRN 研究项目浮出水面。它是一种可自我删除的 Windows 信息窃取程序，并通过由 LLM 驱动的受害者画像阶段来增强其窃取后工作流。

在收集标准的窃密程序所获数据后，包括浏览器密码；Cookie；支付卡；加密货币钱包助记词；Discord、Telegram、Steam 和 Roblox 会话；Microsoft OAuth 令牌；SSH 和云提供商密钥；Wi-Fi 配置文件；以及屏幕截图，VOLTA 会构建一个关于该机器背后用户的结构化证据包。该证据包包含地理位置和家庭住址、雇主及雇主域名、推断出的出生年份、银行卡末四位数字、Slack 工作区、文档作者元数据、iPhone 备份指示信息，以及实时 Roblox 账户估值。随后，它会利用窃取的会话访问权限进一步充实该证据包：搜索受害者的 Gmail 中的购买收据，以佐证家庭住址；获取 UberEats 和 DoorDash 订单历史；并通过窃取的令牌充实 Discord 账户信息。

该证据包会被序列化，并使用一条系统提示词 POST 到 OpenRouter，该提示词指示模型充当“一名起草目标评估的取证情报分析员”。所需输出包括一个标题为“WHAT THEY'RE WORTH”的部分，其中按变现价值将贵重资产划分为低/中/高等级；以及一个关于“THEIR OPSEC”的部分，其中包含对受害者安全态势和密码卫生状况的评估。该模型充当操作人员的分流分析员，将原始凭据日志转化为一份按优先级排列且附有引用依据的受害者及其可变现资产档案。

AI 配置：“深入，而非泛泛而谈……直言不讳、具体、准确。” 

VOLTA 采用多模型架构，以便在某个模型拒绝执行时进行弹性回退；在转交给最多三个模型的链之前，它会检查每个响应中是否包含诸如“我不能”或“我无法”之类的措辞。

端点 

https[:]//openrouter[.]ai/api/v1/chat/completions 

默认模型 

anthropic/claude-opus-4.6 

回退链 

moonshotai/kimi-k2 → google/gemini-2.5-flash 

温度 

0.2 — 确定性一致的输出 

请求格式 

手工组装的 JSON；无 SDK；User-Agent Mozilla/5.0 

模型温度控制 LLM 生成文本的随机性和可预测性。较低的硬编码温度值（0.2）表明攻击者强调准确性和一致性。该恶意软件还使用级联模型链来处理故障。这种多模型架构表明，操作者预料到会遇到拒绝响应，因此后备机制会转向几个规模更小且限制更宽松的模型。

系统提示词直接揭示了操作者的使用场景：生成一份关于受害者是否适合作为目标的简明分析评估，并提供可审计的引用记录作为依据。

提示词还要求完成一项不同寻常的任务，而这正是智能体所擅长的：在稀疏且互不相关的数据之间建立联系。例如，鼓励将受害者的姓名、地址或大学与其密码中的模式联系起来。在这种情况下，模型并非被要求查找数据；而是被要求延展数据，并作出有用的推断，从而提升已抓取数据的价值。

窃密功能 

VOLTA 的功能与现代数字生活产生的记录高度契合，远超基本的凭据窃取。在单次运行中，该窃密程序可以从基于 Chromium 的浏览器中提取浏览器凭据、Cookie 和已保存的支付卡。它还会针对 Firefox 和 Thunderbird、Outlook 配置文件、Slack 工作区、Steam 和 Battle.net 会话、Discord 令牌、Telegram 会话、Roblox 账户，以及 SSH 和云服务商配置文件（gcloud、OpenVPN、Hide.me）进行窃取。VOLTA 不只是复制加密货币钱包，还会直接对保管库运行内嵌破解程序，并将结果写入其自身报告中的 WALLET VAULTS CRACKED 一行。  

机器上保存的每个 Wi-Fi 密码均通过直接调用 WlanGetProfileList 提取，并转储为明文。

真正让 VOLTA 有别于普通窃密程序的是初始收集之后的处理。它会进行实时数据增强，利用被盗会话深入挖掘受害者的数据。例如，使用受害者自己的已认证 Gmail 令牌，查询其收件箱中来自 Amazon、DoorDash、Uber Eats、Grubhub、Walmart 和 PayPal 的收据，然后审查这些收据以确认家庭住址。被盗的 Uber Eats 和 DoorDash 会话会被直接调用以获取订单历史。Discord 令牌会被重新用于丰富受害者账户资料。Roblox 库存则通过实时查询“Rolimons[.]com”进行估值。

收集和数据增强阶段完成后，数据会在本地汇编并整理到一个名为“Identity_Report.txt”的文件中。该文件会被序列化为 JSON 格式的压缩包，与系统提示词一并 POST 至 OpenRouter。返回的载荷会被接收为“AI_Analysis.txt”。两个文件会一起外传至“volta_dox.zip”。

整个推理往返过程完全通过受害者自己的网络连接，在他们自己的机器上进行，随后结果才会被外泄。 

部署模型 

VOLTA 没有将 Telegram 频道、API 密钥和设置直接硬编码到代码中（编写个人使用工具的人很可能会这样做），而是使用了一个包含六个可替换插槽的模板，并在构建时填入这些内容。  

这表明它采用的是构建者模型：作者出售访问权限，客户提供相应值，构建者为每个订单编译一个定制二进制文件。这些插槽中的凭据经过加密，但并非真正有意义的加密。密钥是同一二进制文件中两个常量的 SHA-256 值，但它之所以存在，大概是因为客户期望自己的 API 密钥不以明文形式存放，而非因为它能提供真正的保护。任何逆向该文件的人都能恢复这些凭据。  

如果 VOLTA 确实是商品化的恶意软件，那么 AI 情报档案功能就不是作者为自己的行动而发明的。它是一项功能，使任何技术水平的客户都能将其指向受害者，并开始在自己的 Telegram 收件箱中接收排名后的目标评估。  

观察到的该恶意软件的所有终端均由第三方控制。没有任何行为者自有基础设施。

对策 

VOLTA 的大部分令牌窃取能力依赖于绕过 Chrome 中 App-Bound Encryption（ABE）的技术。一项限制哪些进程可使用 --headless 启动 Chrome 的应用程序控制策略，将彻底阻断 ABE 解密路径。至少，你还可以在 Chrome 由任何不在已知开发人员之列的进程使用 --headless 启动时发出警报。用于安全存储凭据的硬件支持存储最佳实践也同样适用。 

一旦发生失陷，主可执行文件可能已自行删除，但用户仍应尝试保留“APPDATA%\volta_debug.txt”文件。这是一个带时间戳的收集日志，准确记录了所收集的内容以及 LLM 调用是否成功。撤销任何可能已失陷的令牌并更改密码。对于加密货币钱包，如果种子短语曾以明文形式存放在磁盘上，应将该钱包视为已完全失陷，并将资金迁移到一个使用隔离设备生成种子的新钱包中。 

结论 

VOLTA 是一款成熟的窃密器，它在后期增加了一层 AI，唯一目的就是减轻操作者的分析工作。这里 AI 改进的维度并非速度或规模，而是取代人力投入；同样的逻辑也可见于 CLOSEDQUORUM，只是应用在了不同的阶段。这些植入体反映了相同的底层逻辑：找出需要最多持续人工关注的步骤，并将其替换为一次模型调用。对防御者而言，问题不在于这种模式是否会在其他地方出现，而在于它下一步会触及哪个阶段。

第二个值得关注的趋势是预期模型拒绝以及构建韧性的方法。在这种情况下，它包括从 Claude 到 Kimi 再到 Gemini 的回退链，以及在没有任何密钥时完全跳过 LLM 阶段运行的能力。随着恶意软件中 AI 集成的成熟，拒绝韧性可能成为标准设计要求。 

这两个趋势背后的核心问题是，犯罪软件的投入转移是否会以有意义的方式改变其格局：降低运营门槛、扩大规模上限，还是两者兼有。网络犯罪行动一直是机会主义的，其复杂程度门槛也一直低于人们所设想的水平，但广撒网与会自行筛选的广撒网之间仍有区别。
