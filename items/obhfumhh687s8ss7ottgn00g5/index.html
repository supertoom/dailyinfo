CISA warns of Fragnesia Linux flaw chained in PHP2Shell attacks

正文 · AI 翻译
中文原文

美国网络安全和基础设施安全局（CISA）警告联邦机构修补一个高危 Linux 内核权限提升漏洞，攻击者目前正将其与现实中的 PHP2Shell 漏洞串联利用。

该漏洞被追踪为 CVE-2026-46300 ，也称为 Fragnesia，源于 Linux XFRM ESP-in-TCP 子系统中的一个逻辑漏洞，可让攻击者以 root 权限运行恶意代码。

Fragnesia 属于 Dirty Frag 漏洞类别，并且已有概念验证（PoC）漏洞利用程序，本地攻击者可利用它在采用 2026 年 5 月 13 日之前发布的内核的主要 Linux 发行版上获取 root 权限。

CISA 于周三将 CVE-2026-46300 加入 已知被利用漏洞（KEV）目录，并依据其约束性运营指令（BOD）26-04，要求联邦机构在 10 日星期六之前修补系统。

该网络安全机构未披露正在进行的 Fragnesia 攻击的详细信息，但指出威胁行为者可将其与两个严重 PHP 漏洞（CVE-2026-109618 和 CVE-2026-109619，统称为 PHP2Shell）串联利用，在未修补的系统上部署 Web shell。

“该漏洞可与 CVE-2026-109618 和 CVE-2026-109619 串联利用，以植入 PHP Web shell 并以 root 身份运行命令，” CISA 表示。

Fragnesia 和 PHP2Shell 漏洞利用链

尽管 CISA 未提供更多关于攻击者串联利用 Fragnesia 和 PHP2Shell 漏洞的信息，但 Dream Security 分析人员在一份周一的报告中表示，这些漏洞已被用于入侵二十多台服务器，其中包括一台美国政府关联组织的服务器。

“Dream 研究人员发现了一次完整的攻击行动，其中包括对 PHP2Shell 漏洞利用链（CVE-2026-109618/CVE-2026-109619）的定制武器化，并将其与 Fragnesia 内核权限提升漏洞（CVE-2026-46300）结合，还包括目标列表、漏洞利用日志以及大约 40 个定制的漏洞利用后脚本，” 他们表示。

“其中包括一次已控制美国、日本、台湾和韩国境内 25 台服务器的攻击活动痕迹。在取得 root 权限后，攻击者将目标锁定在美国政府关联环境中的三台特定服务器上。”

CISA 还于周一将 PHP2Shell 漏洞 加入其actively exploited vulnerabilities 列表，并要求联邦文官行政分支（FCEB）机构在周四之前保护其网络。

尽管美国网络安全机构尚未提供有关正在进行的 PHP2Shell 攻击的更多详细信息，但 Perplexity 安全工程师 Adel Karimi 证实，其蜜罐在周末记录到了针对运行 PHP 8.4.26 的 Apache mod_php 安装环境的 远程代码执行证据。

当 BleepingComputer 于今天早些时候联系时，CISA 发言人无法立即提供更多信息，说明威胁行为者可能在攻击中串联利用 Fragnesia 和 PHP2Shell。
