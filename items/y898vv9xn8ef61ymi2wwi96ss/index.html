Check Point Security Gateway 遭 PHP2Shell 在野利用，CVE-2026-123039 被用于提权

PHP2Shell Exploitation on Check Point Gateway

AI 导读

攻击者自 2026 年 10 月 30 日起利用未修补的 Check Point Security Gateway Mobile Access 门户开展扫描与利用，以 PHP2Shell 及 CVE-2026-109618、CVE-2026-109619 获取初始访问，再利用 DynamicCLI 接口的本地提权漏洞 CVE-2026-123039 提权至 root。

值得关注

文章还原了从 PHP2Shell 初始访问、权限提升到后门驻留与破坏的完整链路，并公开相关 IOC，便于防守方识别和处置。

主要发现

  • 自 2026 年 10 月 30 日起，攻击者针对存在未修补漏洞的 Check Point Security Gateway 组织发起扫描和漏洞利用活动，以带有 PHP2Shell 的 Mobile Access 门户作为初始访问途径，随后利用 CVE-2026-123039。
  • 第一波攻击于 10 月 30 日展开，以色列组织成为目标，其中包括针对其中部分组织的破坏性活动。11 月 2 日的第二波攻击范围更广，目标涵盖多个国家和多个行业，未发现破坏性活动。
  • 在所调查的入侵中，PHP2Shell 提供了初始访问途径，随后攻击者利用 DynamicCLI 接口进行权限提升，该漏洞追踪为 CVE-2026-123039。攻击者随后部署了 PHP webshell、持久化 TSGA 后门及其内置的 TSProxy 网络组件。
  • 攻击者通过 SSH 从网关转向 VMware ESXi 主机，部署 destroy_v6 擦除器，并在破坏阶段留下带有政治主题的 DREAM_ANNEXATION.txt 字条。
  • TSGA 和 TSProxy 是 PhiliKit 的修改变体；该恶意软件框架此前曾出现在相关文档记录中，用于利用 Ivanti 漏洞的攻击。这两种工具与该框架共享独特的代码、配置和加密材料。
  • 尽管 ESET 将 PhiliKit 与中国关联组织 UNC5221 联系起来，但现有证据无法让我们高度确信地判断本次行动的真实性质。仍有多种可能情形：所识别攻击者策划了整个行动、仅充当初始访问代理，或参与了一场虚假旗行动。破坏性活动也不排除是烟幕的可能。
  • 破坏性活动期间留下的字条使用了 Dream Security 品牌。Dream 此前刚刚发布了关于中国关联组织利用 PHP2Shell 入侵 Palo Alto Networks 设备的研究。尽管这一时间关系引发了报复的可能性，但现有证据未能确立明确的动机。

引言

我们现已确认，在 2026 年 10 月下旬，即安全修复发布约一周后，来自 130.94.19[.]204 的活动通过 Check Point Security Gateway 上存在漏洞的 Mobile Access 门户 targeting 以色列组织。证据表明，部分案例遭到成功入侵，其漏洞利用活动与 PHP2Shell 一致，涉及 CVE-2026-109618 和 CVE-2026-109619。

在获得初始访问后，攻击者利用 CVE-2026-123039，将权限从门户服务账户提升至 root；这是 DynamicCLI IPC 接口中的一个本地权限提升漏洞。攻击者随后利用特权命令执行部署 PHP webshell 并建立持久化。

11 月 2 日nd的第二波扫描以第一波攻击期间曾被 targeting 的部分以色列组织为目标，同时还 targeting 了全球其他组织，似乎并未明确聚焦于以色列。两波攻击均未表现出明显的行业偏好，说明这属于机会主义的初始访问尝试，而非针对特定行业的定向攻击。

感染流程

2026 年 10 月 30 日，受攻击的 Check Point Mobile Access 网关首次出现了被利用的迹象。在 /opt/CPcvpn-R81.20/tmp/ 下创建了 PHP 会话工件，其中包括带有 upload_progress_pwn 标记的会话文件，该标记与此次利用活动有关。在同一时间段内，该门户的 Apache/PHP 工作进程出现了数百次段错误，为反复尝试利用该服务提供了更多证据。

在获取 Mobile Access 门户访问权限后，攻击者利用 DynamicCLI 接口中的本地权限提升漏洞 CVE-2026-123039，将权限提升至 root。凭借特权命令执行能力，攻击者将 PHP Web shell 放入 <templates>，这是 Mobile Access 门户用于构建登录页面的目录。这些 Web shell 提供了一种通过 Web 门户发送命令的方式，从而在已入侵的环境中建立了更牢固的据点。

printf <base64 Webshell> | base64 -d > <templates>/zz<random>.tpl

攻击者使用了多个名称匹配 zz*.tpl 模式的 .tpl 文件。每个文件最初都包含一个命令执行 shell，随后被替换为功能更强大的版本。扩展后的 shell 需要硬编码密钥 zz2026，并支持操作系统命令、PHP 代码执行和文件上传。上传的文件保存到固定路径 /tmp/.up.tpl。随后，攻击者发出命令，将该文件复制到门户目录并命名为 challenge_render.tpl。

随后，攻击者从基于 Web 的访问转向独立的被动后门，在后台启动 TSGA 恶意软件（/tmp/CPconfigdaemon），并将其输出重定向至隐藏的临时日志：

nohup /tmp/CPconfigdaemon >/tmp/.bd.log 2>&1 & printf started

以 root 身份执行时，该恶意软件会自行迁移至启动持久化目录，并以 slot_CPconfigdaemon 为名重新启动。该可执行文件还携带第二个组件 TSProxy：这是一个嵌入式共享库，会被写入 /lib/libcpfwcommon.so。其注入代码会将该库加载到选定的设备进程中，在其中拦截网络函数，以处理带有特殊标记的攻击者连接，同时允许常规流量继续传输。这将独立的持久化后门与通过现有设备服务进行的隐蔽访问结合起来。

随后，攻击者在网关上部署了 gogo 扫描器，以发现网络中的内部资产和服务，并通过 SSH 使用 vpxuser 服务账户继续横向移动至 VMware ESXi 主机。在该 ESXi 主机上，他们将 destroy_v6 擦除器暂存至 /tmp/des wiper 并执行。最终，攻击者留下一条名为 DREAM_ANNEXATION.txt 的说明，伴随此次破坏活动。

技术分析

Web shell

扩展后的 PHP Web shell 需要硬编码密钥才能访问其命令执行、PHP 求值和文件上传功能。它支持纯文本命令以及经过 Base64 编码和 XOR 混淆的命令，并将上传的文件保存到 /tmp/.up.tpl。

擦除器

Linux ELF 擦除器 destroy_v6 接受目标目录作为命令行参数。可选的 -f 标志启用快速删除，而 -w 指定以管道符分隔的排除目录列表。该擦除器会递归遍历目标目录，删除所有扩展名的文件，并跳过被排除的子树。默认情况下，它会尝试用零覆写文件后再将其删除，而快速模式会跳过覆写步骤。它还会向每个已处理的目录写入 DREAM_ANNEXATION.txt。这份带有政治主题的说明包含时间戳，并明确拒绝赎金谈判。

TSGA – slot_CPconfigdaemon

作为 slot_CPconfigdaemon 部署的 TSGA 植入程序是一款 Linux 网关植入程序，具备大量特定于 Check Point 的功能。它提供加密远程访问、配置窃取、备份和快照持久化、进程注入，以及二进制防火墙日志篡改。

TSProxy

TSProxy 是一款嵌入 TSGA 并投放为 /lib/libcpfwcommon.so 的 Linux 共享库后门，支持加密的 SOCKS 风格代理。

工具关系

TSGA 和 TSProxy 都是特定于 Check Point 的组件，与此前报告的与 PhiliKit 相关的工具集有关联。PhiliKit 是一款针对 Ivanti VPN 设备的被动后门和安装程序，此前在名为 philistine 的样本于 2026 年 2 月 25 日上传至 VirusTotal 后被报告。

TSGA 和 PhiliKit 植入程序都源自 Tiny SHell，并共享一组核心远程控制能力。两者均通过 TCP 端口 11072 和 Unix 套接字 /tmp/.p_sock 实施经过身份验证的加密通信。所分析的 PhiliKit 构建将其 TCP 监听器限制在环回地址，而 TSGA 则监听所有 IPv4 接口。两者均提供带伪终端分配的交互式 shell、可配置的终端尺寸以及双向输入/输出。操作员可以执行任意 shell 命令以及 Python 或 Perl 脚本、检索其输出、使用操作员选择的路径传输文件，并通过加密通道收集选定或完整的设备配置。

TSProxy 与嵌入 PhiliKit 软件包中的网络组件 libdssafe.so 共享独特的配置：相同的操作员凭据、传输密钥、三个匹配的激活选择器摘要，以及相同的 TLS 证书和私钥。这些重合之处有力地支持了二者具有共同工具谱系的判断。

归因

投放到网关的植入程序 TSGA 和 TSProxy 属于 PhiliKit 恶意软件家族，该家族此前曾与中国关联组织 UNC5221 以及针对 Ivanti 设备的先前利用活动相关联。此外，gogo 扫描器也曾被报告与利用 Ivanti 漏洞的中国关联威胁行为者有关。

攻击者使用的基础设施 IP 地址托管于 LightNode VPS 基础设施上，此前该服务曾与中国关联威胁行为者的活动相关联。

扫描活动集中在 UTC 时间 00:00 至 09:00 之间，对应中国时间的 08:00–17:00，大体符合中国典型的工作时间。

综上所述，以下在所述攻击活动中出现的属性似乎并未完全符合已知中国关联组织（尤其是 UNC5221）的动机和利益：

  • 破坏性操作
  • 关注以色列，以及用希伯来语撰写、提及以巴冲突的删除工具说明
  • Philikit 名称源自该恶意软件的内部名称 philistine

综合来看，现有证据不足以让我们高度确信地判断此次行动的真实性质。仍有多种情形可能成立：已识别的行为者独自实施了整个活动，仅充当了初始访问中介，或参与了一场虚假旗行动。破坏活动也可能是用来转移注意力的烟幕。
