GeoServer未认证RCE链已复现并出现利用探测

9 篇报道8 个报道来源9 小时前更新

先了解这件事

AI 综述

GeoServer 五个漏洞（CVE-2026-129242、CVE-2026-129243、CVE-2026-129244、CVE-2026-120705、CVE-2026-129245，CVSS 3.1 9.8）可串联成未认证远程代码执行链，奇安信CERT、长亭安全应急响应中心、深瞳漏洞实验室等已复现，PoC与技术细节均已公开；WatchTowr 观察到攻击者利用 CVE-2026-120705 和 CVE-2026-129243 发送基于错误的利用探针探测存在漏洞的服务器，尚未发现成功实现远程代码执行的案例。 利用无需认证，但前提是默认配置且 WFS 与 REST 接口网络可达；绿盟科技CERT进一步指出，需 WFS 与 REST API 对匿名用户开放、remember-me 认证启用且默认用户中的管理员账户可用。受影响版本为 GeoServer <= 2.27.6、2.28.0 <= GeoServer <= 2.28.5、3.0.0 <= GeoServer <= 3.0.1；攻击者可读取服务器端安全配置、伪造管理员会话并以 GeoServer 服务进程权限执行代码，以官方容器镜像默认配置部署时该进程以 root 运行。 官方已发布补丁，修复版本为 3.0.2、2.28.6、2.27.7 及对应分支更高版本，CNVD 收录为 CNVD-2026-47957 至 CNVD-2026-47961 并建议受影响用户立即自查升级。
