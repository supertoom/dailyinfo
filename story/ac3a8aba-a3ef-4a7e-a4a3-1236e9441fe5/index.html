微软修复Azure API Management Classic漏洞

4 篇报道4 个报道来源13 小时前更新

先了解这件事

AI 综述

微软确认Azure API Management Classic层级漏洞已被利用，攻击者可未授权访问部分管理功能并窃取实例中存储的凭据，受害者包括Equinor、Skagerak Energi等挪威能源组织；微软已关闭访问路径并部署缓解措施，但未披露受影响客户数量，整体利用范围仍不明确。 仅未按微软安全最佳实践配置的Classic实例受影响，APIM v2层级不受影响。可能暴露的凭据包括命名值、身份提供程序及OpenID Connect客户端密钥、订阅密钥和APIM直接管理API令牌。微软修复后不会自动使此前可能被访问的凭据失效，客户应按排查和轮换指导处理，并确认实例已更新至固定运行时版本0.52.31936或更高版本、0.53.31938或更高版本；具体受影响版本、漏洞编号和CVSS评分报道未提供。
