AI 综述

ConnectWise 正在调查攻击者劫持托管服务提供商（MSP）的 ScreenConnect 环境，通过 Run Command 向客户托管端点投放 SCKit 恶意客户端；Huntress 已确认至少 48 家组织的 288 个端点受影响，恶意客户端可建立持久后门。ConnectWise 已在约 400 个 ScreenConnect 环境中禁用 Labtech Plus、RMM Plus、RMM+、RMM Plus Password Link 和 RMM+ Password Link 五个扩展。 Blackpoint Cyber 称，SCKit 利用 ScreenConnect 的鉴权绕过漏洞 CVE-2026-84869（CVSS 9.9）在活跃远程会话中实现未授权文件传输和执行；其测试确认现有补丁可阻止该利用，且未观察到攻击成功利用该漏洞或绕过补丁。初始访问是否来自恶意第三方扩展仍缺乏充分证据，补丁也不能消除已认证操作员会话遭劫持的风险；目前没有证据显示恶意软件已从受感染端点成功传播至技术员工作站。
