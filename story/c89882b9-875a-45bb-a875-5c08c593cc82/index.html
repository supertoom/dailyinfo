云安全公司 Wiz 称，未披露攻击者利用已泄露的 Qubole AWS IAM 凭据，冒充客户为大数据平台 Qubole 设置的跨账户角色，进入逾12家组织的 AWS 环境窃取数据；凭据如何泄露、是否已被禁用及攻击是否停止均未说明。后续报道援引 Sentra 称受害者达数十家，仅一个客户就有数百万个文件被盗，但确切下游受害数量未披露。 攻击活动于10月14日至26日进行，用于枚举资源、收集 Secrets Manager、SSM Parameter Store 中的凭据与配置并访问数据。Wiz 还发现10月8日至11日的另一轮攻击：攻击者测试客户自有 AWS 访问密钥，部分环境遭入侵。Wiz 表示，在此次观察到的角色扮演中，仅设置源 IP 条件即可阻止每次操作。
