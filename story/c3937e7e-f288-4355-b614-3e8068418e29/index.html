Google 已修复 Chrome XML 组件释放后重用漏洞 CVE-2026-125350，并确认该漏洞存在在野利用；奇安信威胁情报中心已复现，深信服千里目安全实验室将其 CVSS 3.1 评分列为 8.8、高危。该漏洞利用无需认证、默认配置即可远程触发，攻击者诱导用户访问包含恶意 XSLT 的网页即可造成浏览器渲染进程内存损坏并可能实现任意代码执行；受影响版本为 Chrome Windows/Mac < 157.0.8103.50/.51、Linux < 157.0.8103.50。 修复版本为 Chrome Windows/Mac 157.0.8103.50/.51、Linux 157.0.8103.50，桌面稳定通道将在未来数日或数周内逐步推送；Android 版 157.0.8103.50 也已发布并包含对应桌面版安全修复。Google 尚未披露攻击者身份、攻击目标或利用规模；CISA 也尚未将 CVE-2026-125350 列入 KEV。
