Armory Castle利用vCenter零日漏洞植入后门

3 篇报道3 个报道来源9 分钟前更新

先了解这件事

AI 综述

Mandiant/Google Threat Intelligence 称，疑似中国国家支持组织 Armory Castle（原 UNC5221，又名 Warp Panda）自2026年9月起在野利用 VMware vCenter 认证绕过漏洞 CVE-2026-123890（CVSS 9.8），攻击者只需网络访问受影响部署，无需凭据即可绕过认证并以 Administrator 用户权限取得未授权访问。该漏洞位于 VMware Directory Service。 攻击者使用定制工具 Bonesaw 窃取 Lightning Memory-Mapped Database（LMDB）、提取 SAML 签名材料并创建单点登录（SSO）管理员账号，该工具适用于 vCenter 7.x 和 8.x。Bonesaw 属于后手植入手段，已被 Mandiant 记录到攻击活动；Broadcom 尚未确认该漏洞被利用。 Broadcom 已于11月19日通过 VMSA-2026-0009 发布修复版本 vCenter 9.1.1.0200、9.0.2.0200 和 8.0 U3m，同时修复 VMware SDDC Manager 与 VMware Tools for Windows 的另外四个漏洞；补丁无法通过 vCenter Quick Patch 安装，Broadcom 列为无官方变通方案，仅建议以网络限制和防火墙控制降低暴露面。已于2025年10月结束常规支持的 vCenter 7.0 目前尚无公开补丁；正在升级中的客户需查阅厂商 FAQ 与互操作矩阵。
