SignDrop Windows 提权 PoC 已公开

4 篇报道4 个报道来源16 小时前更新

先了解这件事

AI 综述

安全研究员 Abdelhamid Naceri（MSNightmare、Chaotic Eclipse）公开了 Windows CLFS 驱动本地权限提升漏洞 SignDrop 的 PoC，可借路径重定向和 .cnpf 伴生文件链式启动 SYSTEM shell，使标准用户获得 SYSTEM 权限；目前尚无已确认的在野利用，Microsoft 尚未确认漏洞、分配 CVE 或发布修复，CISA 已知遭利用漏洞目录也未收录。 公开利用链要求 CLFS 认证注册表模式为 0（强制）或 1（学习），且 Windows Defender 必须启用。Naceri 在 Windows 11 26H2、Windows 11 26H2 Experimental 和 Windows Server 2025 Experimental 上完成测试，并估计约 80% 的 Windows 安装可能受影响，但该利用不适用于所有机器。关闭 CLFS 缓解措施会暴露于利用内存破坏漏洞的攻击，目前可行应对是等待 Microsoft 补丁。
