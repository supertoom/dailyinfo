vCenter认证绕过漏洞已复现并发布补丁

7 篇报道7 个报道来源2 天前更新

先了解这件事

AI 综述

Broadcom 已通过 VMSA-2026-0011 修复 VMware vCenter Server 认证绕过漏洞 CVE-2026-123903（CVSS v3.1 9.8，Critical）；Rapid7 验证公开 PoC 可成功绕过认证，长亭安全应急响应中心和微步在线研究响应中心也已独立复现。截至相关公告发布时，尚无该漏洞在野利用的公开报告，受害规模未确认。 攻击者只需通过网络访问受影响实例的 VMware Directory Service（vmdir）389 端口，无需任何凭据。长亭称，漏洞仅影响 SASL 认证路径，未认证攻击者在一次 SASL SRP 认证失败后即可残留管理员身份、获得管理员会话并创建管理员账号接管 vCenter；simple bind 失败会清理状态。 受影响版本为 vCenter Server 9.1.x.x<=version<9.1.2、9.0.x.x<=version<9.0.2.0300、8.0<=version<8.0U3m 及 7.x，修复版本为 9.1.2、9.0.2.0300、8.0 U3m，VMware Cloud Foundation 5.x 升级至 5.2.5。Broadcom 未提供临时变通方案，更新不适用于 Quick Patch；已为修复 CVE-2026-123890 安装 vCenter 8.0 U3m 的实例无需再更新。
