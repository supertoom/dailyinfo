Apache HTTP/2 远程代码执行漏洞 CVE-2026-119618 已复现

Apache HTTP Server 的 mod_http2 存在远程代码执行漏洞 CVE-2026-119618，奇安信 CERT 已成功复现。攻击者无需认证，在目标启用并开放 HTTP/2 时，可利用并发流和特定请求头布局触发无锁 APR allocator 竞争，造成进程崩溃、拒绝服务，并可能以 httpd 进程权限执行任意代码。
